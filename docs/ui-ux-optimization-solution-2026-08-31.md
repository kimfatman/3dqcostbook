# 算得清 · 全局 UI/UX 升级优化方案
**版本：** v2（全局总方案） ｜ **日期：** 2026-08-31 ｜ **范围：** 全站（5 个底部 Tab + 详情页/二级页 + 登录/管理后台 + 全局体系层），**不限于单一模块**
**方法：** 全局优化研究报告（12 页实测）× `ui-ux-pro-max` 规则库（119 条 UX 规则/图表/配色）× `apple-design` 流体交互 × 现有 `DESIGN.md` 令牌基线 × C1–C7 已上线成果
**核心立场：** 本方案是全站 UI/UX 升级的**唯一权威总方案**；经营分析模块、后续任何新页面都只是它的消费方，必须遵守其中规则。

## 一、覆盖范围与总原则

### 1.1 覆盖范围（全局，非单模块）
| 面 | 覆盖内容 |
|---|---|
| **全局体系层** | 设计令牌（颜色/字号/圆角/间距/阴影）、组件库、图标体系、动效体系、暗色模式、无障碍基线、性能 |
| **导航层** | 底部 Tab、粘性导航、详情页主导航、FAB、back/深链接、空导航态 |
| **5 个主 Tab** | 工作台 / 订单 / 商品 / 洞察（→经营分析）/ 我的 |
| **详情与二级页** | 订单详情、商品详情、成本诊断、智能定价、消息中心、登录页、经营分析双 Tab |
| **跨端** | Web App（当前落地）+ 小程序（复用同一规则与令牌） |

### 1.2 总原则（全站通用）
1. **令牌优先**：全站样式只写 `--sdq-*` 语义令牌，禁止新增硬编码 hex / 非标圆角 / 随机字号 [U-pro §6]
2. **移动优先**：触控 ≥44pt/48dp、安全区、8dp 间距节奏、375px 回归 [U-pro pro-rules]
3. **动效克制**：apple-design 流体原则，只动 transform/opacity，respect reduced-motion [apple-design][U-pro §7]
4. **数据可视化语义化**：图表颜色+符号+文本，不单靠颜色 [U-pro §10]
5. **双主题贯穿**：light/deep 对比度独立校验 [U-pro pro-rules]
6. **图标纪律**：结构化图标全 SVG（Lucide），无 emoji，统一描边/填充 [U-pro pro-rules]

## 二、全局体系层（先立标准，后改页面）

### 2.1 设计令牌（77 色/13 圆角/10 字号 → 收敛）
C1 已建原色阶 50–950 + 语义层重指向 + Tailwind `@theme` 桥。**收尾动作：**

| 体系 | 收敛方案 | 现状 |
|---|---|---|
| 颜色 | 品牌蓝五级阶梯语义固化：深蓝=数据快照、亮蓝=操作；全站检查残留 hex 逐一收编 | 报告 P1-B + DESIGN.md §1 |
| 字号 | 11 档体系（11/12/14/16/18/20/24/30/36/48），补 17→39 断档；金融数字 IBM Plex Mono 全局统一 | 报告 §2.2 |
| 圆角 | 8 档（0/4/8/12/16/24/9999/50%），现有 7/9/10/11/17 归档 | 报告 §2.3 |
| 按钮 | 5 档（xs24/sm32/md40/lg48/xl56）+ FAB56 | 报告 §2.4 |
| 间距 | 8dp 节奏：4/8/16/24/32/48 层级化 | [U-pro pro-rules] |
| 阴影 | 4 档蓝调收敛 | 报告 §2.5 |

### 2.2 组件库（12 核心组件全站复用）
现有 `components/ui/`（shadcn 基）已具多数原子组件。补齐语义组件并全站强制复用，禁止页面私有样式：
`Button`（5 size×4 variant）｜ `Input` ｜ `Card` ｜ `MetricCard`（大数字+标签+趋势）｜ `Badge`（默认/警示/成功/待观察）｜ `SegmentedControl` ｜ `Drawer` ｜ `Modal` ｜ `Toast`（sonner）｜ `FAB`（智能避让）｜ `EmptyState`（结果/原因/行动）｜ `PageHeader`（返回+标题+操作）

### 2.3 图标体系
- 全站结构化图标统一 Lucide SVG；删除 emoji 图标
- 图标尺寸 token（icon-sm/md/lg）、统一描边、统一填充/线性
- 纯图标按钮带 aria-label；装饰图标 aria-hidden；图标对比度 ≥3:1

### 2.4 动效体系（apple-design 抽取，全局统一）
| 规则 | 落地 |
|---|---|
| 按压即反馈 | `:active` 立即 scale 0.97/100ms，不等 release |
| 可中断 | 抽屉/展开动画随时反向，绝不锁输入 |
| 弹簧曲线 | 进入 deceleration、退出 acceleration；退场=入场 60–70% |
| 只动 transform/opacity | 禁 width/height/top/left 动画，防 CLS |
| 每屏 ≤2 动效 | 财务数字稳定态优先，无多余动画 |
| reduced-motion | 全站尊重系统偏好关闭动效 |
| 运动 token | 统一 duration/easing 令牌（--sdq-motion-*），全局一致 |

### 2.5 暗色模式（双轨，报告 P2 前置）
- 现有 `skin-deep` 皮肤完备；本轮要求所有新组件按语义 token 双轨书写
- 暗色正文 ≥4.5:1、非文本 ≥3:1 独立校验；分隔线/状态双主题均可见
- 支持 `prefers-color-scheme` 自动跟随（报告 6.2）

### 2.6 无障碍基线
- 对比度正文 ≥4.5:1；焦点环全站可见（focus-visible 已接，保持）
- 键盘导航可达全部交互；图标/按钮 aria 完备
- 表单 label 可见 + 错误内联 `aria-describedby` 关联
- 触控热区 ≥44pt/48dp

### 2.7 性能（报告第五章）
- 首屏 10s→3s：CloudBase 预置并发 + 关键 CSS inline + tRPC httpCache（已 batch）
- 图片 WebP/AVIF + 懒加载；CLS<0.1（骨架屏预留）
- 中期：Next.js 路径路由 /orders/:id + PWA 二次访问秒开（报告 P2）

## 五、全局实施批次（延续 C1–C7 节奏，串行推进）

> **推进方式（结合仓库实际，2026-08-31 调研定稿）**：
> - 仓库既定模式为"多 Agent 协作"（`ui-backend-agent-prompts.md`：统筹/UI/后端 3 Agent，独立分支 + PR 交接 + 回归证据）。C1–C7 已由本地 agent 用"每卡独立分支 → 三门禁 → 合 main → Runbook 发布"成功上线，本批完全复用该模式。
> - **串行推进，非并行**：所有批次（含经营分析一期）都改 Home.tsx 洞察区域，并行会同文件冲突。每批独立分支 `agent/ui-upgrade-cN-*`，合入 main 后开下一批。
> - **P0 后端问题分流**：OTP 链路、注册邮箱验证、店铺切换器属认证/后端，划给后端 Agent 单独批次，不混入 UI 批次。
> - 每批保留 DOM 回归断言（延续 C1–C7 每卡 5–12 项），三门禁（`pnpm check` + `pnpm test` + `pnpm build`）全绿才合并。

| 批 | 内容 | 规模 | 验收锚点 |
|---|---|---|---|
| **后端-P0（分流）** | OTP 链路修复、注册邮箱验证、店铺切换器（后端 Agent） | M | 认证回归 + 店铺切换 e2e |

## 六、全站验收清单

**全局（skill pro-rules + 报告）**
- [ ] 375px 小屏 + 横屏无溢出；无内容被固定栏/安全区遮挡
- [ ] 触控热区 ≥44pt/48dp；按压反馈 80–150ms
- [ ] reduced-motion 全站关闭非必要动效
- [ ] 暗色对比度独立校验（正文 ≥4.5:1）
- [ ] 无 emoji 图标；图标统一 Lucide + token；aria 完备
- [ ] 令牌无新增硬编码 hex；字号/圆角/按钮收敛到体系
- [ ] 详情页保留主 Tab；back 保留状态；深链接可达

**每页（延续现有 DOM 回归惯例）**
- [ ] 每页配 DOM 回归断言 + 375/390/430/768/1280 多视口
- [ ] 空态/加载/错误态三态齐全
- [ ] 财务数字金融字体 + tabular-nums + 语义色
