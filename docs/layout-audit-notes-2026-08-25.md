# 间接成本与智能定价截图排版审阅笔记

## 间接成本分摊：图块 1–2

截图首屏存在两个重复的“间接成本分摊”标题：顶栏居中标题之后，再出现较大的页面主标题，且两者之间的留白和背景渐变占用了过多纵向空间。摘要卡本身可读，但紧随其后的“新增本期成本”标题与“保存后可随时切换是否摊销”并列，形成同一视觉层级的长句竞争；在 390px 级别宽度下，表单第一行的费用类型与金额字段也呈现不均衡的视觉重量。

后续修复目标是将顶栏保持为导航层，页面主标题改为紧凑内容层；将长说明下沉为小号辅助文本；使用统一的表单标签、控件高度和移动端单列优先规则。

## 间接成本分摊：图块 3–4

日期与分类使用双列是合理的，但当前标签与控件之间的垂直间距不一致，备注字段又突然占满整行，造成节奏断裂。“是否已经发生”和“一键摊销到项目”被做成两张浅色嵌套卡，标题、说明、单选按钮和下拉框在同一屏内争夺注意力；项目列表本身的行高又明显大于上方表单控件。

后续应将其收敛为清晰的三步结构：**费用信息 → 计入方式 → 分摊对象**。每一步仅保留一个标题、一行必要说明和一个紧凑的选择控件；项目列表使用与全站列表一致的 52px 左右行高，避免“设置卡中套设置卡”的层级膨胀。

## 间接成本分摊：图块 5–6

保存按钮具备足够触达面积，但在长表单末端与成本池空态之间存在两套相近的白色卡面，主操作完成后仍需要再次辨认下方内容。成本池空态的引导文本与标题、计数同行竞争，底部的“口径说明”以较大文字块占据一张独立卡片，随后留出过大的空白直至浏览器工具栏。

后续将把成本池空态缩减为一条紧凑列表状态；“口径说明”收敛为可展开的低权重说明，默认只保留一行摘要。页面底部统一以内容安全区收口，而不以大面积渐变空白填充。

## 智能测算定价：图块 1–2

定价页同样出现顶栏标题、面包屑和大号口号三层标题，首屏纵向耗费偏高。深色“当前单位完全成本”卡的金额视觉正确，但高度、字号和留白显著大于间接成本页的摘要尺度；其下销售渠道表单又回到白色大卡，形成过强的深浅断裂和双重容器感。

后续将保留顶栏导航与一个紧凑主标题；完全成本降为统一的“重点结果卡”高度；销售渠道内容作为连续表单分组承载，减少不必要的外层卡与分隔线。

## 智能测算定价：图块 3–4

平台模板、费率、履约费用和目标毛利率的输入控件高度明显偏大，空值“0”被放在超高输入框中，造成低信息密度。保本售价随后独立成大白卡，建议售价又立即进入深色大卡；两张结果卡的文字/数字尺度、填充和颜色语义没有遵循同一个等级体系。

后续将把普通数值输入统一为紧凑 48px 控件；保本价作为浅色辅助结果行；建议价保留为唯一深色重点结果卡，并控制在与其他重点卡一致的高度与内边距。

## 智能测算定价：图块 5–6

建议价卡内部继续嵌套滑块面板、趋势图边框、结果提示条和白色写入按钮。每层都使用独立圆角与描边，导致同一“试算结果”被拆成四个视觉容器；趋势图内还残留密集虚线/点线参考线，与当前全站低干扰图表规范冲突。

后续将把滑块、当前值和曲线组合为一个连续的定价结果区：滑块为上半段的直接操作，曲线为下半段的反馈，不再使用多层边框；保本与建议只以低对比实线标记，不使用装饰性虚线或逐点串珠式描边。

## 智能测算定价：图块 7–8

竞品与促销模拟使用双列字段，但“促销折扣”字段被挤成窄小方块，和右侧促销后售价的宽输入框完全不平衡。下方常用目标售价列表则出现粗黑边框和超大行高，与全站圆角、细分隔、轻阴影的卡片规则明显冲突。

后续在手机端让促销模拟改为单列或等宽双列；目标售价列表改为无外框的紧凑可点按行，统一使用细实线分隔、主标签/辅助提示/末端金额三段式对齐。

## 智能测算定价：图块 9

目标售价列表末项后存在不承载信息的大面积渐变空白，直至浏览器工具栏才结束；这与间接成本分摊页的末端问题一致。后续统一通过页面内容安全区和底部导航避让变量收口，避免各页面各自使用不确定的空白高度。

## 统一布局执行规范

| 层级 | 统一规则 | 覆盖范围 |
|---|---|---|
| 导航与标题 | 顶栏只承担返回和页面名称；内容区仅保留一个 22–26px 主标题与一行可选辅助信息。 | 间接成本、智能定价、成本卡、预算与分析二级页。 |
| 页面容器 | 移动端左右内边距为 16px；模块间距为 12px；内容末端通过统一安全区避让导航，不使用装饰性空白。 | 所有 `ledger-page-shell` 二级页。 |
| 卡片 | 普通承载卡为 16px 圆角、12–14px 内边距、细实线或轻阴影；一个页面只允许一个深色“重点结果卡”。 | 表单、摘要、列表、价格结果。 |
| 表单 | 标签 11px，控件 48px；手机端默认单列，只有语义对等的两项才使用等宽双列；说明文字跟随字段而不独占大卡。 | 成本、定价、预算和资料设置表单。 |
| 选择与列表 | 单选组采用紧凑分段控件；项目/档位列表为 52–56px 可点击行，细实线分隔，不嵌套粗边框。 | 分摊模式、项目选择、目标售价、渠道模板。 |
| 图表与结果 | 操作滑块、曲线和当前结论共用一个连续结果区；图表仅保留实线的必要参考标记，避免双重框线、点线和重复图例。 | 智能定价、首页与分析图表。 |

## 实施与验证结果

已新增独立的 `layout-unification.css` 作为统一覆盖层，避免继续在历史主样式的尾部叠加脆弱规则。间接成本页将内容标题改为“本期成本设置”，消除与导航栏“间接成本分摊”的重复；摘要、录入、选项、成本池和口径说明统一为同一圆角、内边距和实线分隔体系。智能定价页将普通输入、保本价、竞品模拟和目标售价统一到轻量卡片体系，并仅保留“当前单位完全成本”和“建议售价”两个深色重点结果区；价格滑块、利润曲线和当前结论改为连续结果区，清除了视觉上多层嵌套的边框节奏。

| 验证面 | 结论 |
|---|---|
| 375px、390px、430px | 字段、单选组、项目行、滑块、价格图和末端操作均未裁切；短标题与辅助文字不再相互竞争。 |
| 768px、1280px | 两页保持 720px 左右的最大阅读宽度，表单对齐而不扩展成后台式宽面板。 |
| 页面级交互 | 真实 Home DOM 回归从“分析 → 间接成本”和“商品 → 成本详情 → 测算定价”进入，断言标题、关键录入、摊销、价格滑块及结果区仍可访问。 |
| 质量门禁 | `pnpm check`、45 个测试文件/162 项测试和 `pnpm build` 均通过；构建仅保留既有主 JavaScript chunk 大于 500kB 的提示。 |

首页与成本分析也在同一轮 375px、390px、430px、768px 与 1280px 截图中复核。首页的经营主卡、目标卡、提醒、轮播、图表入口、悬浮“记一笔”和底部导航保持既有间距层级；成本分析的标题、结果卡、结构排行、折叠复核区与悬浮“记一笔”同样没有裁切或安全区冲突。四页均使用短标题、16px 级圆角承载面、细实线分隔和移动优先的阅读宽度。
