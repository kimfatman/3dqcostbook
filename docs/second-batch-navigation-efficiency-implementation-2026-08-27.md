# 第二批导航、列表效率与真实事件表达实施记录

> 实施日期：2026-08-27。本文记录已确认的第二批整改范围、实际行为、账务边界、本地验收与生产发布结果。

## 实施摘要

第二批将移动端一级导航的经营语义收束为 **工作台 / 订单 / 商品 / 洞察 / 我的**。其中“工作台”承载日常经营概览，“洞察”承载利润和成本分析；两个模块仍保留原有独立页面、URL 状态和返回行为，并未删除或合并账本能力。个人页将视觉皮肤与深色模式由平铺控制收进可返回的“外观设置”二级页。

订单和商品列表分别进行了信息密度收口。商品成本列表不再显示列表级 SKU 技术编码及重复的近六期微趋势，而保留名称、单位、单位成本、售价、单件利润、成本构成与智能定价入口。订单列表支持筛选范围内的多选，复核状态以独立元数据保存，并提供安全的批量复核、取消复核和 CSV 导出。

| 模块 | 已实现行为 | 明确不改变的边界 |
| --- | --- | --- |
| 一级导航 | “经营”更名为“工作台”，“分析”更名为“洞察” | 原页面、深链接、返回、订单和商品入口保持不变。 |
| 外观设置 | 在“我的”中显示单一入口；皮肤和深色模式移至二级页 | 切换只影响显示，绝不改变账本、订单或经营数据。 |
| 商品列表 | 移除列表级 SKU 技术码与重复微趋势，提升成本/售价/单件利润的视觉层级 | SKU 关联、成本卡、售价和智能定价计算不变。 |
| 订单复核 | 新增 `reviewedAt` 独立状态，可多选、批量标记、取消并按“待复核”筛选 | 不改写成交日期、金额、订单行、退款、COGS、费用或成本快照。 |
| 批量导出 | 仅导出选中订单关联的既有账务流水 CSV | 不新增写入，不提供批量改价、删除、退款、SKU 编辑或重算。 |

## 安全批量操作

批量“标记复核”“取消复核”和“导出”均增加二次确认。确认提示会显示当前选中笔数和操作边界：前两者仅更新复核元数据，CSV 导出为只读操作。用户取消确认时，选中状态保持不变，且不触发任何账务写入或下载。

订单复核元数据通过 `applyOrderReviewState` 独立写入，并限制为当前行业的被选订单。状态结构版本升级为 `6`，历史本地账本会在归一化时兼容升级；该版本变化不影响金额以分存储、订单成交日聚合、退款日期归属、SKU 月度边界或历史订单行冻结成本。

## 真实趋势事件

利润趋势下方新增“真实经营事件”摘要。事件只能来自当前行业的可追溯记录：订单按 **成交日**、退款按 **退款日**、独立成本按 **支出日期** 归属。订单自动生成的已售成本不会重复标记为“成本录入”；没有业务来源时不展示事件，也不会生成促销日、食材涨价日或价格变更等虚构标记。

| 事件类型 | 数据来源 | 显示与下钻 |
| --- | --- | --- |
| 订单成交 | `Order.occurredAt` | 显示当月成交笔数，点击进入该月流水。 |
| 退款发生 | `RefundCase.occurredAt`、`refundFen` | 显示退款笔数和金额，点击进入该月流水。 |
| 独立成本支出 | 无 `orderId`、无 `relatedEntryId` 的 `expense` 分录 | 显示录入笔数和金额，点击进入该月流水。 |

## 视觉与可访问性

样式层新增跨页面语义令牌：收益使用绿色、亏损使用红色、预警使用橙色、中性/信息使用蓝色；工作台、订单、商品、洞察、我的和二级页的页面壳共享这些令牌。辅助文字的最小字号提升为 11px，焦点态使用可见的品牌蓝描边。深色模式与深海皮肤覆写同一组令牌，降低浅底浅字风险；同时保留 `prefers-reduced-motion` 下的非动态行为。

本轮没有引入网格、虚线、厚重边框或 BI/ERP 风格装饰，继续保持蓝白/深海军蓝的移动端经营工具视觉基调。
