## 全局配色规范（维度14）

### 14.1 语义令牌强制
- 所有颜色必须使用 `var(--sdq-*)` 语义令牌
- **禁止**在组件 CSS/TSX 中硬编码 `#hex`、`rgb()`、`rgba()`
- 原色阶（`--sdq-blue-*` / `--sdq-neutral-*`）只在令牌定义文件中使用，组件不直接消费

### 14.2 对比度要求（WCAG AA）
| 元素 | 对比度要求 | 验证方式 |
|---|---|---|
| 正文文字（<18px） | ≥4.5:1 | text-primary vs bg-canvas |
| 大文字（≥18px 或 ≥14px 加粗） | ≥3:1 | text-secondary vs bg-canvas |
| 非文本（图标/边框/图形） | ≥3:1 | icon-default vs bg-surface |
| 主按钮文字 | ≥4.5:1 | text-on-brand vs action-primary |
| 业务语义色文字 | ≥3:1 | profit/risk vs bg-surface |

### 14.3 业务语义色保护（不可随皮肤修改）
| 令牌 | 颜色 | 含义 | 保护原因 |
|---|---|---|---|
| `--sdq-profit` | #20a779（绿） | 利润/收入/正向 | 财务红绿约定 |
| `--sdq-cost` | #f6a623（橙） | 成本/支出 | 成本警示 |
| `--sdq-risk` | #e8534f（红） | 风险/亏损/危险 | 危险信号 |
| `--sdq-info` | #5acbfa（浅蓝） | 信息/提示 | 信息色 |

### 14.4 颜色层级
| 层级 | 令牌 | 用途 | 浅色值 | 深色值 |
|---|---|---|---|---|
| 背景最底层 | `--sdq-bg-canvas` | 页面背景 | #f5f7fa | #14191f |
| 背景表面 | `--sdq-bg-surface` | 卡片/面板 | #ffffff | #151f31 |
| 背景次级 | `--sdq-bg-surface-subtle` | 内嵌区域/表头 | #f2f7ff | #1b2940 |
| 背景浮层 | `--sdq-bg-elevated` | 弹窗/抽屉/下拉 | #ffffff | #202e45 |
| 文字主 | `--sdq-text-primary` | 标题/正文 | #212830 | #f5f7fa |
| 文字次 | `--sdq-text-secondary` | 副标题/辅助 | #576575 | #bcc6d2 |
| 文字弱 | `--sdq-text-tertiary` | 占位/禁用 | #8f9dae | #7f8ba0 |
| 边框弱 | `--sdq-border-subtle` | 卡片边框/分割 | #ebf0f4 | #2d3a50 |
| 边框强 | `--sdq-border-strong` | 输入框 focus/强调 | #c9d3de | #49607d |

### 14.5 状态色规范
| 状态 | 样式 | 令牌/值 |
|---|---|---|
| 默认 | 基础样式 | 各组件默认 |
| hover | 亮度+5%，阴影加深 | `filter: brightness(1.05)` |
| active | 缩放 0.97-0.98，变暗 | `transform: scale(.98)` |
| disabled | 透明度 0.5-0.6，cursor not-allowed | `opacity: .58` |
| focus | 4px 光晕 + 边框变色 | `box-shadow: 0 0 0 4px color-mix(in srgb, var(--sdq-action-primary) 10%, transparent)` |
| 错误 | 红色边框 + 红色光晕 | `border-color: var(--sdq-risk)` + `box-shadow: 0 0 0 4px color-mix(in srgb, var(--sdq-risk) 10%, transparent)` |

### 14.6 品牌色使用
- `--sdq-action-primary`：主按钮、链接、焦点环、选中态、图标强调
- `--sdq-bg-brand`：品牌背景区域（hero 区、大卡）
- `--sdq-bg-brand-soft`：品牌色浅底（标签、选中行、徽章背景）
- `--sdq-text-on-brand`：品牌色背景上的文字（必须白色或近白）

### 14.7 图表配色
- 使用语义色：收入=`--sdq-income`，成本=`--sdq-cost`，利润=`--sdq-profit`，风险=`--sdq-risk`
- 不依赖颜色 alone：必须加图例、文字标签、pattern 区分
- 深色模式下图表颜色自动适配（语义令牌已处理）
- 瀑布图：收入/利润用蓝色系，成本/费用用灰色/橙色系

### 14.8 深色模式配色
- 背景：`--sdq-bg-canvas` = neutral-950，`--sdq-bg-surface` = 带蓝调深色（非纯黑）
- 文字：`--sdq-text-primary` = neutral-50，`--sdq-text-secondary` = neutral-300
- 边框：`--sdq-border-subtle` = neutral-800（可见但不突兀）
- 阴影：`--sdq-shadow-card` = 0 6px 20px rgba(0,0,0,0.24)（深色下阴影更明显）
- 业务色：在深色背景下明度提高（如 profit #20a779 → 深色下可辨识），色相不变
