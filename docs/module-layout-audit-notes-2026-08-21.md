# 模块排版布局审查：证据笔记

## 视口覆盖

已在 375×812、390×844 与 430×932 复核首页、订单、商品、分析、预算、流水、个人中心、消息中心、订单表单与商品成本表单。三个视口均没有发现横向溢出、固定按钮被底部导航遮挡或主要金额列换行。

| 模块 | 观察到的排版表现 | 初步判断 |
|---|---|---|
| 首页经营判断 | 核算主卡、96px Banner、趋势与两条数据行形成明确纵向节奏；375px 仍可阅读。 | 结构稳健，应作为跨页布局基准。 |
| 订单空状态 | 空态卡、售后区和固定按钮之间有较大连续留白，顶部加号与底部按钮构成重复行动。 | 需要压缩空白并强化空状态的行业化原因。 |
| 商品成本卡 | 三列数字、六期微趋势与双操作行对齐稳定；单张卡高度较大但信息任务完整。 | 总体良好，可微调趋势区高度与操作行边界。 |
| 分析 | 月度收入/成本图只有最后一期有显著高度时，图表产生大面积低信息留白；排行右侧红色“新发生”竖排压迫数值列。 | 需要将图表高度或空值表达改为数据自适应，并重排状态标签。 |
| 预算 | 环形图占用大面积，橙色覆盖成为视线主导；预测卡、预算卡的白卡边界清楚。 | 需降低环图高度和风险色面积，使蓝色核算结构优先。 |
| 流水 | 筛选、搜索、结果数与日期分组紧凑，金额右对齐清晰。 | 作为高密度列表参考；固定按钮文案仍偏“成本”。 |
| 个人中心 | 店铺信息、余额公式、五行管理入口在 430px 上方集中，后半屏留白明显。 | 应加入一项当前维护任务或最近经营动作，减少“导航壳”感。 |
| 消息中心 | 账本线、影响金额、原因与行动完整；仅有两条提醒时每项高度与下方留白过大。 | 可缩短消息条目最小高度，使用更紧凑的可变内容布局。 |
| 订单表单 | 表单组块清晰；空 SKU 区块的加号与“添加 SKU”分居两侧，缺少前置说明。 | 应在无 SKU/无明细状态显示具体后续路径。 |
| 商品成本表单 | 材料清单、材料项、其他成本和固定保存按钮形成清楚步骤，但嵌套卡片较多。 | 可压缩材料项内边距，保留分组不必删除。 |
