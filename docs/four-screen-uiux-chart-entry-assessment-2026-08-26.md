# 四页参考 UI/UX、图表与功能入口改造评估报告

**评估对象：**用户提供的首页、成本分析、商品、我的四张移动端参考图，以及当前“算得清”同名页面的 390px 实际渲染。  
**结论：**可以按参考图的**视觉语言、信息层级、卡片节奏、图表组合和入口位置**进行主题化升级；不应像素级复制其示例数据、会员文案、餐饮商品图片、经营天数或不存在的功能。当前项目已经拥有账本、订单/SKU、成本卡、预算、成本诊断、主题与资料等真实能力，因此建议采用“**参考结构 + 真实数据 + 现有业务入口**”的方式实施。

> 目标不是把四张示例图覆盖到项目上，而是让用户在 3 秒内看懂“今天/本期经营如何、成本在哪里、商品是否赚钱、下一步应做什么”。

## 一、可复刻范围与不可照搬边界

| 层次 | 可以主题化复刻 | 必须保留/不能照搬 |
|---|---|---|
| 视觉 | 冷白/雾蓝背景、品牌蓝渐变主卡、圆角白色承载面、细实线分隔、蓝/青/橙语义点缀、底部四宫格导航的节奏。 | 不复制参考图的原始 Logo、会员品牌、插画、人像或餐饮图片；不把用户提供的参考经营数字当作真实数据。 |
| 首页 | 顶部店铺身份、日期选择、单张经营主卡、三项轻指标、单张关键趋势、快捷入口和最近动态。 | 现有五行业模板继续决定实体称谓、分类、单位和洞察；没有客户/会员数据时不展示“新增会员”。 |
| 成本分析 | 月/周/日颗粒度、成本主卡、收入/成本双趋势、环形成本构成、三项成本效率指标、成本洞察。 | 不改变现有正向成本分母、回冲、净成本、订单日口径、供应商关联或本期/上期比较规则。 |
| 商品 | 顶部搜索、简洁汇总、分类筛选、图片 + 商品名 + 售价/成本/毛利率的紧凑列表。 | 商品图片只使用用户上传或已有预置资产；缺少售价/销量/成本时必须显示真实空态，不能补造利润排行。 |
| 我的 | 店铺身份卡、统计三格、设置列表、资料/分类/导出/帮助入口和数据同步状态。 | 会员权益仅在真实计费/订阅能力启用后出现；“数据备份”不能在只提供 CSV/XLSX 导出时替代真正备份。 |

## 二、总体 UI/UX 方案：把当前五页结构收束为四个产品主题

当前项目底部包含“经营、订单、商品、分析、我的”五个真实业务入口。参考图是四个入口，因此**不建议删除订单账本**。应将“经营”改名为“首页”，并把订单保持为经营页内的重要快捷入口或继续保留底栏第五项。第一阶段建议保留五项底栏，视觉上采用参考图的等距图标 + 短文字节奏，避免为了对齐参考图而牺牲订单与退款的高频路径。

| 一级页 | 新主题名称 | 核心问题 | 首屏唯一主操作 |
|---|---|---|---|
| 经营 | **首页** | 今天/本期经营是否健康？ | 记一笔 |
| 订单 | **订单** | 哪些订单低利润或受退款影响？ | 记录订单 |
| 商品 | **商品** | 哪些商品正在卖、赚钱或缺少成本？ | 添加商品 |
| 分析 | **成本分析** | 钱花到哪里、为什么变化、先核对什么？ | 核对最大驱动项 |
| 我的 | **我的** | 店铺与账户如何管理？ | 编辑资料/店铺设置 |

### 统一视觉令牌

| 维度 | 方案 | 用途 |
|---|---|---|
| 页面背景 | `#F6F9FE` 冷白带轻雾蓝；深色模式沿用深海军蓝表面。 | 保留移动端清爽层次，不使用大面积装饰纹理。 |
| 主操作蓝 | 使用当前品牌蓝作为主要 CTA、激活态、图表主序列与指标强调。 | “记一笔”、主要趋势、当前期间。 |
| 辅助语义色 | 青色用于健康/效率，橙色用于关注，红色用于风险；同一语义跨四页一致。 | 成本下降、预算超支、低毛利、退款风险。 |
| 容器 | 主卡 18–20px 圆角、普通卡 16px、弱边框或阴影二选一。 | 主经营卡、趋势/结构卡、设置列表。 |
| 字体 | 页面标题 24–26px；模块标题 17–18px；指标数值 22–32px；辅助文字 12–13px。 | 避免当前不同模块的标题和输入高度不一致。 |
| 表单 | 输入、筛选、搜索、分段控件统一 46–48px 高度，边框/聚焦环/禁用态统一。 | 商品搜索、成本筛选、预算、记一笔。 |
| 动效 | 只保留 160–240ms 的透明度/位移进入、数值轻量更新、图表一次绘制；尊重降低动态效果。 | 不使用反复缩放或循环重绘，避免趋势图屏闪。 |

## 三、逐页改造方案

### A. 首页：经营总览，而不是模块堆叠

参考首页的可取之处是一个明确的主线：**身份 → 今日/本期经营结果 → 三个补充指标 → 一张趋势图 → 常用操作 → 最近动态**。当前首页已有经营主卡、月销售目标、经营提醒、宣传轮播、趋势、SKU 排行与快捷入口，但信息段过多，空态时纵向距离也偏大。

#### 建议的信息架构

```text
店铺身份 + 通知
日期/期间选择
本期经营主卡：净营收 | 经营利润 | 利润率
三项经营补充：订单数 | 客单价 | 退款影响（仅有数据时）
本期经营趋势：销售额 + 订单数（现有真实双轴数据）
快捷操作：记一笔 | 新增商品 | 记录订单 | 成本分析
最近动态：真实流水/订单/提醒（最多 3 条）
更多内容：宣传轮播、销售目标、SKU 双排行（按用户操作展开或下移）
```

| 参考元素 | 现有真实来源 | 设计处理 | 入口映射 |
|---|---|---|---|
| 今日经营概览蓝卡 | `totals.revenue`、`operatingProfit`、利润率 | 保留蓝色主卡，但以当前期间替代“今日”；用实际环比/预算风险替代静态装饰文案。 | 点击经营利润进入成本诊断。 |
| 订单数/客单价/新增会员 | 订单数、客单价已存在；会员数据未建立。 | 前两项直接显示；第三项改为“退款影响”或“待补成本 SKU”，无数据则不占位。 | 分别进入订单、订单、商品。 |
| 近 7 日毛利趋势 | 现有销售订单和成本趋势。 | 用真实 7 日经营利润或销售额/订单双趋势，不创造日利润。 | 进入分析的趋势与风险。 |
| 快捷操作 | 当前有商品成本、采购分析、订单管理、经营报告等入口。 | 收束为四项最高频，使用统一图标底板。 | 记一笔、添加商品、记录订单、成本分析。 |
| 最近动态 | 流水、订单、通知。 | 只显示真实最近 3 条，单击进入详情。 | 流水详情/订单详情/消息中心。 |

#### 首页需要避免的改动

不建议在首页复制“会员”“日经营额”或“连续经营天数”，因为当前没有以这些指标为基础的真实数据。宣传轮播仍可保留，但从主视觉的位置下移为“产品功能/活动”卡，以免稀释经营主线。

### B. 成本分析：复刻图表组合，而不是复刻数值

成本分析页最适合作为参考图的主要承载页。当前已经具备成本诊断、成本饼图、分组对比柱、趋势风险、供应商归属。升级重点应是将它们排列为“**经营背景 → 成本趋势 → 成本构成 → 成本效率 → 成本判断**”，而不是继续增加列表。

#### 建议的信息架构

```text
成本分析 + 期间/筛选
日 / 周 / 月 / 季颗粒度（仅切换现有可计算期间）
成本经营卡：本期收入 | 总成本 | 经营利润 | 利润率
收入与成本趋势：真实日期区间 + 统一 Tooltip
成本构成：环形图 + 前 4/5 分类列表 + 查看全部
成本效率：客单成本 | 单品均成本 | 保本销量/盈亏平衡（有真实来源才显示）
成本变化：本期/上期分组柱 + pt 变化（默认 3 项）
成本洞察：最大成本驱动 + 真实变化/风险 + 去核对
供应商归属：前三或压缩空态
```

| 参考图表/模块 | 当前系统基础 | 复刻方式 | 业务保护 |
|---|---|---|---|
| 收入/成本双线趋势 | 销售订单趋势与成本趋势，均已有真实聚合。 | 两条 3px 平滑曲线，轻面积填充，统一 30 日/本期范围；突出末值、峰值和当前 Tooltip。 | 不将退款倒灌销售日期；不混淆现金流与应计成本。 |
| 成本构成环图 | 已有正向成本饼图、最大分类、分类数和下钻。 | 从饼形升级为中心总额的环形图；右侧/下方展示前 4 分类的名称、金额、占比与箭头。 | 分母仍是正向成本；回冲仍与净成本区别展示。 |
| 三项成本效率卡 | 订单、SKU、定价已有部分真实数据。 | 只有当分母存在时显示：客单成本、平均单品成本、保本销量/价格带；没有数据时以单一“补充订单/SKU 成本”行动卡替代。 | 不推算没有订单或 SKU 成本支持的指标。 |
| 商品利润排行 | 已有 `skuRankings.profit`。 | 从首页/商品页复用真实 Top 3，展示缩略图、名称、真实利润率或单位贡献。 | 无真实订单时展示空态，不伪造菜品排行。 |
| 成本洞察 | 已有最大驱动、预算、行业潜在漏损、供应商关联。 | 只显示一条最高优先级洞察和一个行动；多个问题进入“查看全部”。 | 文案须有对应真实条件，不生成“连续下降”等未计算结论。 |

#### 图表复刻标准

| 图表 | 视觉规则 | 交互规则 |
|---|---|---|
| 双线趋势 | 主线品牌蓝、成本线青绿、透明面积填充不超过 16%、必要时只留首尾日期。 | 点击/悬停/键盘聚焦显示统一 Tooltip；不在数据切换时重新播放无限动画。 |
| 环形图 | 中心显示“正向成本”金额；扇区最多五项，其他合并但标注“其他 N 类”。 | 点击图例行或“查看全部”筛选至真实流水。 |
| 分组柱 | 本期蓝、上期橙，分类两行以内；默认变化最大的三项。 | 点击分类进入对应当前期间流水；无上期时呈零基线且明确“暂无上期”。 |
| 排行进度条 | 仅用于 SKU 利润率或销量，不再用于成本结构以免与环图重复。 | 行项目进入 SKU 详情。 |

### C. 商品：成为“可经营的商品目录”

当前商品页面更接近 SKU 成本编辑页，和参考图的“商品列表”差距最大。可复刻的核心是把每一个 SKU 收束为**图片、名称、分类、售价、成本、毛利率**六要素，并提供搜索/筛选和显式新增入口。

| 区块 | 建议 | 现有功能映射 | 数据缺口处理 |
|---|---|---|---|
| 顶部 | 标题“商品”，搜索和新增两个图标按钮；更多菜单收纳批量/排序。 | `goSub("skus")`、成本卡/SKU 编辑、既有搜索。 | 保持已有返回栈与无障碍名称。 |
| 汇总条 | “N 个商品” + “平均毛利率”，在有真实可售商品时显示。 | SKU 列表和可计算毛利。 | 不可计算时显示“待补售价/成本”的数量而非 0%。 |
| 分类 | 全部 + 真实 SKU 分类，横向滚动 pills。 | 商品分类和成本卡分类。 | 不新增虚构的主食/饮品分类。 |
| 列表 | 图片 72–84px，右侧有价格三列与利润条；一屏至少显示 2–3 项。 | 商品图片、成本卡、售价/成本/毛利。 | 无图片使用品牌色初始图标，不使用网络餐饮图。 |
| 悬浮新增 | 右下角圆形 “+”，与全局记一笔分层规则一致。 | 新增 SKU 或成本卡。 | 录入类型由行业模板决定。 |

对于“商品利润排行”，建议在商品页置顶一个可切换的“利润 / 销量”小榜单，而不是让其在首页、成本分析和商品页三处重复。

### D. 我的：店铺与账户控制中心，不预支会员能力

参考“我的”页的结构容易复制，但“算得清 Pro”和会员有效期不可直接上线，因为当前没有订阅、支付或权益系统。应保留其层级方法，替换为真实的工作区、店铺资料、分类、预算、导出、主题和安全设置。

| 参考元素 | 建议替换 | 真实入口 |
|---|---|---|
| 头像 + 店铺身份 | 当前账号、头像、店铺名称、行业与工作区状态。 | 个人与店铺资料、头像、店铺品牌。 |
| Pro 会员卡 | **经营工具卡**：本期预算状态或“补齐成本卡，获得定价建议”。 | 预算管理/成本卡；不显示订阅文案。 |
| 三项数据 | 商品数、本月记录数、已记录经营月数；只显示可真实计算的项目。 | SKU/流水/工作区时间。 |
| 店铺设置/成本科目 | 保留“个人与店铺资料”“经营行业”“经营预算”“分类管理”。 | 已有二级页。 |
| 数据备份/导出 | 更名为“数据导出”，直达 CSV/XLSX；只有真正的远端备份/恢复存在时才新增“数据备份”。 | 已有导出能力。 |
| 帮助与反馈 | 保留为帮助、反馈、隐私与账号安全。 | 需后续接入反馈入口与双验证码安全页。 |
| 同步状态 | 仅在工作区同步确有状态来源时显示，例如“已同步于 HH:mm”。 | 不能静态写“数据已安全同步”。 |

## 五、建议实施分期

| 阶段 | 范围 | 预期页面 | 不碰的边界 |
|---:|---|---|---|
| P0-A | 统一页面令牌、头部、底部导航、卡片与表单；首页模块重排。 | 首页、我的基础层。 | 不改账本/订单数据与路由语义。 |
| P0-B | 成本分析采用“经营背景—双线趋势—环形构成—效率—洞察”的主题布局。 | 成本分析。 | 不改成本口径、回冲、分析期间、供应商与分类下钻。 |

## 六、验收标准

| 范畴 | 验收问题 |
|---|---|
| 第一眼 | 用户能否在 3 秒内辨识当前页主题、唯一主操作与最重要的业务结果？ |
| 图表 | 双线趋势、环图、分组柱和排行榜是否各自只回答一个问题，且所有数字都来自当前真实聚合？ |
| 入口 | 每个一级页是否有一条明确主操作，且不通过参考图虚构不存在的会员、客户或同步功能？ |
| 真实边界 | 无订单、无 SKU、无上期、无供应商、无图片时是否显示诚实空态而非示例数据？ |
| 移动端 | 在 375、390、430px 下，是否无截断、可点击区域至少 44px、底栏和悬浮操作不互相遮挡？ |
| 宽屏 | 在 768 和 1280px 下，是否通过双列/列对齐提高信息密度，而不是仅放大手机卡片？ |
