# 算得清模块排版布局专项审查报告

## 总结

当前模块排版在 375px、390px 与 430px 三档移动端宽度下均无横向溢出，核心金额、固定保存操作、底部导航和表单输入均能完整显示。首页、流水与商品成本卡的排版成熟度最高：前者拥有清楚的阅读顺序，后两者具备可靠的金额列对齐与高密度列表节奏。

主要问题集中在**数据不足时仍保留大画布的图表、空状态后的无效留白、风险色占据过大面积，以及短内容模块套用过高最小高度**。这些问题不影响功能，却会让部分二级页从“经营工具”退化为“卡片拼贴”。建议先完成 P1 的布局收口，再继续统一跨页账本组件。

## 跨视口结论

| 检查项 | 375px | 390px | 430px | 结论 |
|---|---|---|---|---|
| 首页核算卡与 Banner | 无裁切；风险行动在窄屏正确优先保留原因文本。 | 主线清晰。 | 信息列更舒展但未失焦。 | 通过。 |
| 商品成本卡三列 KPI | 三列未换行，趋势标签可读。 | 操作行稳定。 | 列间留白合理。 | 通过；可略缩短微趋势区。 |
| 流水列表 | 金额、分类和箭头不冲突。 | 日期组与结果数清晰。 | 列宽稳定。 | 通过。 |
| 图表与预算 | 无裁切，但稀疏数据时留白偏大。 | 状态清楚。 | 环形图仍偏大。 | 需要收口。 |
| 表单 | 输入、选择与固定保存按钮不遮挡。 | 表单段落节奏稳定。 | 宽度利用良好。 | 通过；前置空状态和嵌套层级可优化。 |
| 管理与消息 | 无横向问题。 | 内容偏稀。 | 下半屏空白更明显。 | 需要内容/高度策略。 |

## P0：阻断性布局问题

当前未发现会造成内容裁切、横向溢出、无法点击保存、固定按钮被导航遮挡或关键金额不可读的布局问题。因此本轮**没有 P0 排版阻断项**。

## P1：建议下一轮实施

| 编号 | 模块 | 问题 | 具体改造建议 | 预期结果 |
|---|---|---|---|---|
| L-01 | 分析趋势卡 | 近 6 月数据只有最后一项显著时，约 200px 图表画布中出现大量低信息区域。 | 为趋势数据计算非零点数；当有效点小于 3 时给 `.trend-chart` 增加 `sparse` 类，降至 132–150px，并将“本期成本 / 环比”摘要置于图表上方。 | 把首屏空间从装饰画布让给经营判断。 |
| L-02 | 成本排行 | 排行行右侧“新发生”竖排占用数值列，视线被重复红字打断。 | 将状态收束为金额下方的单行 `较上月新增` 标签，或只在变化超过阈值时显示红色点/短标签；金额保持统一右对齐。 | 保留状态信号，恢复财务列可扫读性。 |
| L-03 | 预算管理 | 橙色环图面积大于品牌蓝结构，风险色成为页面主色；圆环高度占首屏比例过高。 | 将环图外环基础改为 Digital Blue，橙色仅绘制超支预测弧段；圆环从 246px 收束到 208–218px；把“月末预计超预算”移为圆环下单行风险注记。 | 预算页恢复“核算结构优先、风险色辅助”的层级。 |
| L-04 | 订单空状态 | 空状态、售后区和固定新增按钮之间留白过长，重复入口进一步放大空白。 | 空状态高度压缩 20–28px；售后区与空态之间使用账本虚线分隔；列表为空时隐藏顶部加号，只保留底部主按钮。 | 首次录单路径更集中，页面不显空。 |
| L-05 | 个人中心 | 店铺资料和五行管理入口结束后有大面积空白，页面像设置导航而非经营维护页。 | 在 `profile-card` 后添加一条固定高度的“本期待处理”行（只显示最高优先风险）；无风险时显示“预算与订单已核对”的结果行。 | 用一条可行动内容填补空区并提升任务感。 |
| L-06 | 消息中心 | 两条短提醒仍使用约 108px 高条目，底部造成较大视觉断层。 | 将 `.notification-list > button` 的 `min-height` 改为内容驱动，设为 82px 基准；说明行仅在必要时占第二行。 | 提高提醒密度，保持“结果 → 原因 → 行动”。 |
| L-07 | 订单表单 | 无 SKU 明细时仅显示左右分离的“＋ / 添加 SKU”，任务语义不足。 | 空明细改为一个 72px 的账本提示区：`尚未添加商品 → 选择 SKU 与数量 → 订单将同步收入、成本和佣金`，再放置单一“添加 SKU”按钮。 | 降低首次填写的理解成本。 |

## P2：后续统一收口

| 编号 | 模块 | 建议 |
|---|---|---|
| L-08 | 商品成本卡 | 六期微趋势在单卡中占比略高；当所有成本变化很小时，将图表压缩到 72px，并只突出当前月与变化节点。 |
| L-09 | 商品成本表单 | 基础材料项的卡片嵌套较深；减少一层描边和内边距，使用虚线分隔材料项，不改变字段分组。 |
| L-10 | 管理页与列表 | 提取 `ledger-summary-row`、`ledger-empty-state`、`ledger-form-section`，统一最小高度、页签、虚线、金融数字对齐和空状态密度。 |
| L-11 | 首屏标题体系 | “订单”“商品成本”“经营分析”“预算管理”等标题的字号和上边距存在轻微差异；以 28px 一级标题、16px 模块标题、12px账本标签建立跨页层级令牌。 |

## 应保留的布局资产

首页的“行业印章 → 核算结论 → 3D Banner → 成本趋势 → 两条下钻”的节奏不建议改动。流水页的筛选、搜索、结果数、日期分组和右对齐金额应作为列表参考。商品成本卡的三列 KPI 与双操作行也值得保留；优化重点只是降低微趋势在非关键场景下的垂直占比。

## 建议实施批次

第一批建议实施 L-01 至 L-07；均为前端结构或 CSS 排版调整，不改动账本计算口径。第二批实施 L-08 至 L-11，完成跨页令牌和账本行组件收口。实现后应至少在 375px、390px、430px 再次复核首页、订单空状态、分析、预算、消息、个人中心与两类表单。
