# 首页优化设计参考记录

来源：用户于 2026-08-22 提供的“算得清 · 首页优化设计方案”设计图。

## 必须保留的约束

- 首页以经营结果和可行动异常为主线，数据与图表优先于说明文字。
- 使用干净白底、蓝色经营主卡、轻阴影分组卡、16px 圆角和克制蓝色操作色；不使用网格背景或虚线分隔作为页面装饰。
- 保留既有产品宣传轮播图，但将其作为独立次级模块，不挤占经营结果、目标和提醒路径。
- 首页改造必须同步统一订单、商品、分析、我的页面的背景、卡片、圆角、间距、图标、标题和底部导航语言。
- 所有金额、趋势、目标、提醒和下钻继续使用真实账本数据；数据不足时展示行动型空状态，不补造数据。

## 参考模块顺序

| 顺序 | 参考模块 | 对应实现原则 |
|---|---|---|
| 1 | 顶部信息区 | 店铺名、行业、当前账期、日期/提醒入口；保持移动端单手点击。 |
| 2 | 核心经营结果卡 | 蓝色主卡突出经营利润，清晰展示净营收 − 总成本 ＝ 经营利润、成本率、利润率和较上月变化；保留真实趋势图。 |
| 3 | 经营目标进度 | 环形完成率、已完成、目标差额、进度条与下一步行动。 |
| 4 | 经营提醒 | 异常/风险/机会按色彩和图标分级，包含原因摘要和具体下钻入口。 |
| 5 | 经营分析趋势 | 营收和成本的双卡趋势预览，点击进入对应分析或流水路径。 |
| 6 | 快捷入口 | 商品成本、采购分析、订单管理、经营报告及更多功能，使用统一图标和标签。 |
| 7 | 产品宣传轮播 | 现有 3D 产品轮播保留在首页下段，继续只承担功能宣传和广告承载。 |
