# 层级与模块布局合并优化：实施验收

## 已落地改造

所有“订单”目的地现在通过 `openOrdersContext()` 进入一级订单 Tab。Banner、消息中心与首页经营风险会保留低利润或退款筛选，同时恢复底部五级导航；同一业务目的不再落入不同层级。供应商与分类删除均增加确认提示，并说明历史账本记录不会被删除。

订单页在空数据状态下移除重复的顶部新增入口，保留单一底部主操作并增加账本公式提示。无 SKU 时，从订单入口直接引导至成本卡；异常深链进入订单表单时，如果已有 SKU 会自动建立首条草稿明细，如果没有 SKU 则展示“成本卡 → SKU → 订单”的前置路径。

分析页针对稀疏月份数据压缩趋势画布并补充数据解释，成本排行将“新发生/环比”收束为紧凑状态标签。预算页将主环恢复为蓝色核算结构，橙色只表达预测风险线与单条风险注记。个人中心以首页的最高优先风险生成“本期待处理”行；消息中心、材料表单与商品微趋势同步压缩非关键高度，并以账本虚线、轻网格、等宽金额保持跨页一致。
