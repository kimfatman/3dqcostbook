### R2：字号层级混乱，缺少统一 Type Scale
**严重度：P0**

当前字号从 8px 到 46px，但中间层级不连续，同一语义层级使用不同字号：

| 语义层级 | 当前使用字号 | 问题 |
|---|---|---|
| 页面大标题 h1 | 20px/25px/28px/30px/31px | 5种不同字号，不统一 |
| 卡片标题 h2 | 14px/15px/16px/17px/18px | 5种不同字号 |
| 正文/列表标题 | 11px/12px/13px/14px | 4种不同字号 |
| 辅助文字/副标题 | 8px/9px/10px/11px | 4种不同字号，含极端小 |
| 标签/KICKER | 9px/10px/11px | 3种不同字号 |
| 金额数字 | 13px/14px/15px/22px/25px/27px/29px/33px | 8种不同字号 |

**问题：**
1. 没有统一的字号阶梯（Type Scale），开发者随意选择字号
2. 同一语义层级视觉权重不一致，用户无法通过字号判断信息重要性
3. 金额数字字号混乱，缺少"大/中/小"三档规范

**优化方案：建立 8 级 Type Scale**

| 级别 | 字号 | 行高 | 字距 | 用途 |
|---|---|---|---|---|
| Display | 32px | 1.15 | -0.02em | 登录页大标题/hero金额 |
| H1 | 28px | 1.2 | -0.02em | 页面主标题 |
| H2 | 20px | 1.3 | -0.01em | 卡片标题/分组标题 |
| H3 | 16px | 1.4 | 0 | 子标题/重要正文 |
| Body | 14px | 1.5 | 0 | 正文/列表标题/按钮 |
| Caption | 12px | 1.5 | 0 | 辅助文字/表单标签/副标题 |
| Micro | 11px | 1.45 | 0.02em | 标签/KICKER/时间戳 |
| Chart | 10px | 1.4 | 0 | 图表图例/坐标轴（仅限图表） |

**禁用字号**：8px、9px（全部提升到 10px+）

### R3：80%+ 文字无行高，小字号+低行高=阅读困难
**严重度：P0**

当前 80%+ 的文字没有设置 line-height，使用浏览器默认 1.2。对于小字号（9px/10px/11px），1.2 行高导致行间距过窄，文字拥挤，阅读困难。

**典型问题场景：**
- 列表副标题 9px + 默认行高 1.2 = 行间距仅 10.8px
- 行业洞察描述 10px + 行高 1.6 = 行间距 16px（合理）
- 定价推荐描述 10px + 行高 1.55 = 行间距 15.5px（合理）
- 大部分 11px 正文 + 默认行高 1.2 = 行间距仅 13.2px

**Apple Design 违反：** 排版（§16）— 行高应该根据字号调整，小字号需要更大的行高比例。
**ui-ux-pro-max 违反：** Typography（Priority 6）— "Line-height 1.5" 是 base 要求。

**优化方案：**
1. **全局默认行高**：`body { line-height: 1.5; }`
2. **按字号设置行高**：
   - ≥20px 标题：line-height 1.2-1.3
   - 14-16px 正文：line-height 1.5
   - 12px 辅助文字：line-height 1.5
   - 10-11px 标签/图表：line-height 1.45
3. **小字号行高不低于 1.4**：10px/11px 文字必须有 line-height ≥ 1.4

### R4：小字号+Tertiary颜色=对比度严重不足
**严重度：P0**

当前文字颜色三级：
- text-primary: neutral-900（浅色）/ neutral-50（深色）
- text-secondary: neutral-600（浅色）/ neutral-300（深色）
- text-tertiary: neutral-500（浅色）/ neutral-400（深色）

**问题：** 大量 9px/10px 小字号使用 text-tertiary 颜色，对比度严重不足：

| 场景 | 字号 | 颜色 | 预估对比度 | WCAG AA |
|---|---|---|---|---|
| 列表副标题 | 9px | text-tertiary | ~3.5:1 | ❌ 不达标（需4.5:1） |
| KPI标签 | 9px | text-secondary | ~4.0:1 | ❌ 不达标 |
| 图表图例 | 9px | chart-muted | ~3.0:1 | ❌ 不达标 |
| 行业洞察描述 | 10px | text-secondary | ~4.5:1 | ⚠️ 勉强 |
| 底部导航 | 9px | text-tertiary | ~3.5:1 | ❌ 不达标 |
| 头像预设标签 | 9px | text-secondary | ~4.0:1 | ❌ 不达标 |

**ui-ux-pro-max 违反：** Accessibility（Priority 1）— "Contrast 4.5:1" 是必须要求；"Gray-on-gray" 是 anti-pattern。

**优化方案：**
1. **小字号必须用更高对比度颜色**：
   - 9px/10px 文字：必须用 text-primary 或 text-secondary，禁止用 text-tertiary
   - 11px+ 文字：可用 text-secondary，重要内容用 text-primary
   - text-tertiary 仅限 12px+ 装饰性文字（如时间戳、占位符）
2. **图表文字对比度**：chart-muted 颜色调深，确保 10px 文字对比度 ≥ 4.5:1
3. **底部导航**：未选中状态用 text-secondary（不是 text-tertiary），选中用 action-primary

### R5：文字截断无替代，用户无法看到完整内容
**严重度：P1**

大量使用 `white-space: nowrap + text-overflow: ellipsis` 截断文字，但没有提供查看完整内容的替代方式：

| 场景 | 截断方式 | 问题 |
|---|---|---|
| 商品名称 | nowrap + ellipsis | 长商品名被截断，无 tooltip |
| 供应商名称 | nowrap + ellipsis | 长供应商名被截断 |
| 报表名称 | nowrap + ellipsis | 长报表名被截断 |
| 身份卡店铺名 | nowrap + ellipsis | 长店铺名被截断 |
| 列表副标题 | nowrap + ellipsis | 长描述被截断 |
| 品牌迷你名称 | nowrap + ellipsis | 长品牌名被截断 |

**问题：**
1. 用户无法看到被截断的完整内容
2. 没有 `title` 属性提供原生 tooltip
3. 没有点击展开或长按显示完整内容的机制
4. 截断位置不统一，有的在中间有的在末尾

**ui-ux-pro-max 违反：** Accessibility（Priority 1）— 内容必须可访问；截断后用户无法获取完整信息。

**优化方案：**
1. **所有截断文字加 `title` 属性**：提供原生 tooltip，鼠标悬停/长按显示完整内容
2. **重要内容不截断**：商品名称/供应商名称等重要内容允许换行（2行限制），不使用单行截断
3. **次要内容截断+展开**：描述文字截断为2行，点击"展开"显示完整内容
4. **统一截断位置**：末尾截断（ellipsis），不使用中间截断

## 四、数字排版专项审查

### 4.1 数字字体不统一

当前数字字体有三种：
1. `--financial-numeric-font`：IBM Plex Mono（财务数字，等宽）
2. `--chart-numeric`：图表数字（等宽+负字距）
3. 默认字体：Noto Sans SC（部分数字未使用等宽字体）

**问题：**
1. 部分金额数字未使用等宽字体（如列表中的金额）
2. 百分比数字有的用等宽有的不用
3. 日期/时间数字未统一字体

**优化方案：**
1. **所有金额/百分比/数量数字**：必须用 `--financial-numeric-font` + `font-variant-numeric: tabular-nums`
2. **图表数字**：用 `--chart-numeric`
3. **日期/时间**：可用默认字体，但数字部分用 tabular-nums
4. **建立数字字体规范**：金额≥14px用等宽，<14px可用默认但必须tabular-nums

### 4.2 金额数字字号混乱

当前金额数字字号有8种：13px/14px/15px/22px/25px/27px/29px/33px

**优化方案：建立金额数字三档规范**

| 级别 | 字号 | 用途 |
|---|---|---|
| 大金额 | 28-32px | hero卡/详情页主金额 |
| 中金额 | 16-18px | 列表项金额/KPI金额 |
| 小金额 | 13-14px | 辅助金额/对比金额 |

### 4.3 数字对齐问题

- 部分数字右对齐，部分左对齐，不统一
- 列表中的金额应该右对齐，KPI中的金额应该左对齐或居中

**优化方案：**
- 列表/表格中的数字：右对齐
- KPI卡片中的数字：左对齐（与标签对齐）
- 图表中的数字：根据图表类型决定（柱状图顶部居中，折线图数据点上方）

## 五、标题层级专项审查

### 5.1 标题标签使用不规范

| 问题 | 场景 |
|---|---|
| 用 strong/b 代替 h2/h3 | 卡片标题用 strong 而不是 h2 |
| h1 字号不统一 | 页面标题有20px/25px/28px/30px/31px |
| 缺少 h3 层级 | 子标题直接用 p 或 span |
| 标题嵌套错误 | h2 内包含 h3 |

**优化方案：**
1. **页面主标题**：用 `<h1>`，统一 28px
2. **卡片标题**：用 `<h2>`，统一 20px
3. **子标题/分区标题**：用 `<h3>`，统一 16px
4. **正文**：用 `<p>`，统一 14px
5. **辅助文字**：用 `<span>` 或 `<small>`，统一 12px
6. **禁止用 strong/b 代替标题标签**

### 5.2 标题简洁度（与之前打磨批次一致）

标题啰嗦/重复问题已在批次13-17中记录，本报告不重复。

## 七、新增排版规范（Type Scale）

### 7.1 字号阶梯

```css
:root {
  --sdq-type-display: 32px;    /* 登录页大标题/hero金额 */
  --sdq-type-h1: 28px;         /* 页面主标题 */
  --sdq-type-h2: 20px;         /* 卡片标题/分组标题 */
  --sdq-type-h3: 16px;         /* 子标题/重要正文 */
  --sdq-type-body: 14px;       /* 正文/列表标题/按钮 */
  --sdq-type-caption: 12px;    /* 辅助文字/表单标签/副标题 */
  --sdq-type-micro: 11px;      /* 标签/KICKER/时间戳 */
  --sdq-type-chart: 10px;      /* 图表图例/坐标轴（仅限图表） */
}
```

**禁用字号**：8px、9px（全部提升到 10px+）

### 7.2 行高规范

```css
:root {
  --sdq-leading-display: 1.15;
  --sdq-leading-h1: 1.2;
  --sdq-leading-h2: 1.3;
  --sdq-leading-h3: 1.4;
  --sdq-leading-body: 1.5;
  --sdq-leading-caption: 1.5;
  --sdq-leading-micro: 1.45;
  --sdq-leading-chart: 1.4;
}
```

### 7.3 字距规范

```css
:root {
  --sdq-tracking-display: -0.02em;
  --sdq-tracking-h1: -0.02em;
  --sdq-tracking-h2: -0.01em;
  --sdq-tracking-h3: 0;
  --sdq-tracking-body: 0;
  --sdq-tracking-caption: 0;
  --sdq-tracking-micro: 0.02em;
```

### 7.4 颜色使用规范

| 字号 | 允许颜色 | 禁止颜色 |

| 图表 10px | chart-ink / chart-muted | chart-track（过浅） |
