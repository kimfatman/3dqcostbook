# 算得清 Logo DNA UI 重构记录

## 重构目标

本轮以用户确认的 **Logo System Draft** 为唯一品牌母体，而不是继续叠加“蓝图账本”装饰。目标是将店铺、`＋`、`−`、`＝`、笑脸反馈、圆润线条，以及 Digital Blue `#087FF5` 与 Navy `#0B1836` 转译为可理解、可复用的移动端经营体验。

> “不要让用户只看数据；要让用户看懂数据为什么会这样，以及下一步怎么办。”

## 关键设计决策

| 设计原则 | 具体实施 | 影响页面 |
|---|---|---|
| 结果优先 | 工作台和分析页使用“净营收 − 经营成本 ＝ 经营结果”的算式结果组件。 | 经营、分析、成本详情、个人中心 |
| 原因与行动 | 结果下方直接给出第一成本来源、经营判断和可跳转的复核入口。 | 经营、分析 |
| 减少卡片 | 普通列表改为对齐的数据行；仅保留核算结果、明确状态、重要表单与决策模块容器。 | 订单、商品、流水、分析、我的 |
| 色彩纪律 | 数字蓝和深海军蓝承担品牌与主操作；绿色、橙色、红色仅表示盈利、提醒和风险。 | 全部页面 |
| 算式语言 | `＋` 表示新增与成本组成；`−` 表示成本扣除；`＝` 表示核算结论。 | 经营、流水、成本详情、定价、行业模板 |
| 行业模型 | 行业切换直接展示“成本项 ＋ 成本项 ＝ 行业成本模型”，而非只切换标题。 | 我的、行业模板 |
| 导航重定位 | 底部导航改为“经营｜订单｜商品｜分析｜我的”，突出经营结果而非普通记账。 | 一级导航 |

## 已覆盖的专业体验要求

工作台以经营结果取代功能入口优先级；订单空状态使用“记录第一笔订单”的明确行动；流水列表按“收入 ＋ / 成本 −”显示业务口径；商品成本详情呈现“成本构成 ＝ 单位成本”和“售价 − 成本 ＝ 单件利润”；智能定价保留“先算保本，再定售价”的决策顺序，并以账页式分组组织渠道费用、保本价、建议售价与竞品模拟。个人中心增加预算减成本等于可用余额的经营关系，减少纯设置页感。

## 验收结果

在 390px 宽度下复核了经营、订单、商品、分析、我的、流水、成本详情和智能定价。结果显示，五级导航、算式卡、行业化文案、筛选、空状态、固定主操作和长表单均未出现横向溢出或固定操作遮挡。类型检查通过；5 组自动化测试、共 20 项用例通过；生产构建通过。

生产构建保留主包体积提示，属于后续可通过页面级动态加载优化的性能事项，不影响本轮视觉与功能验收。
