# 腾讯云双验证码控制台配置清单

本清单用于为“算得清”启用**邮箱验证码**和**短信验证码**。建议使用用户已备案的域名 `3dq.site`，认证邮件发信地址使用 `noreply@3dq.site`，显示名称使用“算得清”。请在腾讯云控制台完成以下配置；不要在聊天、截图、代码仓库或 DNS 备注中发送访问密钥、验证码或密码。

> 完成后只需要安全回填区域、模板 ID、AppID、签名、发信地址和独立子账号的访问密钥。应用不会保存明文验证码、密码、私有账本或凭证到产品分析事件中。

## 一、腾讯云 SES：认证邮件

| 顺序 | 控制台操作 | 预期结果 |
|---:|---|---|
| 1 | 登录腾讯云控制台，开通 **邮件推送（SES）**。 | 可进入 SES 控制台。 |
| 2 | 进入“邮件配置 → 发信域名”，新建发信域名 `3dq.site`。 | 控制台生成待验证的 DNS 记录。 |
| 3 | 打开 DNSPod，为 `3dq.site` 按 SES 控制台给出的主机记录、记录值和记录类型逐条新增 DNS 记录。 | SES 域名状态变为“已验证”。DNS 记录必须以控制台实际显示内容为准。 |
| 4 | 进入“邮件配置 → 发信地址”，创建 `noreply@3dq.site`；发件人别名填“算得清”。 | 获得已可发信的认证邮件地址。 |
| 5 | 进入“模板管理”，创建一份**事务类验证码邮件模板**。 | 模板审核通过并得到模板 ID。 |
| 6 | 在 SES 控制台发送测试邮件到你可访问的邮箱。 | 邮件可收到，发件人显示“算得清”。 |

建议邮件正文如下；变量名或变量序号请以 SES 模板编辑器的实际提示为准：

```text
主题：算得清验证码

你的算得清验证码是：{{code}}
验证码将在 {{expiresMin}} 分钟后失效，请勿向任何人透露。
如果不是你本人操作，请忽略此邮件。
```

腾讯云 SES 的发送接口支持触发类邮件，默认使用模板发送；创建发信地址必须基于已验证的发信域名。[1] [2]

## 二、腾讯云短信：手机验证码

| 顺序 | 控制台操作 | 预期结果 |
|---:|---|---|
| 1 | 登录腾讯云控制台，开通 **短信（SMS）**。 | 可进入短信控制台。 |
| 2 | 在“应用管理”创建应用，例如“算得清账户验证”。 | 记录 **SMS SDK AppID**。 |
| 3 | 在“签名管理”申请短信签名，建议使用“算得清”；按控制台要求提交主体与产品证明。 | 签名审核通过。 |
| 4 | 在“模板管理”申请验证码模板。 | 模板审核通过并得到模板 ID。 |
| 5 | 使用短信控制台/API Explorer 向自己的手机发送测试短信。 | 可收到短信，验证码与有效期变量正确替换。 |

建议短信模板如下，变量数量应与系统后续传参保持一致：

```text
你的算得清验证码为{1}，{2}分钟内有效，请勿泄露给他人。
```

后续系统将传入两个变量：`验证码` 与 `有效分钟数`。国内短信发送时，腾讯云 `SendSms` 要求使用已审核的模板 ID，并填写已审核的**签名内容**（不是签名 ID）；模板参数数量必须与模板变量数量一致。[3]

## 三、最小权限子账号

不要使用腾讯云主账号密钥，也不要复用现有 COS 私有媒体密钥。请在“访问管理（CAM）→ 用户 → 新建用户”创建一个专用子账号，例如 `costbook-otp-sender`，只勾选“编程访问”。

| 授权对象 | 最小用途 | 建议动作 |
|---|---|---|
| 腾讯云 SES | 发送认证邮件。 | 仅允许 `SendEmail` 及验证运行所需的最小只读动作。 |
| 腾讯云短信 | 发送认证短信。 | 仅允许 `SendSms`。 |
| 其他服务 | 不授权。 | 不授予 COS、数据库、云服务器、费用、用户管理等权限。 |

如果控制台无法精确配置资源级权限，可以先创建只含 SES 发送与短信发送动作的自定义策略；不要直接授予全局管理员权限。创建成功后生成一对新的 `SecretId` 与 `SecretKey`，仅通过项目安全配置卡回填，生成后不要再复制到聊天中。

## 四、完成后需要提供的非敏感配置

完成审核后，请回复“已完成”，并通过安全配置卡填入下表参数；**不要在聊天正文粘贴 SecretId 或 SecretKey**。

| 参数 | 示例格式 | 从哪里获得 |
|---|---|---|
| SES 区域 | `ap-guangzhou` | SES 控制台或 API 文档。 |
| SES 发信地址 | `noreply@3dq.site` | SES 发信地址管理。 |
| SES 模板 ID | 控制台模板 ID | SES 模板管理。 |
| 短信区域 | `ap-guangzhou` | 短信控制台/API 文档。 |
| SMS SDK AppID | 数字字符串 | 短信应用管理。 |
| 短信签名 | `算得清` | 短信签名管理。 |
| 短信模板 ID | 数字字符串 | 短信模板管理。 |
| OTP 子账号密钥 | 安全配置卡填写 | CAM 子账号“访问密钥”。 |

## 五、回填后的验证顺序

项目接入后将按下列顺序验证：邮件测试发送 → 短信测试发送 → 重发冷却 → 失效验证 → 错误次数锁定 → 不存在账号的通用提示 → 密码找回后旧会话失效 → 管理员后台拒绝普通用户。测试环境只允许使用已明确授权的测试邮箱和手机号码。
