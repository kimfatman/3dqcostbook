# 商品销售联动与利润分析实施记录

**实施日期：** 2026-08-27  
**范围：** 记一笔收入分流、经营分析信息架构、利润可视化与精确数据下钻。

## 已实施变更

“记一笔”不再将所有收入视作同一种销售。交易类型现明确区分支出、其他收入、商品销售和手工退款。其中，**商品销售**直接进入既有订单录入：用户选择 SKU、数量、渠道和成交日期后，由统一订单路径写入销售收入、已售成本及渠道费用快照。其他收入仍是独立收入，不生成订单、SKU 销量、客单价、商品利润或销售趋势，因此不会与商品销售重复入账。

分析页已按“利润先于成本”的决策顺序重排。页面先显示本月经营利润、净营收、销售成本和经营费用，再使用既有利润桥展示利润形成，用近六个月的真实月度聚合显示利润趋势，并新增商品毛利排行。商品毛利指当前 SKU 的**净收入减已售成本**；它与扣除经营费用后的经营利润分开呈现，避免混淆两个口径。

## 数据与下钻边界

| 场景 | 采用数据 | 下钻范围 | 不改变的边界 |
| --- | --- | --- | --- |
| 商品销售 | 订单、SKU、成交日、渠道费用模板 | 对应订单与 SKU 相关流水 | 仍使用订单成交日记销售；不写额外手工收入。 |
| 其他收入 | 手工收入流水 | 对应收入流水 | 不计入订单、销量、客单价或 SKU 利润。 |
| 商品毛利 | SKU 净收入与已售成本 | 该 SKU 的销售、成本与退款流水 | 退款仍按退款日处理，不倒灌销售趋势。 |
| 成本结构 | 分类键与当月流水 | 精确分类键过滤 | 不再用分类名称的模糊搜索替代分类筛选。 |
| 供应商排行 | 供应商 ID 与当月支出 | 精确供应商过滤 | 进入时清除渠道、分类和 SKU 遗留筛选。 |
