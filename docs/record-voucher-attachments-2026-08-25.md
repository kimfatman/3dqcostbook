# 流水私有凭证附件实现记录

**实施日期：** 2026-08-25  
**范围：** 流水凭证由旧的布尔状态升级为可上传、私有读取的图片资产；不改变账本金额、聚合口径或历史分录可读性。

## 实现边界

| 层级 | 当前实现 | 约束 |
|---|---|---|
| 流水状态 | `LedgerEntry.attachmentAssetId?` 关联私有媒体资产，`hasAttachment` 继续保留为兼容状态。账本状态升级至 schema 5。 | 无资产 ID 的历史流水仍显示“已附凭证/未附凭证”，不会被强制迁移。 |
| 前端表单 | 支持 JPEG、PNG、WebP 图片选择，大小限制为 5MB；上传后显示紧凑缩略图，可移除或替换；保存时将资产 ID 写入新增/编辑分录。 | 在上传期间禁用保存；若只勾选线下凭证，仍按旧状态路径保存。 |
| 服务端上传 | 复用 `/api/media/upload`，新增 `record_voucher` 类型。请求需登录、工作区成员关系和非 viewer 写权限。 | 原始文件仅进入私有 COS；响应只返回 `/api/media/{assetId}` 受保护读取地址。 |
| 私有读取 | `/api/media/:assetId` 先验证当前用户的工作区成员关系，再以短时签名地址重定向。 | 不提供公开 COS URL，也不在账本 JSON 内写入文件字节。 |
| 数据库 | `media_assets.kind` 枚举新增 `record_voucher`，变更位于 `drizzle/0004_cheerful_nekra.sql`。 | 迁移只扩展枚举，不删除列或数据；已通过受控 SQL 应用。 |

> 凭证文件会在记录保存前上传，以便保存动作能原子地引用已验证的资产 ID。若用户上传后取消表单，资产不会在界面中被关联；它仍是私有对象且没有 UI 引用。当前存储层不提供底层删除接口，因此该情况按既有媒体存储策略处理。

## 验证记录

| 验证 | 结果 |
|---|---|
| 媒体类型与权限 | `record_voucher` 仅允许 JPEG/PNG/WebP、最大 5MB；viewer 被拒绝。 |
| 私有上传路由 | HTTP 回归验证 editor 可在当前工作区的 `record_voucher/{recordId}` 私有路径创建资产，响应只返回受保护读取路由。 |
| 账本兼容 | 归一化回归保留有效 `attachmentAssetId`、丢弃无效遗留值，并继续支持仅有 `hasAttachment` 的历史流水。 |
| 真实页面路径 | Home DOM 回归 mock 受保护上传成功与失败：验证文件选择后预览、移除、保存后的 `attachmentAssetId` 关联、详情受保护预览入口，以及服务端错误提示；同时保留“线下凭证（仅标记）”历史操作路径。 |
| 移动布局 | 390px 截图确认凭证选择区、格式/大小说明、线下兼容勾选和保存操作均可见且未挤占收支表单。 |
| 质量门禁 | `pnpm check`、43 个测试文件共 154 项测试、`pnpm build` 均通过。构建仅保留既有主 JavaScript chunk 大于 500 kB 的提示。 |

## 仍需生产会话验证

当前浏览器会话没有可用的生产登录态，本记录不把本地 DOM/HTTP 回归替代为真实账户验收。已保留的生产待办包括：上传实际照片、刷新后在同一工作区查看凭证、非成员访问拒绝、编辑替换/移除后的账本保存行为，以及移动设备文件选择器在真实浏览器中的可用性。
