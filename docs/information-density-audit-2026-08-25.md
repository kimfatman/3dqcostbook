# 全站信息密度审阅

本轮仅调整展示层文案与层级，不改动账本、成本分摊、订单、退款、定价或金额计算。审阅范围覆盖首页、订单、商品、成本分析、我的，以及经营流水和关键二级表单。

| 页面/区域 | 发现的重复信息 | 收敛方式 | 保留边界 |
|---|---|---|---|
| 首页 | 行业与月份已在上下文呈现，额外“本期账本实时更新”不提供新的操作或判断。 | 移除泛化状态短语，将空间留给经营结果与提醒。 | 保留行业、月份、提醒入口和所有经营指标。 |
| 订单空态 | 公式式标语与“还没有订单”及引导按钮重复表达“需要先记录订单”。 | 移除装饰性公式，只保留状态、最短引导和主操作。 | 保留收入、成本、利润的业务说明。 |
| 商品成本 | 副标题“清晰管理商品成本变化，提升单件利润”与页面标题语义重复。 | 移除泛化副标题，保留搜索、筛选、商品核心三指标。 | 不移除 SKU、单位成本、售价或单件利润。 |
| 成本分析 | 页面副标题与“本期成本结论”重复提示先看结论。 | 仅保留页面标题、期间和结果卡内的具体指标。 | 保留本期/上期切换、排行、结构与下钻入口。 |
| 经营流水导出 | 结果汇总与导出面板重复展示筛选后的笔数。 | 导出面板改为“当前筛选”语义，不重复数值。 | 保留结果汇总数字、格式选择和筛选范围说明。 |
| 我的/二级表单 | 账户、身份与历史口径说明包含业务边界，非单纯重复。 | 统一限制普通二级页辅助说明的行数与密度，不删会影响理解或安全的口径。 | 保留登录状态、上传限制、历史订单快照、退款/分摊等重要说明。 |

## 全站规则

每个屏幕只保留一个主标题、一个结果主指标和一行以内的泛化辅助信息。数字一旦已在结果区表达，就不在相邻装饰性标签中重复；但会改变用户操作、数据口径或历史数据边界的说明必须保留。普通二级页的辅助说明最多显示两行，避免长段说明挤占表单和结果空间。

## 实施与验证

首页经营主卡由“核心经营结果 / 本月实时核算 / 本月经营利润”收敛为“本期经营 / 本月经营利润”，行业风险继续保留在金额下方；目标未设状态去除“当前状态 / 未设目标”同义字段，只保留真实运行率和设置入口。商品页去除泛化副标题，成本分析去除与首张结论卡重复的引导句，经营流水导出区不再重复筛选笔数。订单空态移除了公式式装饰伪元素，只保留状态、短引导和主操作。

统一样式层将普通二级页辅助说明限制为两行，并以一行紧凑呈现导出筛选说明；用户理解退款、历史快照、分摊、定价及上传限制所需的口径说明均未删除。新增真实 Home DOM 回归断言首页、商品和成本分析的重复标签不存在且主标题、设置入口、搜索和成本结论仍可访问。

| 验证项 | 结果 |

| 375px、390px | 首页、订单、商品、分析、我的的主标题、指标、筛选和主操作均无裁切；订单空态不再出现公式式装饰。 |
| 768px | 五个一级页保持紧凑的结果优先结构，不因辅助文字减少产生空白断层。 |
