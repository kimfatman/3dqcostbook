# 金额精度与价格计算审计

## 统一规则

所有业务金额以**分**为持久化与聚合的最小单位，进入页面、成本卡、订单、退款、预算、报表和 CSV/XLSX 导出时均按两位小数表达。智能定价的建议售价和保本价直接保留两位小数，已移除渠道价格模板中的“按 ¥0.1 / ¥0.5 / ¥1 / ¥5 向上取整”配置与界面。

| 链路 | 修复前 | 修复后 |
|---|---|---|
| 智能定价 | 可按商业步长向上取整，可能改变原始测算售价。 | 直接保留两位小数；原始测算价与写入售价一致。 |
| 费用模板 | 存储 `roundingStep` 并影响后续建议售价。 | 仅保存渠道费率、单件履约费、目标贡献毛利率。 |
| 页面金额展示 | 首页和紧凑金额展示会格式化为整数。 | 所有金额显示两位小数，负数仍以 `-¥` 前缀显示。 |
| 预算输入 | 仅允许整数步长。 | 改为 `0.01` 步长，按分保存。 |
| 订单与退款 | 金额已按分保存，但定价模板仍带取整字段。 | 订单、退款、佣金与履约费用继续按分计算，取整字段已移除。 |
| 间接成本池 | 非末项总是向下取整到分。 | 按最近分分配、末项承接余额，保证总额精确守恒且不系统性向下偏移。 |

## 两位小数与分配余额

“不向上或向下取整”在本次实现中指不再为商业定价把价格强制抬高或压低至某个固定步长。由于人民币分是最小可记录单位，公式结果若产生更小尾差，会按**最近分**表达；成本池最后一项接收剩余分，确保多项目分摊总额等于原始成本池金额，不产生丢分或多分。
