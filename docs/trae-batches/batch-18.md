## 执行步骤

### 步骤1：账号卡打磨
- 布局：左头像（64×64 圆角 16px）/ 中（姓名+邮箱+会员等级）/ 右（编辑按钮）
- 姓名：18px -0.01em text-primary
- 邮箱：13px text-secondary，1 行截断
- 会员等级：标签样式（12px，bg-brand-soft text-primary，圆角 6px）
- 背景：浅色渐变（bg-brand-soft 到 transparent），不使用深色卡
- 点击：跳转到个人资料编辑页
- :active：scale(0.98)

### 步骤2：店铺管理
- 位置：账号卡下方，独立卡片
- 当前店铺：店铺名 + 行业 + 角色（店主/员工），右侧"切换"按钮
- 店铺列表：点击"切换"展开店铺列表，每项可点击切换
- 添加店铺：底部"+ 添加店铺"按钮，ghost 样式
- 店铺头像：40×40 圆角 10px，无图时显示预设图标

### 步骤3：设置项分组
- 分组1：账户设置（个人资料/修改密码/绑定手机/绑定邮箱）
- 分组2：店铺设置（店铺信息/行业模板/员工管理/通知设置）
- 分组3：通用设置（皮肤中心/语言/缓存清理/关于我们）
- 分组4：其他（帮助中心/意见反馈/用户协议/隐私政策）
- 每个分组有分组标题（14px text-secondary，左图标）
- 每项设置：左图标 + 文字 + 右箭头，14px text-primary
- 分割线：1px border-subtle，左对齐 16px，最后一项无

### 步骤4：退出登录按钮
- 位置：页面底部，独立区域
- 样式：full width 按钮，danger outline（边框 risk，文字 risk，背景透明）
- 高度 44px，圆角 12px
- 点击：二次确认模态框（"确定退出登录吗？"，取消/确定）
- 不使用突兀的红色实心大按钮，改为温和的 danger outline

### 步骤5：会员权益展示
- 位置：账号卡下方或店铺管理上方
- 卡片：当前会员等级 + 到期时间 + 核心权益（3 项）
- 升级按钮：primary 小按钮，"升级会员"
- 权益图标：3 个图标 + 文字（如"库存盘点/PDF导出/多店铺"）
- 免费用户：显示"免费版"，升级按钮突出
- 付费用户：显示会员等级和到期时间，"管理订阅"按钮

### 步骤6：帮助中心入口
- 位置：通用设置分组中
- 项：左图标（问号圆圈）+ "帮助中心" + 右箭头
- 点击：打开帮助中心页面（或外部链接）
- 常见问题：帮助中心页顶部展示 5 个常见问题（可折叠）
- 联系客服：帮助中心页底部"联系客服"按钮

## 常见问题与回退
- **问题：** 设置项过多导致页面过长
  **解决：** 合理分组，次要设置（如语言/缓存）放在"通用设置"折叠中
- **问题：** 会员权益数据缺失
  **解决：** 免费用户显示默认权益，付费用户从接口获取，无数据时显示骨架屏
- **回退：** `git revert` 本批次提交
