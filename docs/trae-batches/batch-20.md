## 执行步骤

### 步骤1：创建通用折叠组件
创建 `client/src/components/Collapsible.tsx`：
- Props：title / defaultOpen / icon / children / badge
- 样式：分组标题（14px -0.01em text-secondary，左侧图标，右侧箭头）
- 动画：grid-template-rows 0fr→1fr（320ms standard），内容淡入延迟 50ms
- 箭头：rotate 180deg（180ms fast），与内容展开同步
- 可访问：aria-expanded / aria-controls，键盘 Enter/Space 切换

### 步骤2：洞察页折叠重构（重点）
- **拆分两层嵌套折叠**：将"成本与结构复核"大折叠内的子折叠拆分为独立 Collapsible 组件，不嵌套
- **默认状态统一**：
  - 关键数据（经营利润/成本构成）默认展开
  - 详细明细（行业参考/评分公式/历史数据）默认折叠
- **卡片顺序优化**：经营概览 → 利润构成 → 成本结构 → 行业参考 → 健康度 → 历史数据（从宏观到微观）
- **分组标题**：每个折叠区域有清晰的分组标题+图标，不使用裸文字

### 步骤3：全局折叠默认状态规范
建立全局折叠默认状态规范：
- **默认展开**：页面核心数据、用户首次访问需要看到的内容、<3 项的简短内容
- **默认折叠**：辅助信息、详细明细、高级设置、>5 项的长内容、历史数据
- **不折叠**：页面主操作、关键指标、空态引导
- 逐项检查全局 11 处折叠，调整默认状态

### 步骤4：分组标题规范
- 所有内容分组必须有分组标题（不使用裸分隔线）
- 分组标题样式：14px -0.01em text-secondary，左侧 16px 图标，右侧可选操作（折叠箭头/"查看全部"）
- 分组标题与内容间距：标题下方 12px，内容卡片之间 16px
- 分组标题可点击折叠（如该组可折叠）
- 全局搜索无标题的内容分组，添加分组标题

### 步骤5：卡片顺序与信息层级
- 每个页面的卡片顺序：核心指标 → 详细数据 → 辅助信息 → 操作入口
- 信息层级：页面标题（h1 28px）→ 卡片标题（h2 20px）→ 分组标题（14px）→ 内容（14px）→ 辅助文字（12px）
- 不跳级：不使用 h3 作为卡片标题，不使用 12px 作为主要内容
- 逐项检查 5 个 Tab + 33 个子页面的卡片顺序

### 步骤6：折叠展开动画统一
- 所有折叠使用通用 Collapsible 组件，不内联实现
- 动画：grid-template-rows 0fr→1fr（320ms），内容淡入（250ms 延迟 50ms），箭头旋转（180ms）
- 可中断：CSS transition 天然可中断，快速点击不跳变
- prefers-reduced-motion：动画禁用，直接显示/隐藏

## 常见问题与回退
- **问题：** 通用 Collapsible 组件在某些页面样式不匹配
  **解决：** 扩展组件的 variant/size props，或为该页面添加特例样式
- **问题：** 折叠内容包含图表，展开时图表尺寸计算错误
  **解决：** 展开后触发图表 resize 事件，或使用 ResizeObserver
- **回退：** `git revert` 本批次提交
