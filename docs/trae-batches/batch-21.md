## 执行步骤

### 步骤1：建立 8 级 Type Scale
在 primitives.css 中新增字号令牌：
```css
:root {
  --sdq-font-display: 32px;   /* 大数字/英雄区 */
  --sdq-font-h1: 28px;        /* 页面标题 */
  --sdq-font-h2: 20px;        /* 卡片标题 */
  --sdq-font-h3: 16px;        /* 子标题/分组标题 */
  --sdq-font-body: 14px;      /* 正文/主要内容 */
  --sdq-font-caption: 12px;   /* 辅助文字/标签 */
  --sdq-font-micro: 11px;     /* 次要辅助/时间戳 */
  --sdq-font-chart: 10px;     /* 图表坐标轴/标签（仅限图表） */
}
```
**最小字号：10px（仅限图表），其他地方不允许 <11px。**

### 步骤2：删除极端小字号
- **8px（5处）**：全部删除或提升到 10px（图表）/ 11px（辅助）
- **9px（24处）**：全部提升到 10px（图表）/ 11px（辅助）/ 12px（标签）
- **底部导航 9px**：提升到 10px（与图表同级，可接受）
- 全局搜索 `font-size: 8px` / `9px`，逐一替换，不遗漏

### 步骤3：全局替换硬编码字号
搜索所有 .css/.tsx 文件中的硬编码 font-size，替换为令牌：
- 32px → var(--sdq-font-display)
- 28px → var(--sdq-font-h1)
- 20px → var(--sdq-font-h2)
- 16px → var(--sdq-font-h3)
- 14px → var(--sdq-font-body)
- 12px → var(--sdq-font-caption)
- 11px → var(--sdq-font-micro)
- 10px → var(--sdq-font-chart)（仅限图表）
- 其他字号（13px/15px/18px/24px）：就近归入相邻级别，或保留但注释说明

### 步骤4：行高规范
- 全局默认行高：1.5（body 正文）
- 大标题（display/h1）：1.15（紧凑）
- 卡片标题（h2/h3）：1.3
- 正文（body）：1.5
- 长文本（描述/说明）：1.6（≥40 字的段落）
- 小字号（caption/micro/chart）：1.4（不小于 1.4，避免拥挤）
- 全局搜索无行高的文字，添加对应行高

### 步骤5：字距规范
- 大标题（display/h1）：-0.02em（负字距，紧凑高级）
- 卡片标题（h2）：-0.01em
- 子标题（h3）：0
- 正文（body）：0
- 标签/辅助（caption/micro）：0.01em（正字距，提升小字号可读性）
- 图表标签（chart）：0.02em
- 金额/数字：使用 tabular-nums（等宽数字，对齐）

### 步骤6：小字号对比度规范
- 10-11px 小字号：禁用 text-tertiary，必须使用 text-secondary 以上
- 12px 辅助文字：可使用 text-tertiary，但对比度 ≥3:1
- 深色背景上的小字号：使用 rgba(255,255,255,0.7)（非 text-tertiary）
- 全局搜索小字号+tertiary 组合，替换为 secondary

### 步骤7：文字截断与可访问
- 所有截断文字（text-overflow: ellipsis）添加 title 属性（hover 显示完整内容）
- 重要内容（订单号/商品名/金额）不截断，允许 2 行
- 页面标题使用 h1 标签，卡片标题使用 h2，子标题使用 h3（不用 strong/b 代替）
- 屏幕阅读器友好：语义化标签，aria-label

## 常见问题与回退
- **问题：** 字号提升后某些布局错乱（内容溢出/换行）
  **解决：** 调整容器宽度/允许 2 行/缩短文案，不降低字号
- **问题：** 图表 10px 字号在高 DPI 屏幕不可读
  **解决：** 图表坐标轴可提升到 11px，或添加 hover 放大
- **问题：** 全局替换令牌后某些页面字号不符合预期
  **解决：** 检查该页面是否有内联样式覆盖，删除内联样式
- **回退：** `git revert` 本批次提交
