## 执行步骤

### 步骤1：经营概览卡打磨
- 布局：左侧大数字（利润/收入/成本），右侧趋势图（迷你折线图）
- 数字：利润 28px -0.02em，收入/成本 16px
- 趋势：较上月变化百分比，上升 success 绿色，下降 risk 红色
- 时间范围切换：本月/上月/近30天，切换时数字滚动计数动画
- 深色背景卡：文字 text-inverse，次要文字 rgba(255,255,255,0.7)

### 步骤2：KPI 卡片统一
- 4 个 KPI：订单数/客单价/退款率/利润率
- 统一布局：图标（左）+ 数字（中）+ 趋势（右）
- 数字 20px -0.01em，标签 12px text-secondary
- 卡片 12px 圆角，16px 内边距，:active scale(0.98)
- 删除不统一的图标大小/颜色/间距

### 步骤3：销售动能图打磨
- 图表类型：近 7 天销售额柱状图 + 趋势线
- 交互：hover 显示 Tooltip（日期+金额+环比）
- 入场动画：柱状图从底部生长（460ms），趋势线描边（720ms）
- 空态：无数据时显示"开始记录第一笔流水"引导
- 配色：柱状图 action-primary，趋势线 success

### 步骤4：快捷入口布局
- 4 个快捷入口：记一笔/订单/商品/洞察（或根据业务调整）
- 网格布局：2×2 或 1×4，统一图标+文字
- 图标 24px，文字 12px，卡片 12px 圆角
- :active scale(0.95) + 背景加深
- 删除不统一的入口样式

### 步骤5：通知轮播打磨
- 位置：经营概览卡下方，不突兀
- 样式：浅色背景（bg-brand-soft），左侧图标，右侧文字
- 轮播：3s 自动切换，fade-in + slide-up 过渡
- 可点击：点击跳转到对应页面
- 可关闭：右侧 × 按钮，关闭后不再显示（本次会话）

### 步骤6：列表区域统一
- 最近订单/最近商品列表：统一卡片样式
- 列表项：左图标/头像 + 中标题+描述 + 右金额/状态
- 分割线：1px border-subtle，左对齐 16px，最后一项无
- 查看更多：底部"查看全部"按钮，14px action-primary

## 常见问题与回退
- **问题：** 经营概览卡数字在小屏幕溢出
  **解决：** 数字使用响应式字号（28px → 24px），或缩短单位
- **问题：** 销售动能图 hover Tooltip 在移动端不工作
  **解决：** 移动端改为点击显示 Tooltip，或默认显示数值标签
- **回退：** `git revert` 本批次提交
