## 执行步骤

### 步骤1：修复 FAB 遮挡瀑布图
- 洞察页瀑布图底部添加 padding-bottom: 80px（为 FAB 留出空间）
- 或 FAB 改为不固定定位，随页面滚动
- 确认所有有 FAB 的页面底部都有足够空间

### 步骤2：修复标题重复
- 商品详情页标题"商品商品成本详情" → "商品成本详情"
- 全局搜索重复标题（如"订单订单""经营经营"），逐一修复
- 标题格式统一：页面名 + 功能描述，不重复

### 步骤3：修复深色 hero 卡文字不可读
- 经营概览蓝色大卡 / 订单详情深蓝卡：确认文字颜色为 #fff 或 text-inverse
- 深色背景上的次要文字：使用 rgba(255,255,255,0.7)，不使用 text-tertiary
- 检查所有深色背景卡片的文字对比度

### 步骤4：修复关键数据缺失
- 订单详情页：补全 SKU 成交明细、退款金额、实际到账
- 商品详情页：补全成本构成明细、利润率、环比变化
- 洞察页：补全利润构成瀑布图的各项数值标签

### 步骤5：修复空态/错误态
- 列表为空时显示空态插画 + 引导文案（非空白）
- 加载中显示骨架屏（非空白）
- 错误时显示错误提示 + 重试按钮

## 常见问题与回退
- **问题：** 修复标题后某些地方引用了旧标题
  **解决：** 全局搜索旧标题字符串，替换为新标题
- **问题：** 深色卡片文字在浅色皮肤下不可读
  **解决：** 确认文字颜色使用 text-inverse（在深色背景上自动适配）
- **回退：** `git revert` 本批次提交
