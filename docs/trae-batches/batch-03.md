## 执行步骤

### 步骤1：统一卡片间距
- 所有卡片外边距：margin-bottom: var(--sdq-space-4)（16px）
- 卡片内边距：padding: var(--sdq-space-4)（16px），大卡可用 20px
- 卡片之间间距统一，不混用 12px/16px/20px

### 步骤2：统一卡片圆角
- 小卡片（标签/徽章）：radius-sm 8px
- 标准卡片（列表项/表单）：radius-md 12px
- 大卡片（概览/KPI）：radius-lg 16px
- 全局搜索 border-radius 硬编码值，替换为令牌

### 步骤3：统一图标风格
- 所有图标使用同一图标库（Lucide 或现有库）
- 图标尺寸统一：导航 20px / 按钮 16px / 列表 18px
- 图标线宽统一：1.5px（不混用 1px/2px）
- 删除混用的 emoji 图标（如 ⚠️ ✅ 📊），替换为 SVG 图标

### 步骤4：补全按钮状态
- 所有按钮必须有 4 种状态：default / hover / active / disabled
- disabled 状态：opacity 0.5 + cursor not-allowed + 禁止点击
- active 状态：scale(0.97) + 背景加深
- 全局搜索按钮组件，确认状态完整

### 步骤5：统一列表分割线
- 列表项之间分割线：1px solid var(--sdq-border-subtle)
- 分割线左边距：与列表内容对齐（通常 16px）
- 最后一项不显示分割线
- 删除混用的 hr 标签和 border-bottom

### 步骤6：统一表单标签对齐
- 表单标签左对齐，字号 14px，颜色 text-primary
- 必填项标签后加红色 *
- 输入框高度统一：44px（移动端触控目标）
- 错误提示在输入框下方，字号 12px，颜色 risk
