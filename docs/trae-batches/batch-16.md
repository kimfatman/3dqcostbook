## 执行步骤

### 步骤1：商品列表卡打磨
- 布局：左缩略图（64×64 圆角 12px）/ 中（名称+分类+成本/售价）/ 右（利润率标签+箭头）
- 名称：16px -0.01em text-primary，1 行截断
- 成本/售价：13px text-secondary，"成本 ¥12.5 / 售价 ¥29"
- 利润率标签：>50% success / 30-50% primary / <30% warning
- 分类标签：12px bg-brand-soft text-primary，圆角 6px

### 步骤2：筛选与排序
- 顶部筛选：全部分类（下拉）/ 排序（利润率/成本/售价/名称）
- 搜索框：44px 高度，placeholder "搜索商品名"
- 视图切换：列表/网格（右上角图标按钮）
- 空态：无商品时显示插画+引导"添加第一个商品"

### 步骤3：商品详情页打磨
- **标题修复**："商品商品成本详情" → "商品成本详情"（删除重复）
- 图片区：120×120 圆角 16px，无图时显示占位图标+点击上传
- 基本信息：名称/分类/SKU/单位，标签+值布局
- 成本构成：物料成本/包装成本/人工成本/其他，进度条展示占比
- 本期核算：深蓝卡，文字 text-inverse，本期销量/收入/成本/利润

### 步骤4：BOM 配方展示
- 物料清单：表格布局（物料名/用量/单位成本/小计）
- 每项物料：可编辑用量，实时更新小计
- 合计：底部突出显示总物料成本
- 添加物料：底部"+ 添加物料"按钮
- 空态：无物料时显示"还没有添加物料，点击下方按钮添加"

### 步骤5：操作按钮统一
- 三个按钮：编辑 / 复制 / 删除（或根据业务调整）
- 布局：底部固定栏，主按钮（编辑）primary 大按钮，次按钮（复制/删除）ghost
- 删除：danger 样式，点击后二次确认模态框
- 删除突兀的内联按钮，统一到固定操作栏

## 常见问题与回退
- **问题：** BOM 配方表格在小屏幕溢出
  **解决：** 改为卡片布局，每项物料独立行，用量可滑动编辑
- **问题：** 成本构成进度条颜色在深色皮肤下不清晰
  **解决：** 使用语义令牌（success/warning/info/risk），深色皮肤自动适配
- **回退：** `git revert` 本批次提交
