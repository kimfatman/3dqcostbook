## 新增页面级回归边界

`client/src/pages/Home.template-display.dom.test.tsx` 新增统一账本真实 DOM 用例。它以真实 `Home`、真实 `useCostBook()` 和真实页面栈执行以下路径：

> 首页悬浮“记一笔” → 成本分录新增（含凭证状态） → 流水搜索 → 编辑 → 删除 → 浏览器返回恢复一级导航 → 成本卡搜索空态/恢复 → 分析成本分类下钻至带关键词的流水。

网络 tRPC 仅被替换为无数据句柄，以避免该组件回归触及鉴权、云同步和媒体上传；账本状态、分录写入、派生计算、导航及条件渲染均来自生产组件代码。
