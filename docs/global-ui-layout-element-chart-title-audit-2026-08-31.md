## 五、全局设计系统改进建议

### 5.1 设计令牌收尾

| 令牌 | 现状 | 改进 |
|---|---|---|
| 颜色 | 77 色已收敛到语义层（C1） | 补全：警示色阶（橙/红 50-900）、图表色板（5 色）、状态色（成功/警告/危险/信息） |
| 字号 | 11 档体系 | 严格执行：页面标题 18px / 卡片标题 16px / 正文 14px / 辅助 13px / 说明 12px / 不得 <11px |
| 圆角 | 13 种（C1 前） | 收敛到 8 档：0/4/8/12/16/20/9999/50%；卡片统一 12px，按钮 8px |
| 按钮 | 5 档尺寸 | 严格执行层级：主/次/文字/危险/图标；每批审计按钮变体 |
| 间距 | 8dp 节奏 | 统一：卡片内边距 20px、卡片间距 12px、分组间距 24px、页面边距 16px |
| 阴影 | 4 档蓝调 | 统一：sm（普通卡片）/ md（悬浮/模态）/ lg（弹窗）；不用随机阴影 |
| 动效 | 缺统一令牌 | 新增 `--sdq-motion-*`：duration-fast 150ms / duration-normal 300ms / easing-deceleration / easing-acceleration |

### 5.2 组件库补齐

现有 `components/ui/`（shadcn）已具多数原子组件。需补齐/强化：
- **Select 自定义组件**：替换所有原生 select，统一样式
- **Empty 空态组件**：扩展三段式（图标+标题+描述+行动按钮）
- **MetricCard 指标卡**：统一大数字+标签+趋势展示
- **Badge 徽章组件**：统一语义色变体（success/warning/danger/info/neutral）
- **Skeleton 骨架屏**：统一加载态，防 CLS
- **ChartTooltip 图表提示**：统一 tooltip 样式，所有图表复用
- **PageHeader 页面标题**：统一标题+副标题+面包屑+操作区

### 5.3 全局规范执行

1. **财务数字规范**：所有金额用等宽字体 + tabular-nums + 右对齐
2. **状态色规范**：成功=绿/警告=橙/危险=红/信息=蓝/中性=灰
3. **图表规范**：颜色+符号+文本三重传达，不单靠颜色；所有图表有图例+tooltip+空态
4. **无障碍规范**：对比度正文 ≥4.5:1/非文本 ≥3:1；焦点环可见；图标 aria-label；表单 label+错误关联
5. **动效规范**：只动 transform/opacity；respect reduced-motion；每屏 ≤2 动效；流体曲线
