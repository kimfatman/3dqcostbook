# 经营流水 CSV / Excel 导出

## 导出范围

经营流水页的导出始终使用页面当前可见结果，而不是未筛选的全量数据。月份、收支类型、关键词、渠道下钻与供应商下钻会共同限定导出行；没有匹配结果时，系统不创建空文件并给出明确反馈。

| 导出字段 | 说明 |
| --- | --- |
| 日期、收支类型、分类、商户 | 保持账本流水的基础业务识别信息。 |
| 金额（元） | 收入为正数；成本与退款为负数，保留两位小数。 |
| 状态、渠道、供应商、订单号 | 保留入账状态与关联订单/供应商的可追溯维度；无关联时留空。 |
| 是否有凭证、备注 | 保留凭证状态和用户填写的业务说明。 |

CSV 采用 UTF-8 BOM 与 RFC 风格的双引号转义，便于中文表格软件直接打开；Excel 使用 `.xlsx` 工作簿，包含“经营流水”工作表、筛选范围与导出笔数元信息，金额列使用带正负号的人民币数值格式。Excel 生成模块按需加载，避免增加经营流水页面的初始脚本负担。

## 交互与验收

流水二级页标题栏提供“导出”快捷按钮，页面底部提供 CSV 与 Excel 两种明确格式选择。390px 截图复核显示筛选、列表、固定新增操作与导出面板不互相遮挡；浏览器实测成功下载 CSV 与 XLSX。下载后的 CSV 包含 BOM、筛选范围、7 笔示例流水及中文内容，XLSX 包含标准工作簿与首个工作表。

`client/src/lib/bill-export.test.ts` 覆盖筛选上下文、收入/成本正负金额、关联维度、中文文本、逗号/引号转义与文件命名。类型检查、27 个测试文件共 95 项测试、生产构建通过。
