# 全站排版舒展感与中文本地化修复记录

> 实施日期：2026-08-27。本文针对用户反馈的数字不齐、信息密度、层级、辅助文字对比度、英文原生控件和文本截断完成展示层修复；未改动账本、订单、退款、金额精度或统计口径。

## 处理原则

本轮以“财务数字清晰、卡片呼吸有序、文字完整可读”为目标。所有修改限定在前端文字、样式和登录表单反馈：金额仍以分存储并按既有 `yuan` 规则展示两位小数；订单成交日、退款日期、SKU 销量、COGS、费用和历史订单冻结成本均未触及。

| 用户反馈 | 实施方式 | 业务边界 |
| --- | --- | --- |
| 纵向数字不齐 | 为经营页面开启 `tabular-nums lining-nums`，并将目标统计、报表分类明细、报表摘要、排行和财务标题接入金融数字字体。 | 只改变字形与字距，不改变数字值、符号、小数位或格式化。 |
| 目标卡过满 | 三列目标统计使用稳定分栏、独立内边距与金融数值层；说明和操作与统计区分开。 | 月目标、预测和剩余金额的原有公式不变。 |
| 空状态拥挤 | 利润构成空状态改为“记录商品销售后，将自动归集销售收入与已售成本。” | 商品销售仍经现有订单/SKU 入账路径。 |
| 字号/字重跨度小 | 提高一级标题、二级标题、指标标签和说明的层级差；卡片说明统一 11px 以上和更宽行距。 | 不修改页面信息、筛选或下钻。 |
| 辅助文字偏弱 | 为顶栏、页面引导、空状态和报表说明建立较深的辅助文字令牌，并为深色/深海皮肤保留对应覆写。 | 不改变收益、亏损、预警的既有语义色计算。 |
| 英文文件/校验提示 | 资料页文件输入改为中文可见的上传触发控件；自建登录/注册表单关闭浏览器原生校验弹层，改用中文字段校验消息。 | 上传类型、大小限制、身份认证和服务端校验不变。 |
| 错误截断 | 店铺身份和高频顶栏文本允许换行与断词，不再以切掉首尾显示名称；金额列保留单行等宽右对齐。 | 不截断用于业务计算的原始店铺或分类名称。 |

## 关键实现

全局样式新增 `--app-copy-muted`、`--app-copy-subtle` 和 `--app-heading-strong`。财务数值继续使用既有 `--financial-numeric-font`，只在数字呈现区域启用，中文标题与正文仍使用 Noto Sans SC / 系统中文字体，从而避免将整段中文强行改为等宽字体。

`SelfHostedAccessGate` 保留 HTML 字段的 `required` 和密码最小长度约束，但表单使用 `noValidate` 避免浏览器显示 “Please fill out this field.”。提交时按初始化、注册和登录场景返回“请输入邮箱地址”“请输入正确的邮箱地址”“密码至少需要 8 个字符”等中文可见错误。资料页头像/店铺 Logo 上传框保持原有上传事件，只将原生文件按钮视觉隐藏，由中文标签承担可访问触发入口和键盘焦点。
