# 账单 CSV 与 Excel 导出说明

经营流水页新增“导出账单”操作区，位于筛选与结果统计之后。用户可选择 CSV 或 Excel；两个文件均只包含当前页面筛选后的流水，而非全量账本。

| 项目 | 实现约定 |
| --- | --- |
| 筛选范围 | 月份、收入/成本/退款类型、渠道、供应商及关键词搜索共同决定导出结果。 |
| 导出字段 | 日期、类型、分类、商户、金额、供应商、渠道、订单号、备注、凭证、状态与流水编号。 |
| CSV | UTF-8 BOM、CRLF 换行、完整 CSV 转义，兼容中文 Windows 表格软件。 |
| Excel | 标准 `.xlsx` 工作簿，含店铺/行业/筛选范围/导出时间元数据、冻结表头、自动筛选、金额格式及列宽。 |
| 安全 | 商户、订单号、备注及流水编号以单引号保护 `= + - @` 开头的文本，避免被电子表格程序当作公式执行。 |
| 空结果 | 导出按钮仍可见；点击后提示当前筛选没有可导出的流水，不生成空文件。 |

本轮还修复了演示账本在新增当前账期后，增长系数数组不足会将 `NaN` 持久化为 `null` 的问题。新账期创建时沿用最近一期有效系数；已存在的演示账本在初始化时按行业、账期与分类恢复可推导金额，避免流水列表和导出文件出现无效金额。

质量验证已完成 TypeScript 检查、27 个测试文件共 98 项测试及生产构建。浏览器在 390px 视口实际触发 CSV 与 Excel 导出，生成的文件分别被系统识别为 UTF-8 BOM CSV 和 Microsoft Excel 2007+ 格式。
