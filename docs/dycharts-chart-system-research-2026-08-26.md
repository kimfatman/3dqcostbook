## Dycharts 已核实能力

Dycharts 是面向创作与传播的零代码可视化平台，而不是面向嵌入式经营 App 的单一 JavaScript 图表库。官网帮助明确其工作流为：先按“占比、比较、多维”等分析目的或图表类型选择模板，再绑定数据、调整映射/颜色/标签/轴/网格线/图例/样式，并按手机或电脑画幅适配；作品可通过交互链接或 iframe 分享。[1]

官方模板页覆盖基础折线、曲线折线、柱状、条形、堆叠面积、瀑布、环形、雷达、热力图等大量类型；帮助文档还明确支持按原数据切换图表类型、设置线宽/节点/柱形圆角/内径占比、按需显示标签以及调整轴范围。[1][2] 这些能力对当前产品的价值在于建立“**分析目的 → 推荐图形 → 同一数据口径下切换呈现**”的系统，而不是引入更多图形数量。

> Dycharts 将交互链接、Iframe 分享、动态图表导出、数据图文与大屏视为内容制作与传播能力。[1]

本项目是商家日常决策工具，因此不应照搬大屏模板、自由画布、音视频、导出动画、任意配色或繁复网格。应保留它的三项产品方法：按任务推荐图形、将数据/视觉/交互配置分层、以及在不改数据的前提下切换适合的呈现方式。

## 模板库实测：可用图形候选

2026-08-26 实际访问 Dycharts 模板库后，页面提供“动态图表、地图、饼图、线形图、柱状图、散点图、关系图、仪表盘”等分类，并可见基础柱状图、基础饼图、折线图、折线+分组柱状混合、动态条形图、动态折线变化图、动态排名变化图、子弹图、甘特图、箱线图、折线+堆叠柱状混合、折线+层叠面积混合、纵向双轴面积图、百分比符号条形图、棒棒糖图、纵向杠铃图、堆叠柱状图、层叠面积图（平滑）、变化瀑布图与区间柱状图等模板。[9]

这些图形不是全部都适合商家成本管理。地图、桑基、关系、词云、极坐标、仪表盘大屏、维诺图等模板不能使现有账本数据更可读，因而不进入改造范围。优先使用“**混合趋势、平滑层叠面积、变化瀑布、子弹图、分组/区间柱、百分比条、棒棒糖、纵向杠铃、动态排名变化**”九类模板语言，且全部采用当前应用的浅色/深色、蓝绿红橙语义和移动端卡片规范。

| 现有经营指标 | Dycharts 对标模板 | 改造后要表达的更多信息 | 选型理由 |
|---|---|---|---|
| 本期利润形成 | **变化瀑布图** | 净营收、销售成本、经营费用、经营利润；可加上期差额的细标记。 | 保留“从收入到利润”的因果过程，不把经营利润误作普通柱。 |
| 销售额与订单数 | **折线+分组柱状混合** | 柱形显示销售额，平滑线显示订单数；当前/峰值/低值、单点金额和订单数同显。 | 一张图解释成交金额与成交密度，替代分散趋势卡。 |
| 月成本趋势 | **层叠面积图（平滑）** | 近6月总成本、主要分类构成、较上月变化、单分类聚焦。 | 同时保留趋势和构成，较单一折线增加信息承载。 |
| 月现金流 | **分组柱状图 / 区间柱状图** | 每月流入、流出与净额；当前筛选条件和最大缺口月份。 | 现金流是双方向对照，需避免与利润趋势混淆。 |
| 成本结构对比 | **百分比符号条形图 / 纵向杠铃图** | 本期占比、上期占比、百分点变化与金额变化。 | 更适合结构比较，避免仅靠两个环形图难以判断变化。 |
| SKU 与供应商排行 | **动态排名变化图 / 棒棒糖图** | 当前排名、上期排名、变化方向、实际数值和下钻。 | 保留排行的紧凑性，并提升变化信息密度。 |
| 预算与销售目标 | **子弹图** | 已完成、目标、预测月末、预算警戒阈值。 | 比环形图更适合同时比较实际、目标与预测三条基准。 |

| 退款原因 | **排行条形 + 累计曲线（帕累托混合）** | 退款金额、件数、累计占比和前二原因集中度。 | 直接支持“先处理哪类退款”的决策。 |
| 智能定价 | **单线敏感性曲线 + 区间标记** | 当前价、保本价、建议价、贡献利润和毛利率辅助读数。 | 保持“价格是唯一输入”，不以复杂混合图干扰滑块试算。 |

## 不可改变的边界

所有经营图表仍由当前纯函数聚合：销售动能按订单成交日统计，退款不倒灌销售日；SKU 当前期间指标分别按订单日和退款日处理；月度成本只归集已入账的销售成本与经营费用；现金流只认分录的现金方向；定价曲线必须使用滑块实际范围、固定采样及两位小数贡献利润。图表系统升级不得改动这些输入、排序、时间边界、金额精度或下钻目标。[3]

## 推荐的图表系统架构

升级目标不是把每一页变成模板画布，而是让用户以同一套动作理解所有经营数据：**先选时间，再选指标，再看单点读数，最后下钻到原始订单或流水**。借鉴 Dycharts “数据映射、视觉样式、图表类型可分层配置”的方法，本项目应将当前散落在各页面的 SVG 结构收敛为轻量展示契约，同时继续由现有纯函数输出真实数据。[1]

| 层级 | 新增职责 | 复用/禁止改变 |
|---|---|---|
| 数据适配层 | 为每个图表建立 `ChartSeries`：`id`、`label`、`unit`、`points`、`period`、`drilldown`、`emptyReason`。 | 继续调用 `buildDailySalesOrders`、`buildMonthlyCostStack`、`buildMonthlyCashFlow`、`buildPricingProfitTrend` 等函数；不得重算、补数或改变排序。 |
| 展示规范层 | `ChartSpec` 只描述推荐图形、语义色、数字格式、图例、是否允许比较与下钻。 | 沿用现有品牌蓝/成功绿/风险红/预警橙、金融数字、深色令牌、减少动效与无网格规则。 |
| 通用交互层 | `ChartToolbar`（时间、指标、比较）、`ChartFocus`（当前触碰点）、`ChartTooltip`（单点读数）、`ChartDetailSheet`（摘要与下钻）。 | 保留已有点击条目、点击柱形、价格滑块、渠道/供应商筛选和键盘 Tooltip 行为。 |
| 图表载体层 | `TrendChart`、`RankChart`、`CompositionChart`、`GoalChart`、`BridgeChart` 五种稳定载体。 | 继续使用纯 SVG/CSS，不在 P0 引入大屏或重量级图表运行时。 |

> Dycharts 将“同一数据可切换图表类型”用于探索式创作；成本管家只应在**同一决策任务**内提供有限切换，例如“成本趋势：金额 / 占比”，而不是向用户暴露上百种图形选择。[1]

### 统一交互规则

1. **一个图表、一条当前读数。** 用户触碰或聚焦折线/柱形/面积图的某一日期时，顶部摘要、辅助读数和 Tooltip 同时指向同一时间点；离开后回到当前期摘要。移动端不出现悬浮十字线和多层浮窗叠加。
2. **时间是一级控制，指标是二级控制。** 首页仅提供“7日 / 30日 / 本月”；分析页提供“本月 / 上月 / 近6月”；定价页不增加期间选择，价格滑块本身就是唯一横轴控制。
3. **比较只在有可比基线时出现。** 已有上期结构、预算和预测可显示差异；无上期、无目标或不足两个月数据时显示既有可行动空态，绝不以 0 补齐或伪造同比。
4. **图形点击只做原有下钻。** 触点、柱、排行行、成本分类和退款原因继续带入当前筛选打开订单/流水；图表层不直接修改账本数据。
5. **同一业务语义只保留一个主图。** 例如首页保留销售动能，分析页保留可展开的成本趋势；不再同时堆放近义的趋势缩略图、重复 KPI 和说明性图例。

## 分阶段路线

| 优先级 | 范围 | 交付内容 | 不变边界 | 验收标准 |
|---|---|---|---|---|
| P0：统一读取与下钻 | `SalesOrdersTrend`、`MonthlyCostStackChart`、`MonthlyCashFlowChart`、`PricingProfitTrendChart` | `ChartSeries` / `ChartFocus` 契约；单点 Tooltip；紧凑时间段切换；当前点联动摘要；统一空态与下钻。 | 订单日、分录日、现金方向、定价采样与两位小数完全不变。 | 390px 单手触点可达；三秒能读出当前值与趋势；键盘焦点、深色、减少动效均可用。 |
| P1：同口径比较 | 成本结构、SKU/供应商排行、预算环、目标环、退款帕累托 | 金额/占比切换；本期/上期比较条；目标/预测状态；排行变化值与统一详情抽屉。 | 排行顺序、正向成本分母、成本回冲处理、退款累计计算不变。 | 只在基线存在时显示差异；点击仍进入原有筛选后的真实流水/订单。 |
| P2：决策视图与导出 | 首页、分析页、报表详情 | 可保存的“经营概览 / 成本复核 / 定价试算”视图；静态 PNG/SVG 报表图导出；图表可访问摘要。 | 不新增伪数据、不改变账本导出字段、不将用户经营数据送入第三方图表服务。 | 视图切换不改变数据；导出与屏幕显示同一数值；移动端与桌面同一图表规范。 |

## 建议的页面分工

| 页面 | 保留主图 | P0/P1 互动 | 应减少的内容 |
|---|---|---|---|

## 结论

该站最适合提供**设计系统思路**，而不是作为本项目的直接技术依赖。当前应用已经具备平滑曲线、语义点、深色模式、移动 Tooltip、下钻、数字反馈与真实空态等基础；下一步的主要价值是把它们从“单个图表各自实现”升级为“同一时间、比较、聚焦和下钻规则”。建议先实施 P0，完成后再由真实经营数据验证哪些商家需要 P1 的结构/排行比较，避免为了“图表丰富”而增加信息噪声。

## 已落地的模板化展示改造

本轮在既有纯 SVG/CSS 图表基础上采用模板库的**图形语义与信息编排**，没有引入 Dycharts 运行时、第三方数据传输或模板大屏语言。利润桥升级为变化瀑布的三项业务读数，销售动能升级为柱线混合图的最新/峰值/客单信息带，成本趋势加入最新月、环比与最大分类比较条，现金流加入流入、流出、净额与最大缺口说明。成本结构补充最大分类洞察，退款原因补充前二原因集中度，预算与销售目标在保留环形总览的前提下增加实际—预测—目标的子弹轨道。

健康度保留已验证数据的雷达概览，但用紧凑杠铃评分列表补足每个维度的当前分和待补数状态；定价曲线保留唯一的价格滑块和固定采样曲线，并补充当前、保本、建议三项关键价格带。供应商排行已在分析页使用紧凑横向模板、Tooltip 和真实下钻；SKU 销量/利润排行现已接入首页趋势后方，复用当前期间的真实 SKU 指标和 SKU 经营页下钻，不伪造不存在的上期排名变化。

本期/上期结构对照已进一步改为“当前占比条 + 上期橙色标记”的紧凑杠铃轨道；供应商排行在存在真实已关联支出时改为按实际金额归一化的蓝色棒棒糖条。二者仍使用原有 `buildCostStructureComparison` 与 `buildSupplierCostRankings` 结果，点击分类/供应商继续带入原来的流水筛选。没有上期基线时结构保留当前分类条并将上期标记置于零点；没有已关联供应商支出时显示录入引导，绝不补造排名或变化数据。

### 验证记录

模板化图表在 375px、390px、430px、768px 与 1280px 的首页、成本分析、智能定价页面完成截图复核。新增长度受限的三列比较带、关键价格带和子弹轨道均采用截断保护与金融数字等宽显示；未发现移动端裁切或桌面宽屏失去阅读重心。真实 Home DOM 回归新增“Dycharts 模板化图表信息层级”场景，验证定价关键点、利润桥比较读数及既有导航路径。`pnpm check`、45 个测试文件共 169 项测试、`pnpm build` 均通过；构建仅保留既有主 JavaScript chunk 大于 500kB 提示。

补充的成本分析 DOM 回归在真实导航链路中创建已关联供应商支出，断言结构对照的 `.structure-dumbbell` 与供应商排行的 `.supplier-lollipop` 均出现，并确认供应商行继续下钻到对应流水。390px 成本分析截图亦复核了本期/上期结构中的当前条、上期标记、百分点变化及无供应商空态的紧凑收口。

模板组件通过受控的 `data-chart-template` 标识公开图形语义：`rank`、`pareto-rank`、`bullet-goal`、`composition` 与 `structure-dumbbell`。跨场景 DOM 回归从“我的 → 经营预算”和“分析”真实导航进入，断言目标子弹图、供应商排行、结构杠铃与真实供应商空态均可见；订单页的真实订单/退款夹具直接断言 `pareto-rank`、紧凑原因轨道和原因下钻筛选，并在首页直接断言销量/利润两个 `rank` 卡。另新增真实页面无上期基线夹具：上期成本全部为空时，结构轨道仍显示当前分类、`上期 0%` 和零点标记，点击分类仍带入真实流水筛选，未产生伪造的历史对比。

### 跨场景模板一致性

| 场景 | 图形载体与语义色 | 标签/留白规则 | 数据缺失或基线缺失处理 | 证据 |
|---|---|---|---|---|
| SKU 销量/利润排行 | `home-sku-ranking` 的蓝色圆角横条；利润仍按真实正毛利过滤。 | Top N、序号、名称、单一数值与右侧下钻；不额外塞入变化列。 | 无销量或无正利润时显示原有行动空态。 | `SkuTopBars` 已接入首页，真实订单夹具断言销量/利润两个排行卡均出现。 |
| 退款原因排行 | `template-pareto` 的预警橙累计集中度轨道与金额条。 | 标题下仅保留“前二原因占比”；行内保留件数、累计占比和金额。 | 本期无退款时显示“本期无退款”，不生成空排行。 | `RefundPareto` 模板实现、图表指标退款回归和真实订单/退款 DOM 路径。 |
| 供应商成本排行 | `template-supplier-lollipop` 的品牌蓝金额归一化棒棒糖条。 | 序号、供应商、入账笔数/占比、金额和下钻共用 SKU 排行的紧凑行节奏。 | 无关联供应商支出时保留录入引导，且 DOM 回归断言不存在棒棒糖项。 | Home DOM 空态/下钻回归，`buildSupplierCostRankings` 无关联输入回归。 |
| 本期/上期成本结构 | `template-structure-dumbbell` 的蓝色当前条与橙色上期标记。 | 分类名、两期占比、短轨道、百分点变化与下钻位于一行节奏内。 | 上期无基线时 `previousShare=0`，标记停留零点，不伪造同比分母。 | 纯函数无上期基线回归、真实页面无上期基线夹具与 390px 截图。 |
| 预算与销售目标 | `template-bullet-goal` 的蓝色实际轨、橙色预测标记、灰色目标线。 | 环心仅承担当前结果；轨道承担实际/预测/目标的比较，标签一行收口。 | 无目标时保留原有设置引导，不绘制虚构预测。 | `BudgetRing` / `SalesTargetProgress` 原有目标回归与多视口截图。 |

该矩阵证明统一性来自相同的语义色、5–7px 紧凑轨道、最大三项并列读数、等宽金融数字、短标签、真实空态和原有下钻；并不通过虚构历史排名、上期数据或预测补数来制造更多信息。
