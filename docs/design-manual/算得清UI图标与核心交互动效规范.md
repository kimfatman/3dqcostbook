# 算得清 App UI 图标与核心交互动效规范

**版本：** 1.0  
**适用端：** iOS、Android、微信小程序、H5 与 Web 管理后台。  
**目标：** 建立一套清晰、可信、易识别且可被研发稳定实现的图标与动效系统，帮助小微商家更快理解经营数据、完成关键操作并感知系统反馈。

> 图标与动效的职责是**缩短理解路径，而非增加装饰**。所有细节应服务于“看清数据、减少犹豫、及时行动”。

---

## 1. 系统总览

“算得清”UI 图标采用**圆角线性图标为主、实心状态图标为辅**的体系。圆角与连续曲线呼应品牌标志中的屋檐与微笑曲线；简洁的几何结构强化数据产品的可靠感。动效采用短时、柔和、可预测的节奏，避免高频闪烁、无意义旋转或夸张弹跳。

| 系统维度 | 基准规范 | 设计目的 |
| --- | --- | --- |
| 基础网格 | 24 × 24 dp / px 等效画板 | 覆盖导航、功能入口、列表与表单等高频场景。 |
| 常用输出尺寸 | 16、20、24、28、32、48 dp | 保证从紧凑列表到空状态插画的一致尺度。 |
| 描边风格 | Round cap + round join | 体现友好、连续、轻松的品牌感。 |
| 默认线宽 | 24 dp 图标使用 2 dp | 在浅色背景与高密度界面中均可清晰识别。 |
| 默认圆角 | 2 dp–4 dp | 与产品卡片、按钮的圆角体系呼应。 |
| 主色 | 品牌蓝 `#087AFF` | 用于激活、主功能、可操作元素。 |
| 强调色 | 活力橙 `#F6A623` | 用于收益、待关注状态和单点提醒。 |
| 中性色 | 深灰 `#1C1C1E`、中灰 `#8B95A7` | 分配信息权重，避免满屏蓝色。 |

## 2. 图标设计基础规范

### 2.1 网格、留白与对齐

所有 24 dp 图标应置于 24 × 24 的正方形画板中，视觉主体占用范围建议为 18–20 dp。图标的最外侧与画板边缘至少保留 2 dp 空白；含有外框的图标必须保证四边留白对称。除箭头、趋势线等方向性图标外，主体应优先在几何中心对齐，避免视觉重心偏移。

| 输出尺寸 | 画板 | 推荐线宽 | 最小留白 | 典型使用场景 |
| ---: | ---: | ---: | ---: | --- |
| 16 dp | 16 × 16 | 1.5 dp | 1.5 dp | 表格操作、状态标签、紧凑列表。 |
| 20 dp | 20 × 20 | 1.75 dp | 2 dp | 表单前缀、按钮附属图标。 |
| 24 dp | 24 × 24 | 2 dp | 2 dp | 底部导航、功能入口、通用操作。 |
| 28–32 dp | 28–32 × 28–32 | 2–2.25 dp | 3 dp | 空状态、快捷入口、数据分类。 |
| 48 dp | 48 × 48 | 3 dp | 5 dp | 大型入口、错误页、引导页。 |

### 2.2 线条与填充

默认状态使用线性图标；当图标处于“当前选中”“强提醒”“核心状态已完成”时，可切换至实心或线面组合版本。切换必须保持外轮廓、比例和中心点一致，不能因为状态变化造成跳动。线条末端与连接处统一为圆角；不要混用尖角线段、极细描边和厚重填充。

| 图标类型 | 结构 | 示例 | 使用边界 |
| --- | --- | --- | --- |
| 通用操作 | 线性、单层结构 | 搜索、筛选、编辑、更多 | 常规操作栏和列表末尾。 |
| 业务功能 | 线性 + 1 个语义细节 | 店铺、库存、订单、报表 | 首页快捷入口、管理后台导航。 |
| 状态提醒 | 线性 + 圆点 / 数字角标 | 铃铛、库存预警、待办 | 注意角标不得遮挡主体识别。 |
| 选中导航 | 实心或线面组合 | 首页、数据、经营、报表、我的 | 仅当前页使用品牌蓝。 |
| 情绪插画 | 线面结合、可用算小胖 | 暂无数据、完成、欢迎 | 仅用于非紧急反馈，不替代系统图标。 |

### 2.3 图标颜色与状态

色彩必须与交互语义绑定。默认图标不应全部为品牌蓝；通常操作使用中灰，激活或主要入口再使用品牌蓝。橙色只用于“建议关注”而不是普通的装饰；严重错误必须配合明确文字，不能只依靠红色图标。

| 状态 | 图标颜色 | 文字/容器建议 | 示例 |
| --- | --- | --- | --- |
| 默认 | `#8B95A7` | 无底色或白底 | 未选中的底部导航。 |
| 可操作 | `#087AFF` | 浅蓝容器 `#E6F1FF` | 新增、查看详情、主要入口。 |
| 选中 | `#087AFF` 实心或加粗 | 浅蓝选中底 / 品牌蓝标签 | 当前页面导航。 |
| 收益/正向 | `#20A779` | 浅绿底或白底 | 增长趋势、任务完成。 |
| 待关注 | `#F6A623` | 浅橙底 | 库存偏低、成本波动。 |
| 高风险 | `#E8534F` | 浅红底，必须显示原因与操作 | 删除、同步失败、严重异常。 |
| 禁用 | `#C9CFD9` | `#F2F4F7` 容器 | 不可用按钮、无权限操作。 |

## 3. 核心图标库

### 3.1 一级导航图标

底部导航固定使用 24 dp 图标与 10–12 dp 标签。非选中状态为中灰线性，选中状态为品牌蓝线面组合。导航项不建议超过 5 个。

| 导航项 | 图标语义 | 默认形态 | 选中形态 | 标签 |

| 数据 | 柱状图 / 数据列 | 三柱线性图 | 中心柱填充蓝色 | 数据 |

| 我的 | 用户头像 | 线性头像 | 头像底填充蓝色 | 我的 |

### 3.3 通用操作图标

| 操作 | 图标 | 规则 |
| --- | --- | --- |
| 新增 | 圆角加号 | 加号横竖笔等长；主按钮内使用白色。 |
| 搜索 | 放大镜 | 镜圈完整、手柄角度约 45°。 |
| 筛选 | 三层横线 + 漏斗 | 适用于列表顶部，禁止与“排序”同形。 |
| 编辑 | 铅笔 | 笔尖朝右上；与文字编辑语义一致。 |
| 删除 | 圆角垃圾桶 | 高风险操作可用红色；需配文字或二次确认。 |
| 查看详情 | 右箭头 / 右尖括号 | 默认中灰；仅表达进入下一层。 |
| 返回 | 左箭头 | 24 dp 画板内，箭头长度不小于 12 dp。 |
| 关闭 | 圆角叉号 | 弹层关闭放右上；不与“取消”按钮混淆。 |
| 更多 | 三点 | 横向用于行内更多，纵向用于页面更多，不混用。 |
| 成功 | 圆形勾选 | 成功绿或品牌蓝，必须与成功文案配合。 |

### 3.4 角标与徽标

数字角标置于图标右上方，直径最小 14 dp，背景色为活力橙或风险红，文字为白色、11 dp Medium。角标数量超过 99 时显示 `99+`。角标必须覆盖在图标画板外沿附近，但不可触及组件边缘；对于底部导航，只在消息或提醒功能确有未处理事项时展示。

## 4. 核心交互动效原则

### 4.1 动效角色

动效只承担四种角色：**建立层级、解释状态变化、确认任务完成、引导下一步动作**。任何动效在关闭“减少动态效果”系统设置后都必须降级为即时状态切换或不产生空间位移的淡入。

| 原则 | 具体要求 | 反例 |
| --- | --- | --- |
| 快速 | 微交互通常 120–240 ms；页面切换通常不超过 320 ms。 | 超过 500 ms 的常规按钮反馈。 |
| 连续 | 出现、消失、展开和收起保持明确的前后关系。 | 元素从无关位置飞入或突然跳变。 |
| 有因果 | 用户操作后先产生按压或加载反馈，再更新结果。 | 点击后静止数秒，再突然切换完整页面。 |
| 克制 | 一屏同时运动元素不超过 3 个。 | 卡片、图表、吉祥物、背景同时循环跳动。 |
| 可访问 | 重要信息不只通过动效传达。 | 仅靠抖动提示输入错误。 |

### 4.2 时间与缓动标准

| 动效类型 | 推荐时长 | 推荐缓动 | 适用场景 |
| --- | ---: | --- | --- |
| 点击按压 | 100–140 ms | `ease-out` | 图标按钮、列表项、主按钮。 |
| 状态切换 | 160–220 ms | `ease-in-out` | Tab 选中、开关、筛选切换。 |
| 弹层出现 | 220–280 ms | `cubic-bezier(0.2, 0.8, 0.2, 1)` | 底部抽屉、对话框、轻提示。 |
| 页面转场 | 240–320 ms | `cubic-bezier(0.2, 0.0, 0.0, 1)` | 详情进入、层级返回。 |
| 数据递增 | 360–600 ms | `ease-out` | 首页金额、统计卡、关键指标。 |
| 图表绘制 | 450–700 ms | `ease-out` | 首次出现的趋势线、柱状图。 |
| 柔和呼吸 | 1.8–2.4 s / 次 | `ease-in-out` | 加载页品牌图标、非关键空状态。 |

### 4.3 减少动态效果

当系统启用“减少动态效果”时，页面转场应取消平移，仅保留 120–160 ms 透明度渐变；数字不执行逐位滚动，直接显示最终数值；折线图不执行描边绘制，直接显示完整图表；不使用铃铛摇摆、吉祥物挥爪或任何持续循环动效。

## 5. 核心交互动效说明

### 5.1 底部导航切换

用户点击底部导航后，旧页面在 160 ms 内淡出，新页面在 220 ms 内淡入并轻微上移 8 dp。选中图标从线性切换为线面组合，颜色从中灰过渡到品牌蓝；标签字重从 Regular 变为 Medium。禁止让整个导航栏整体跳动或让所有图标同时缩放。

| 阶段 | 时长 | 视觉表现 | 落地要求 |
| --- | ---: | --- | --- |
| 按压 | 80–100 ms | 图标与标签缩放至 0.96。 | 手指抬起即恢复。 |
| 激活 | 160 ms | 颜色过渡，中间形态保持轮廓对齐。 | 不改变图标画板大小。 |
| 内容切换 | 220 ms | 新页面淡入并上移 8 dp。 | 滚动位置与导航状态同步。 |

### 5.2 首页数据加载与刷新

首页进入时，卡片按照“经营摘要—趋势—待办”顺序渐显，卡片之间间隔 40–60 ms。金额先显示货币符号和整数骨架，再在 360–600 ms 内平滑递增到最终数值；涨跌箭头在数字稳定后 80 ms 出现。下拉刷新使用品牌图标或简化的屋檐/等号符号完成 180°–240° 的短旋转，不使用无限旋转的品牌主Logo。

### 5.3 趋势图表进入

趋势图表首次进入时，坐标与图例先以 120 ms 渐显，主收入线在 500–700 ms 内从左至右绘制，成本线和利润线随后各延迟 80 ms。关键数据点只在用户停留或点击时放大 1.15 倍并出现浮层，不应在静态状态下持续闪烁。

| 图表元素 | 首次进入 | 用户交互 | 禁用规则 |
| --- | --- | --- | --- |
| 图例 | 120 ms 淡入 | 点击时切换透明度 | 不使用跳跃或旋转。 |
| 主趋势线 | 500–700 ms 描边 | 长按显示数据点与浮层 | 不循环重绘。 |
| 数据点 | 延迟 80 ms 依次出现 | 轻微放大到 1.15 | 不使用光晕脉冲。 |
| 浮层 | 160 ms 上移 + 淡入 | 跟随触点更新 | 不遮挡整个图表。 |

### 5.4 库存预警与经营提醒

当出现库存不足或成本异常时，列表卡片左侧图标从中灰过渡到活力橙，背景由白色过渡至浅橙色；时长为 180 ms。铃铛图标仅在首次新增提醒时可左右轻摆 6°、持续 220 ms，最多执行一次。提醒卡点击后进入详情页，使用 240 ms 右推转场，详情页首屏自动定位到“原因—影响—建议动作”三个区块。

### 5.5 主按钮与提交反馈

主按钮高度不小于 44 dp。按下时背景深度增加、缩放至 0.98、持续 100 ms；松开后恢复，并在请求未完成时显示 16 dp 圆形加载指示。提交成功后按钮可在 180 ms 内由品牌蓝过渡为成功绿，同时加号或提交图标平滑替换为勾选图标；成功信息停留 1.2–1.8 秒后恢复正常或进入下一页面。失败时不使用震动式连续抖动，采用 160 ms 的浅红边框与明确错误文案。

### 5.6 空状态与算小胖

空状态中的算小胖用于降低新手或无数据时的挫败感。页面出现后，吉祥物可在 280 ms 内从下方上移 12 dp 并淡入，算盘珠允许有一次极轻微的 120 ms 位移；不支持循环跳动。空状态必须提供明确下一步按钮，如“添加第一件商品”“录入第一笔收入”，而不能只展示吉祥物。

### 5.7 品牌启动与加载

启动页中，品牌图标以 360 ms 的淡入 + 1.00 至 1.04 的轻微缩放出现，随后保持静止。若加载超过 1 秒，可添加一次低对比度的外圈光晕呼吸，周期 2.0 秒，最多循环 2 次。应用内容准备完成后，启动页整体在 180 ms 内淡出，首页在 220 ms 内淡入；避免图标高速旋转或大范围粒子特效。

## 6. 研发交付建议

### 6.1 图标文件

图标必须优先交付 SVG 源文件，并保持每个图标独立命名、单一画板、无多余蒙版与不可编辑位图。用于 iOS、Android 的矢量资产应从同一 SVG 源文件导出，避免不同平台分别手绘造成形状漂移。

| 类别 | 命名规则 | 示例 |
| --- | --- | --- |
| 一级导航 | `ic_nav_{name}_{state}` | `ic_nav_home_active.svg` |
| 业务功能 | `ic_biz_{name}` | `ic_biz_inventory.svg` |
| 通用操作 | `ic_action_{name}` | `ic_action_filter.svg` |
| 状态反馈 | `ic_status_{name}` | `ic_status_warning.svg` |
| 吉祥物插画 | `illus_mascot_{scene}` | `illus_mascot_empty_inventory.svg` |

### 6.2 动效标注

交互稿应至少标明触发条件、初始状态、结束状态、时长、缓动曲线、是否可中断、加载或失败时的降级路径。推荐使用状态描述而非只提交GIF，以便研发在不同端实现一致行为。

| 动效名称 | 触发 | 时长 | 缓动 | 可中断 | 降级方式 |
| --- | --- | ---: | --- | --- | --- |
| `nav-switch` | 点击底部导航 | 220 ms | 标准入场曲线 | 是 | 仅淡入页面。 |
| `metric-count-up` | 首页数据返回 | 360–600 ms | ease-out | 否 | 直接显示终值。 |
| `chart-reveal` | 图表首屏可见 | 500–700 ms | ease-out | 是 | 直接显示完整图表。 |
| `alert-arrival` | 新提醒进入 | 180–220 ms | ease-in-out | 是 | 颜色和角标立即出现。 |
| `submit-success` | 提交成功 | 180 ms | ease-out | 否 | 勾选图标与成功文案直接出现。 |

## 7. 审核清单

| 核验项 | 合格标准 |
| --- | --- |
| 网格一致性 | 所有常规图标以 24 dp 基准绘制，留白与描边统一。 |
| 可识别性 | 在 16 dp 尺寸下仍能区分核心业务图标，不依赖文字猜测。 |
| 状态明确性 | 默认、选中、警示、禁用状态同时体现颜色、形态或标签变化。 |
| 色彩克制 | 橙色和红色仅用于语义强调，不作为大面积装饰。 |
| 动效性能 | 常规动效时长适中，不阻塞用户操作，不影响列表滑动。 |
| 信息可达性 | 动效关闭后，任务成功、错误与提醒仍可通过静态信息理解。 |
| 品牌一致性 | 圆角、线性结构、蓝橙配色和算小胖使用与品牌规范保持一致。 |

> 当效率、识别性与装饰性发生冲突时，优先级始终为：**操作反馈 > 信息理解 > 品牌一致 > 视觉趣味**。这将保证“算得清”在日常高频经营场景中始终显得可靠、轻松且好用。
