## 1. 品牌定位与设计原则

### 1.1 品牌定义

“算得清”是一款面向中国小微商家的经营管理 App。它帮助店主把收入、成本、库存、订单与利润转化为一眼可懂的经营信息，并通过及时提醒降低日常管理的遗漏与焦虑。品牌不是冷冰冰的账务工具，而是一位**懂经营、会提醒、让人安心的生意小助手**。

| 品牌维度 | 核心定义 | 设计表达 |
| --- | --- | --- |
| 品牌名称 | **算得清** | 字形稳健、阅读直接，突出“结果清晰”。 |
| 核心承诺 | 经营数据一目了然，关键事项及时提醒。 | 卡片层级清楚、数字突出、状态可行动。 |
| 目标人群 | 零售、餐饮、批发、服务业、多门店经营者。 | 场景真实、语言平实、避免专业术语堆叠。 |
| 品牌气质 | 清晰、可靠、智能、轻松、亲和。 | 蓝色构建信任，橙色提供行动，吉祥物带来温度。 |
| 首要价值 | 看清生意，减少操心。 | 先展示结论，再提供趋势与详情。 |

### 1.2 设计原则

| 原则 | 应有表现 | 应避免表现 |
| --- | --- | --- |
| **先结论，后细节** | 首页先显示收入、成本、利润与待办。 | 先让用户面对大段表格或复杂图表。 |
| **一屏一个焦点** | 一个页面只有一个主数据或主动作。 | 多个大按钮、多种高饱和重点同时竞争。 |
| **信任来自清晰** | 留白充分、标签简短、数据单位明确。 | 装饰过多、信息拥挤、只用颜色区分状态。 |
| **轻松不等于幼稚** | 圆角、微笑曲线、算小胖提供温度。 | 夸张卡通、无意义动画、打断高频操作。 |
| **提醒必须能行动** | 提示原因、影响和下一步操作。 | 只显示“异常”“告警”等抽象信息。 |

### 1.3 文案语气

文案像一位耐心的经营伙伴：短、清楚、积极，并能指导下一步。优先使用“已为你整理”“建议先处理”“去看看”“还差一步”等表达；避免训诫、命令或夸大承诺。

| 场景 | 推荐表达 | 不推荐表达 |
| --- | --- | --- |
| 成功完成 | 已记好这笔账，今天的收入更清楚了。 | 操作成功！ |
| 库存关注 | 牛奶库存只剩 3 件，建议及时补货。 | 库存严重告急！！！ |
| 空状态 | 还没有商品，先添加第一件吧。 | 暂无数据。 |
| 成本波动 | 这笔成本与平时差异较大，建议核对一下。 | 检测到异常数据。 |
| 引导操作 | 看懂趋势，下一步更有把握。 | 请完成经营数据配置。 |

## 2. 标志与品牌识别

### 2.1 标志概念

主标志为蓝色圆角方形 App 图标。白色店铺屋檐代表服务小微商家；加号代表收支、能力与增长；等号代表结果清晰；底部微笑曲线代表轻松经营。这四个元素组成一个兼具“店铺、计算、结果、陪伴”的可识别符号。

| 标志元素 | 品牌含义 | 使用规则 |
| --- | --- | --- |
| 店铺屋檐 | 商家、门店、经营场景。 | 始终在图标上半区，不旋转、不拆分。 |
| 加号 | 收入、增长、汇总。 | 笔画圆角，横竖笔长度保持一致。 |
| 等号 | 算清、平衡、得出结果。 | 两条横线保持同宽与同圆角。 |
| 微笑曲线 | 轻松、满意、陪伴。 | 保持向上弧度，禁止改为直线或下弧。 |

### 2.2 标志版本与场景

| 版本 | 推荐场景 | 说明 |
| --- | --- | --- |
| 彩色 App 图标 | App、小程序、社交头像、应用商店。 | 默认优先使用，蓝色渐变底 + 白色符号。 |
| 横向组合标志 | 官网导航、门店招牌、合作物料。 | 图标在左、中文名在右、拼音为副标。 |
| 纵向组合标志 | 启动页、品牌海报、展架。 | 图标居上，中文名居中，拼音置底。 |
| 深蓝单色版 | 单色印刷、文件页眉、低成本物料。 | 白底上使用 `#1C1C1E` 或 `#087AFF`。 |
| 反白版 | 深蓝背景、夜间招牌、深色横幅。 | 图形和文字均使用白色。 |

### 2.3 安全空间与最小尺寸

以图标内“加号横笔高度”为 **X**。标志四周至少留出 **1X** 空白，不得放置文字、边线、其他标志或高对比图形。

| 使用端 | 图标最小尺寸 | 组合标志最小宽度 | 规范 |
| --- | ---: | ---: | --- |
| 移动端 | 24 px | 108 px | 小于最小尺寸仅使用图标。 |
| Web / 后台 | 32 px | 132 px | 导航使用横向组合标志。 |
| 社交头像 | 80 px | 不适用 | 固定使用彩色图标。 |
| 印刷物 | 8 mm | 28 mm | 小尺寸优先使用单色版。 |
| 门店物料 | 120 mm | 240 mm | 建议使用不小于 2X 的安全区。 |

### 2.4 标志禁用

严禁拉伸、压扁、描边、加复杂投影、加入纹理、变更渐变方向或替换任何内部符号。不可将标志置于对比不足的图片上，也不可将算小胖替代为官方账号头像或主标志。

## 3. 色彩、字体与版式

### 3.1 色彩系统

蓝色是系统的信任锚点；橙色是行动和关注的提示色；白色与浅蓝支撑长时间阅读。产品中不应出现大面积、无语义的橙色或红色。

| 名称 | 色值 | 用途 | 推荐占比 |
| --- | --- | --- | ---: |
| **品牌蓝** | `#087AFF` | 主按钮、主要入口、激活状态、品牌图形。 | 20%–30% |
| **辅助蓝** | `#5ACBFA` | 渐变高光、辅助图表、插画细节。 | 8%–12% |
| **浅蓝** | `#E6F1FF` | 卡片选中底、空状态、图标容器。 | 10%–18% |
| **深灰** | `#1C1C1E` | 标题、核心数字、深色横幅。 | 5%–10% |
| **活力橙** | `#F6A623` | CTA重点、库存关注、增长提示。 | 3%–8% |
| 成功绿 | `#20A779` | 成功完成、正向增长。 | 按需 |
| 风险红 | `#E8534F` | 删除、严重错误、高风险异常。 | 按需且克制 |
| 页面底色 | `#F7F9FC` | 默认页面背景。 | 40%–55% |
| 分割线灰 | `#EAECEF` | 边框、分割线、禁用背景。 | 按需 |

### 3.2 渐变

主渐变方向固定为**左上辅助蓝 `#5ACBFA` 至右下品牌蓝 `#087AFF`**。该渐变适用于 App 图标、启动页、重点横幅和大型活动主视觉；不得覆盖大段正文。橙色渐变仅用于节日或正向收益信息，建议 `#F6A623 → #FFCF70`。

### 3.3 字体与数字

中文使用 **思源黑体 / Source Han Sans SC**。系统回退依次为 `PingFang SC`、`Microsoft YaHei`、`Noto Sans CJK SC`。英文和数字保持同一无衬线体系。关键金额使用视觉稳定的数字形式，带货币符号和千分位，例如 `¥ 8,888.00`。

| 层级 | 建议字号 / 行高 | 字重 | 场景 |
| --- | --- | --- | --- |
| 品牌大标题 | 48 / 60 px | Bold 700 | 海报、应用商店、展架。 |
| 页面标题 | 24 / 32 px | Semibold 600 | 页面首屏、一级模块。 |
| 关键金额 | 28 / 36 px | Bold 700 | 收入、利润、库存关键指标。 |
| 二级标题 | 18 / 26 px | Semibold 600 | 卡片标题、功能区名称。 |
| 正文 | 14 / 22 px | Regular 400 | 说明、列表、表单。 |
| 辅助文字 | 12 / 18 px | Regular 400 | 时间、备注、次要状态。 |

### 3.4 布局与间距

移动端使用 4 pt 基础栅格，常用间距为 4、8、12、16、20、24、32 px。页面水平边距默认 16 px，卡片圆角 12 px，页面大区块间距 24 px。桌面端采用 8 pt 栅格，内容最大宽度建议为 1200 px。

## 4. 图标、辅助图形与吉祥物

### 4.1 UI 图标体系

图标体系以 24 × 24 dp 网格为基础，24 dp 图标默认采用 2 dp 圆角描边，统一 `round cap` 和 `round join`。主体占用 18–20 dp，四边至少保留 2 dp 安全留白。常用尺寸可在 16、20、24、28、32、48 dp 六档中等比扩展。

| 状态 | 图标规则 | 颜色 |
| --- | --- | --- |
| 默认 | 单层线性 | `#8B95A7` |
| 可操作 | 线性或线面组合 | `#087AFF` |
| 当前选中 | 实心或线面组合 | `#087AFF` |
| 成功 | 勾选、上升等正向形态 | `#20A779` |
| 待关注 | 警示点或提示形态 | `#F6A623` |
| 高风险 | 明确错误形态 + 文案 | `#E8534F` |
| 禁用 | 降低对比度 | `#C9CFD9` |

| 图标类别 | 核心图标 | 应用场景 |
| --- | --- | --- |
| 一级导航 | 首页、数据、经营、报表、我的 | 底部导航，当前项使用品牌蓝。 |
| 经营管理 | 店铺、收入、成本、利润、库存、订单、客户、多店 | 首页快捷入口、业务模块导航。 |
| 通用操作 | 新增、搜索、筛选、编辑、删除、返回、关闭、更多 | 表单、列表、操作栏。 |
| 状态反馈 | 成功、提醒、库存预警、帮助、空状态 | 系统提示、经营提醒。 |

### 4.2 品牌辅助图形

辅助图形由**算盘珠、等号与微笑曲线**组成，可按固定节奏重复排布。该图形适用于启动页底部、包装内页、活动背景和空状态装饰；透明度通常不超过 16%，不得压住正文、关键数值、二维码或标志安全区。

### 4.3 吉祥物“算小胖”

算小胖是一只圆润的橘色猫咪，佩戴小算盘，承担陪伴、欢迎、提醒和空状态的情绪表达。它不是主标志，不应用于删除、付款确认、严重风险或法律条款等严肃场景。

| 状态 | 形象动作 | 推荐场景 |
| --- | --- | --- |
| 清晰 | 坐姿微笑、双爪扶算盘。 | 数据同步完成、经营正常。 |
| 轻松 | 侧卧、抱算盘、舒展。 | 引导页、品牌海报、应用商店。 |
| 提醒 | 举爪或配合轻量感叹号。 | 库存不足、待办、功能引导。 |
| 欢迎 | 正面招手。 | 新用户引导、首次建账。 |
| 空状态 | 搭配纸箱、文件夹等小道具。 | 暂无商品、暂无订单、暂无数据。 |

保持算小胖的橘色毛发、白色肚皮、圆润比例、深棕算盘和友善表情，不随意改变主体毛色、饰品或身体比例。

## 5. 产品 UI 组件规范

### 5.1 信息架构

业务页遵循“**摘要—趋势—待办**”的阅读顺序：页面顶部给出关键结论，中部展示趋势或拆解，底部放置可立即处理的任务。多门店情况下，门店选择器应在页面顶部清楚显示当前门店与统计周期。

| 组件 | 视觉规则 | 使用规则 |
| --- | --- | --- |
| 经营数据卡 | 白底、12 px 圆角、轻阴影或 1 px 浅灰边。 | 展示一个核心指标 + 次级趋势。 |
| 主按钮 | 品牌蓝底、白字、最小高度 44 dp、10 px 圆角。 | 每屏最多一个主按钮。 |
| 次按钮 | 白底蓝描边或浅蓝底、蓝字。 | 用于取消、详情、稍后处理。 |
| 状态标签 | 浅色底 + 语义色文字。 | 必须搭配原因和操作，不能只给颜色。 |
| 底部导航 | 不超过 5 个入口；当前项蓝色。 | 图标下必须配文字标签。 |
| 图表 | 蓝色为主线，橙、绿为辅助。 | 必有周期、单位、图例和空状态。 |

### 5.2 数据卡与图表

收入、成本、利润等主数据以深灰或品牌蓝显示；同比、环比趋势搭配箭头和文字；橙色只强调待关注项目。单张卡不应同时使用多种高饱和颜色。图表首次进入可执行一次绘制动效，静态状态不循环播放。

### 5.3 空状态与异常状态

空状态需要“说明 + 下一步动作 + 轻量情绪支持”。例如“还没有商品，先添加第一件吧”与“添加商品”按钮；算小胖可以配合出现。异常状态必须直说原因和建议，例如“牛奶库存仅剩 3 件，建议及时补货”，不可只显示抽象图标。

## 6. 核心交互动效规范

### 6.1 总体原则

动效只服务于建立层级、解释状态变化、确认任务完成与引导下一步操作。常规微交互应短、柔和、可预测；一屏内同时运动的元素不超过 3 个。开启系统“减少动态效果”后，所有关键状态必须能通过静态内容被理解。

| 动效类型 | 建议时长 | 推荐缓动 | 场景 |
| --- | ---: | --- | --- |
| 点击按压 | 100–140 ms | `ease-out` | 图标、按钮、列表项。 |
| 状态切换 | 160–220 ms | `ease-in-out` | Tab、筛选、开关。 |
| 弹层出现 | 220–280 ms | `cubic-bezier(0.2, 0.8, 0.2, 1)` | 抽屉、对话框、轻提示。 |
| 页面转场 | 240–320 ms | `cubic-bezier(0.2, 0.0, 0.0, 1)` | 详情进入、层级返回。 |
| 数据递增 | 360–600 ms | `ease-out` | 首页金额、经营指标。 |
| 图表绘制 | 500–700 ms | `ease-out` | 首次展示趋势线。 |
| 柔和呼吸 | 1.8–2.4 s / 次 | `ease-in-out` | 启动页、非关键空状态。 |

### 6.2 核心动效说明

| 动效名称 | 触发与表现 | 规范 |
| --- | --- | --- |
| 底部导航切换 | 点击后旧页面淡出，新页面淡入并上移 8 dp；图标从中灰线性过渡到蓝色线面组合。 | 内容切换 220 ms；不让整个导航栏跳动。 |
| 首页数据加载 | 经营摘要、趋势、待办依次渐显；卡片间隔 40–60 ms；金额递增到最终值。 | 金额 360–600 ms；避免每次滚动都重复播放。 |
| 趋势图表进入 | 图例先淡入，收入线从左至右绘制，成本和利润线分别延迟 80 ms。 | 500–700 ms；不循环重绘。 |
| 库存预警到达 | 图标和标签由中灰/白底过渡至橙色/浅橙底。 | 180 ms；铃铛只允许一次 220 ms 轻摆。 |
| 提交成功 | 按钮由蓝色过渡为成功绿，加号平滑替换为勾选。 | 180 ms；状态停留 1.2–1.8 秒。 |
| 空状态出现 | 算小胖从下方上移 12 dp 并淡入，配合下一步按钮。 | 280 ms；禁止循环跳动。 |
| 启动页 | 图标 360 ms 淡入并轻微缩放至 1.04，内容加载后整体淡出。 | 不使用高速旋转、粒子爆炸或长时等待。 |

### 6.3 减少动态效果

当设备启用“减少动态效果”，页面转场改为 120–160 ms 透明度切换；数字直接显示最终值；图表直接完整呈现；不播放铃铛摇摆、吉祥物动作和任何循环呼吸光效。

## 7. 应用商店视觉素材

应用商店宣传图采用 9:16 竖版、1440 × 2560 px。五张图按“经营总览—库存预警—趋势分析—多门店管理—经营提醒”叙事，前三张优先传递核心价值。每张图顶部保留品牌识别，标题控制两行以内，手机界面占画面约 55%–70%。

| 图序 | 标题 | 副标题 | 主视觉文件 |
| ---: | --- | --- | --- |

## 9. 线下与品牌传播应用

| 物料 | 推荐版式 | 关键规范 |
| --- | --- | --- |
| 门店招牌 | 深蓝底 + 反白横向组合标志。 | 远距离优先看到图标与中文名，不放功能清单。 |
| 名片 | 白底；左上图标，信息区深灰字与蓝色分隔线。 | 留白充分，不使用全幅渐变。 |
| 收银台立牌 | 顶部口号，中部二维码，底部算小胖或产品示意。 | 二维码周围留白不小于 4X。 |
| 员工服饰 | 白色或深蓝Polo；胸前小图标、背部横向标志。 | 不在袖口、衣摆大面积重复纹样。 |
| 包装贴纸 | 彩色图标 + 浅蓝辅助纹样 + 橙色小点。 | 适合圆形、方形及长条封口贴。 |
| 社交媒体头像 | 固定使用彩色App图标。 | 不使用吉祥物替代官方账号标识。 |

### 10.3 上线前审核

| 审核维度 | 通过标准 |

| 品牌识别 | 使用批准的Logo版本，并满足安全空间与最小尺寸。 |

| 动效 | 不阻塞操作；减少动效设置下仍可理解状态。 |
| 运营物料 | 标题在缩略图下仍清楚，CTA与二维码安全区完整。 |

> 当效率、识别性与装饰性发生冲突时，优先级固定为：**操作反馈 > 信息理解 > 品牌一致 > 视觉趣味**。这条原则确保“算得清”在每一个真实经营场景中始终显得可靠、清楚、轻松且好用。
