# 算得清 App 运营海报文案与视觉排版方案

**版本：** 1.0  
**投放渠道：** 微信公众号文章封面、公众号次图、朋友圈九宫格、社群转发海报与销售顾问私域传播。  
**核心目标：** 在极短浏览时间内传达“算得清能帮助店主看清生意、减少操心、及时行动”的价值，并引导用户下载、试用或咨询。

> **系列主题：** 生意算得清，老板更轻松。  
> **统一传播主张：** 不用盯着表格，也能把收入、成本、库存和利润看明白。

---

## 1. 运营海报的整体策略

本系列采用“痛点共鸣—功能证明—行动引导”的叙事结构。第一张承担记忆与品牌建立，第二至第五张分别解释库存、趋势、多门店与提醒四项高频价值。每张海报只让用户记住一个核心利益点，并通过真实业务数据、手机界面和算小胖吉祥物建立可信且轻松的感受。

| 海报序号 | 核心价值 | 目标情绪 | 推荐渠道 | 建议主CTA |
| ---: | --- | --- | --- | --- |
| 01 | 收入、成本、利润一眼看清 | “终于不用自己算了” | 朋友圈首图、公众号封面 | 免费试试看 |
| 02 | 库存及时预警，减少断货 | “这正是我需要的提醒” | 商超、零售商家社群 | 去看看库存提醒 |
| 03 | 经营趋势可视，决策更有底 | “数据原来可以这么好懂” | 公众号功能介绍文章 | 查看经营报表 |
| 04 | 多门店统一管理 | “多家店也能管得过来” | 连锁门店、批发商家私域 | 管好每一家店 |
| 05 | 待办与异常主动提醒 | “少操心，少遗漏” | 朋友圈转化收口、社群转发 | 立即开启提醒 |

### 1.1 统一视觉语言

海报使用**品牌蓝 `#087AFF`**构建可信赖的数字经营氛围，采用**浅蓝 `#E6F1FF`**与白色维持清爽留白，并以**活力橙 `#F6A623`**突出增长、提醒和CTA。顶部固定使用彩色 App 图标与“算得清 / SUAN DE QING”组合标识；中部使用高对比大标题；下半部以手机界面呈现功能证据；右下角由橘猫吉祥物“算小胖”提供情绪收口。

文字必须遵循“标题大、数据大、说明短”的层级。标题不超过 16 个汉字；副标题不超过 24 个汉字；手机界面中的每张卡片不超过 2 行关键信息。单张朋友圈海报建议使用 3:4 竖版；公众号文章头图建议采用 16:9 或 2.35:1 横版，并保留标题安全区域。

### 1.2 版式结构

| 区域 | 版式比例 | 内容规范 |
| --- | ---: | --- |
| 品牌识别区 | 顶部 12%–16% | 彩色图标 + 中文品牌名 + 拼音副标；白底或浅蓝底。 |
| 主张区 | 顶部至中部 18%–24% | 一句大标题 + 一句辅助说明；左对齐或居中。 |
| 功能证明区 | 中下部 42%–50% | 手机Mockup或放大的关键数据卡；清楚可见，不放复杂长文。 |
| 情绪与CTA区 | 底部 16%–22% | 算小胖、按钮、二维码预留位或行动文案。 |

## 2. 海报 01：经营总览

### 海报定位

这是系列的品牌首图，用最直接的方式解决“我每天很忙，但不知道今天到底赚了多少”的经营焦虑。画面以品牌蓝为主，传达成熟、可靠和可掌控。

| 内容层级 | 指定文案 | 排版与视觉说明 |
| --- | --- | --- |
| 顶部品牌 | 算得清 / SUAN DE QING | 图标置左或居中；作为统一识别锚点。 |
| 主标题 | **生意，一眼算清** | 48–64 px 等效大字，深灰或深蓝，高对比。 |
| 副标题 | 收入、成本、利润，今天就看明白 | 20–28 px 等效字号，低于标题一级。 |
| 数据证明 | 今日收入 ¥8,888.00；今日利润 ¥2,345.60 | 在手机中以白色圆角数据卡呈现，金额使用粗体。 |
| CTA | 下载算得清，今天的生意今天看懂 | 底部蓝色按钮或橙色短标签；二维码在实际投放版补入。 |

**朋友圈配文建议：**

> 开店最怕的不是忙，而是忙了一天还不知道到底赚了多少。用算得清，把收入、成本、利润放在一张首页里。今天的生意，今天就看懂。

## 3. 海报 02：库存预警

### 海报定位

本张直接面向零售、便利店、餐饮和批发商家的“断货”痛点。画面不要渲染紧张气氛，而是强调系统提前提醒带来的从容。

| 内容层级 | 指定文案 | 排版与视觉说明 |
| --- | --- | --- |
| 顶部品牌 | 算得清 / SUAN DE QING | 与系列保持同一位置与尺度。 |
| 主标题 | **库存有提醒，不怕卖断货** | 主标题可两行排版，但每行字数应均衡。 |
| 副标题 | 商品余量实时掌握，补货刚刚好 | 使用深灰蓝，避免危机叙事。 |
| 数据证明 | 牛奶库存仅剩 3 件；纸巾库存仅剩 6 箱 | 在手机列表中使用橙色“预警”标签。 |
| CTA | 让库存提前告诉你下一步 | 底部搭配举爪提醒的算小胖。 |

**朋友圈配文建议：**

> 好生意别断在库存上。商品还剩多少、什么时候该补货，算得清会提前提醒你。少一次断货，多一份从容。

| 内容层级 | 指定文案 | 排版与视觉说明 |

| 顶部品牌 | 算得清 / SUAN DE QING | 与其他海报一致。 |

> 生意不是只看今天。收入有没有涨、成本哪里变高、利润为什么波动，打开算得清，一条趋势线就能看明白。

| 内容层级 | 指定文案 | 排版与视觉说明 |

| 主标题 | **多门店，也能一起管清楚** | 标题可分两行，突出“多门店”。 |

**朋友圈配文建议：**

> 店多了，账和货也容易乱。算得清把每家店的收入、利润、库存放在一部手机里，在哪里都能看得清楚。

## 6. 海报 05：经营提醒

### 海报定位

本张作为系列的转化收口，展现工具的主动陪伴能力。重点不是“制造警报”，而是让用户感到日常经营有人帮自己记着。

| 内容层级 | 指定文案 | 排版与视觉说明 |
| --- | --- | --- |
| 顶部品牌 | 算得清 / SUAN DE QING | 统一识别。 |
| 主标题 | **及时提醒，少操心一点** | 标题保持友好，而非紧急警示。 |
| 副标题 | 待办、库存、成本异常，都会告诉你 | 使用短句列出三种提醒价值。 |
| 数据证明 | 牛奶库存仅剩 3 件；本周成本较上周增加 20%；还有 5 笔订单等待处理 | 按重要度采用蓝、橙、绿/蓝图标区分，避免全部使用红色。 |
| CTA | 让重要的事，不再靠记性 | 算小胖挥爪、铃铛作为友好收口。 |

**朋友圈配文建议：**

> 忙起来，最容易漏掉的是小事；而小事一多，就会影响生意。待办、库存、成本变化，算得清会及时提醒你。

## 7. 公众号文章封面与朋友圈适配

### 7.1 公众号封面

公众号文章主封面采用**横向 16:9**版式，左侧安排主标题和副标题，右侧放手机界面与算小胖。若用作文章次图，应进一步放大标题、简化手机细节，使缩略图仍能清晰识别核心价值。

| 文章主题 | 封面标题 | 副标题 | 建议主视觉 |
| --- | --- | --- | --- |
| 经营总览 | 开店一天，到底赚了多少？ | 算得清把收入、成本和利润放在一张首页。 | 经营总览手机界面。 |
| 库存管理 | 库存总是来不及补？ | 提前提醒，别让好生意断在货架上。 | 库存预警列表 + 算小胖。 |
| 数据复盘 | 经营趋势，看懂才有用 | 不只记录数据，更帮你发现变化。 | 三色趋势线与经营建议卡。 |
| 多门店 | 店多，不等于账要更乱 | 一部手机管清每一家店。 | 多门店汇总卡 + 店铺插画。 |

### 7.2 朋友圈九宫格建议

九宫格按 3×3 编排。第一排建立问题：忙、账乱、库存忘；第二排展示算得清的经营总览、趋势与提醒；第三排形成行动：多门店、算小胖陪伴、下载引导。九宫格中心图建议使用彩色App图标与主标语“生意算得清，老板更轻松”，使单张被转发时也仍保有品牌识别。

### 7.3 二维码与法律信息预留

实际投放版本应在底部安全区预留二维码位。二维码应为正方形，四周至少保留二维码模块宽度 4 倍的空白区；二维码旁仅保留一句行为指引，如“扫码下载算得清”。如涉及优惠、活动规则或资格限制，应由运营团队提供经确认的正式文字后再加入，不可在主视觉内堆叠小字。

## 8. 生产检查清单

| 检查维度 | 发布前标准 |
| --- | --- |
| 品牌识别 | 每张主海报均使用标准图标与“算得清”字标；不出现其他无关品牌。 |
| 文案 | 标题只有一个重点，不夸大承诺，不使用焦虑式用语。 |
| 色彩 | 蓝色为主、橙色用于强调；警示信息不以红色铺满画面。 |
| 手机界面 | 关键数据可读，卡片、图标、圆角和导航符合产品系统。 |
| 吉祥物 | 算小胖情绪与主题匹配，不遮挡手机关键数据或CTA。 |
| 渠道适配 | 朋友圈采用 3:4 竖版；公众号主封面采用横版安全区。 |
| 转化路径 | 实投版有明确CTA和二维码/下载入口，但不破坏主视觉层级。 |

> 本方案可作为运营、设计和市场团队的共用制作基线。若开展节日促销、行业定向或联名活动，应保持本系列的Logo位置、蓝橙色关系、字体层级及算小胖角色识别不变，只替换活动主题与短期利益点。
