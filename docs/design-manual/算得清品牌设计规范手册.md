# 算得清 App 品牌设计规范手册

**版本：** 1.0  
**适用范围：** App、应用商店、微信小程序、Web 管理后台、社交媒体、线下物料及品牌合作传播。  
**品牌定位：** 面向中国小微商家的一站式经营管理工具，以清晰的数据、轻松的操作和可信赖的提醒，帮助店主看懂生意、算清利润、稳步经营。

> 本手册以已确定的蓝色“店铺 + 加号 + 等号 + 微笑曲线”标志与“算小胖”橘猫吉祥物为基础。所有落地设计均应优先保持**清晰、可信、轻松、亲和**四项品牌感知的一致性。

---

## 1. 品牌战略与设计总则

### 1.1 品牌核心

“算得清”并非只提供记账与报表功能，而是把经营者最关心的收入、成本、库存和利润转换成可理解、可行动的判断。视觉系统必须避免金融产品常见的冷峻、复杂或高压感，而应让用户在接触品牌的第一秒感到数据是友好的、经营是可控的。

| 品牌要素 | 规范定义 | 设计转译 |
| --- | --- | --- |
| 品牌名称 | **算得清** | 名称强调“计算结果清晰”，中文字标须稳健、易读、亲和。 |
| 品牌口号 | **生意算得清，老板更轻松** | 用于品牌页、应用商店首图、广告及大型传播物料。 |
| 品牌愿景 | 让每一次经营决策都有清晰依据。 | 使用“洞察、掌握、增长、安心”等积极动词。 |
| 品牌承诺 | 经营数据一目了然，提醒及时可靠。 | 信息层级明确；重要异常以温和、可执行的方式提示。 |
| 目标用户 | 社区零售、餐饮、批发、服务业及多门店的小微经营者。 | 用语口语化但不随意；优先真实经营场景。 |

### 1.2 品牌人格

品牌应被理解为一位既懂生意又有耐心的经营助手。它不会居高临下地“教育”用户，也不会用夸张营销制造焦虑，而是在关键时刻递上数据、给出提醒、帮助做出下一步动作。

| 人格关键词 | 应有表现 | 应避免表现 |
| --- | --- | --- |
| 清晰 | 清爽网格、短句标签、可扫描的信息层级。 | 堆叠长段文字、复杂装饰、无主次的数据卡。 |
| 可靠 | 深蓝锚定重点；数字、状态、提醒均有一致规则。 | 过度渐变、强烈闪烁、与风险无关的红色警告。 |
| 智能 | 使用趋势线、摘要和建议，让信息产生解释。 | 将“AI”“智能”作为无意义装饰词。 |
| 轻松 | 圆角、笑脸曲线、橙色点缀及吉祥物互动。 | 过度幼态、游戏化干扰、影响效率的动画。 |

### 1.3 设计原则

1. **先结论，后细节。** 首页、广告和推送优先呈现“今天赚了多少”“哪个商品要补货”“下一步做什么”等可行动结论。
2. **一屏一个焦点。** 无论是应用商店截图还是业务页面，都只保留一个主信息与一个主操作。
3. **蓝色建立信任，橙色推动行动。** 蓝色用于信息架构与稳定状态；橙色只用于积极增长、重要提醒或主行动。
4. **让数据具有人情味。** 通过“算小胖”的陪伴、简洁鼓励文案与柔和留白，降低经营数据的压力感。
5. **所有关键状态都能被识别。** 不可仅依赖颜色区分风险或成功；必须结合图标、标签、文案与数值趋势。

## 2. 品牌标志系统

### 2.1 标志构成与寓意

主标志采用圆角方形蓝色渐变底板，白色图形包含店铺屋檐、加号、等号与微笑曲线。店铺表达服务对象；加号代表收支、增长和汇总；等号代表算清结果；微笑曲线表达店主获得经营掌控后的轻松感。

| 组件 | 含义 | 使用要求 |
| --- | --- | --- |
| 店铺屋檐 | 小微商家、经营场景、归属感。 | 始终位于图标上部，不旋转、不拆分。 |
| 加号 | 收入、能力叠加、增长。 | 使用白色实线；不可替换为其他数学符号。 |
| 等号 | 清晰结果、平衡与结算。 | 两条横线长度、圆角与加号笔画保持一致。 |
| 微笑曲线 | 轻松经营、品牌温度。 | 必须保持向上弧度，不改为直线或下弧。 |

### 2.2 标志版本

| 标志版本 | 推荐场景 | 使用说明 |
| --- | --- | --- |
| 彩色图标 | App 图标、小程序、数字产品、社交头像。 | 优先使用；保持蓝色渐变与白色符号。 |
| 横向组合标志 | 官网页首、门店牌、横幅、联名物料。 | 图标在左，文字在右；适合横向信息区。 |
| 纵向组合标志 | 品牌页、展架、应用商店首图。 | 图标在上，中文名居中，英文副标置底。 |
| 单色深蓝版 | 单色印刷、传真、低成本物料。 | 白底上使用品牌深蓝；符号与文字同色。 |
| 反白版 | 深色底、照片深色区域、夜间场景。 | 图形与文字使用白色；背景需保证足够对比。 |

### 2.3 安全空间与最小尺寸

将图标内“加号横笔的高度”定义为 **X**。任何标志外侧至少保留 **1X** 的空白区域，不放置文字、边线、其他标志或复杂图片。

| 载体 | 图标最小尺寸 | 横向组合最小宽度 | 备注 |
| --- | ---: | ---: | --- |
| 移动端界面 | 24 px | 108 px | 小于该尺寸时仅使用图标。 |
| Web 与后台 | 32 px | 132 px | 导航中建议用图标 + 文字组合。 |
| 社交媒体 | 80 px | 不建议 | 头像优先使用彩色图标。 |
| 印刷物 | 8 mm | 28 mm | 小尺寸印刷使用单色版，避免渐变失真。 |
| 门店与户外 | 120 mm | 240 mm | 应留出更大安全边距，建议不小于 2X。 |

### 2.4 标志禁用规则

标志不可被拉伸、压扁、描边、加投影、添加复杂纹理或替换渐变色。不得改变加号、等号和微笑曲线的相对位置；不得把标志置于对比不足、纹理复杂或高饱和橙色背景上。任何合作物料中，算得清标志应与合作方标志保持等高或等视觉权重。

## 3. 色彩系统

### 3.1 主色与辅助色

品牌采用科技蓝建立专业信任，以活力橙提供行动引导，以浅蓝和中性灰构成低压力的信息界面。界面中蓝色必须占主导，橙色只承担强调功能。

| 色彩名称 | HEX | RGB | 主要用途 | 推荐占比 |
| --- | --- | --- | --- | ---: |
| 品牌蓝 | **#087AFF** | 8, 122, 255 | 主按钮、重要数字、品牌图形、链接、激活状态。 | 20%–30% |
| 辅助蓝 | **#5ACBFA** | 90, 203, 250 | 渐变高光、辅助图表、插画细节、浅层背景。 | 8%–12% |
| 浅蓝 | **#E6F1FF** | 230, 241, 255 | 信息卡背景、选中底色、浅色插画、空状态。 | 10%–18% |
| 深灰 | **#1C1C1E** | 28, 28, 30 | 标题、核心数字、深色横幅背景。 | 5%–10% |
| 活力橙 | **#F6A623** | 246, 166, 35 | 主CTA重点、收益增长、库存提醒、吉祥物饰品。 | 3%–8% |
| 成功绿 | **#20A779** | 32, 167, 121 | 完成、增长、健康状态。 | 按需 |
| 风险红 | **#E8534F** | 232, 83, 79 | 严重风险、删除确认、逾期异常。 | 按需且克制 |
| 页面底色 | **#F7F9FC** | 247, 249, 252 | 主页面底色。 | 40%–55% |
| 分割线灰 | **#EAECEF** | 234, 236, 239 | 边框、分割线、禁用背景。 | 按需 |

### 3.2 渐变规范

主品牌渐变用于 App 图标、启动页光感、英雄横幅或大型重点卡片。渐变应保持从**左上浅青蓝向右下品牌蓝**的稳定方向，推荐起止色为 `#5ACBFA → #087AFF`。橙色渐变仅用于节日营销或积极收益表达，推荐 `#F6A623 → #FFCF70`，不可覆盖大面积正文区域。

### 3.3 语义色使用

| 场景 | 建议颜色 | 文字或图标 | 示例文案 |
| --- | --- | --- | --- |
| 正常经营 | 品牌蓝 / 深灰 | 深灰标题 + 蓝色数据 | 今日收入 ¥8,888.00 |
| 收益增长 | 成功绿 + 活力橙点缀 | 绿色趋势箭头 | 较昨日 +23.5% |
| 库存关注 | 活力橙 | 橙色标签 + 中性说明 | 牛奶库存仅剩 3 件 |
| 严重异常 | 风险红 | 红色图标 + 明确动作 | 请立即核对账目 |
| 暂无数据 | 浅蓝 / 中性灰 | 灰蓝文字 | 还没有商品，去添加第一件吧 |

## 4. 字体与排版系统

### 4.1 字体选择

中文优先使用 **思源黑体 / Source Han Sans SC**；如设备环境不可用，可按系统回退为 `PingFang SC`、`Microsoft YaHei`、`Noto Sans CJK SC`。英文和数字沿用 Source Han Sans 或使用系统无衬线字体。字体风格应干净、现代，不使用书法体、手写体或装饰性过强的标题字体。

| 层级 | 字号 / 行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| 品牌大标题 | 48 / 60 px | Bold 700 | 品牌页、应用商店首图、展架。 |
| 页面标题 | 24 / 32 px | Semibold 600 | 页面顶部、模块标题。 |
| 卡片主数据 | 28 / 36 px | Bold 700 | 收入、利润、库存关键指标。 |
| 二级标题 | 18 / 26 px | Semibold 600 | 卡片标题、功能区名称。 |
| 正文 | 14 / 22 px | Regular 400 | 说明、表单标签、列表内容。 |
| 辅助文字 | 12 / 18 px | Regular 400 | 注释、时间、次要状态。 |
| 按钮文字 | 16 / 22 px | Medium 500 | 主按钮、导航操作。 |

### 4.2 数字与数据排版

关键金额必须采用等宽或视觉稳定的数字字形，并使用千分位。例如：`¥ 8,888.00`、`23.5%`、`1,280 件`。金额的货币符号与数字之间留一个细空格；小数部分不弱化到难以辨识。同比、环比类趋势必须配合箭头图标与文字说明，不能只显示颜色。

### 4.3 栅格与间距

移动端采用 4 pt 基础栅格，常用间距为 4、8、12、16、20、24、32 px。标准页面左右边距为 16 px，卡片圆角为 12 px，页面大区块之间的垂直间距建议为 24 px。桌面端采用 8 pt 栅格，内容区最大宽度建议为 1200 px。

## 5. 图标、图形与插画

### 5.1 功能图标

图标使用**统一圆角线性风格**，默认 2 px 描边、圆角端点与圆角转折。主图标以品牌蓝呈现；通知、库存、增长等重点位置可使用活力橙作为单点强调。图标容器建议使用浅蓝底色，避免使用厚重拟物效果。

| 功能 | 图标语义 | 推荐标签 |
| --- | --- | --- |
| 店铺 | 店铺管理、多门店 | 店铺管理 |
| 计算器 | 收支、账目、算账 | 计算器 |
| 钱币 / 单据 | 收入、成本、流水 | 收入管理、成本管理 |
| 折线箭头 | 经营趋势、利润增长 | 利润分析 |
| 盒子 | 商品、仓储、库存 | 库存管理 |
| 铃铛 | 经营提醒、预警 | 提醒通知 |
| 报表 | 数据汇总、经营复盘 | 报表分析 |

### 5.2 品牌辅助图形

辅助图形由算盘珠、等号和微笑曲线组成，可重复排列为轻量纹样。该纹样仅用于空白区域、包装内页、启动页底部或活动背景，透明度建议低于 16%，不可覆盖正文、关键数据或标志安全空间。

### 5.3 吉祥物“算小胖”

算小胖是橘色圆润猫咪，佩戴小算盘，是品牌的人情化表达。它不承担企业标志功能，不应在严肃的风控、协议、付款确认或错误警告中替代系统提示。

| 吉祥物状态 | 使用场景 | 情绪与动作 |
| --- | --- | --- |
| 清晰 | 数据已同步、任务已完成、经营正常。 | 坐姿微笑，双爪扶算盘。 |
| 轻松 | 引导页、应用商店、增长提示。 | 侧卧或抱算盘，舒展、安心。 |
| 提醒 | 库存不足、待处理事项、功能引导。 | 举爪或配合感叹号，表情专注而不焦虑。 |
| 欢迎 | 新用户引导、首次建账、欢迎页。 | 正面招手，表情热情。 |
| 空状态 | 暂无商品、暂无订单、暂无数据。 | 纸箱、文件夹或小道具辅助说明，避免沮丧。 |

吉祥物的橙色应与品牌活力橙协调，白色肚皮与深棕算盘形成视觉锚点。除节日限定活动外，不更换猫咪主体毛色、体型比例、算盘饰品和面部识别特征。

## 6. UI 视觉规范

### 6.1 页面结构

所有经营页面应遵循“摘要—趋势—待办”的阅读顺序。顶部先呈现总览数据，中部展示趋势与关键业务模块，底部呈现可立即完成的待办事项。对于多门店用户，门店切换器应明确显示当前门店与数据统计周期。

| UI 组件 | 视觉规范 | 交互提示 |
| --- | --- | --- |
| 经营数据卡 | 白底、12 px 圆角、轻阴影或 1 px 浅灰边框。 | 卡片整体可点击时应显示箭头或明确入口。 |
| 主按钮 | 品牌蓝实底、白字、44 px 最小高度、10 px 圆角。 | 一屏最多一个主按钮。 |
| 次按钮 | 白底蓝色描边或浅蓝底、品牌蓝文字。 | 用于取消、查看详情、稍后处理。 |
| 警示标签 | 浅橙底 + 橙色文字；严重风险使用浅红底。 | 标签后必须配清楚的原因与操作。 |
| 底部导航 | 5 个以内主入口；选中项使用品牌蓝。 | 标签不得仅用图标代替。 |
| 图表 | 品牌蓝为主线，辅助线使用浅蓝、成功绿和活力橙。 | 必有周期、单位、图例与可解释的空状态。 |

### 6.2 信息优先级

页面的主数据使用深灰或品牌蓝；次要说明使用中性灰；仅在需要用户行动时使用活力橙或风险色。任何一张页面中，强强调色不超过两种。不要将每个数据都做成高饱和标签，否则会降低重要警报的识别效率。

### 6.3 反馈与动效

动效应服务于状态切换和任务反馈。推荐短促、柔和、可预测的渐显、上移与数字递增效果；常规持续时间为 180–300 ms。品牌图标可以在启动、加载或空状态中产生轻微呼吸光效，但不得使用频繁旋转、强闪烁和干扰阅读的循环动画。

## 7. 文案语气规范

### 7.1 语气与句式

文案使用简洁、明确、积极的表达，像一位懂经营的伙伴。优先使用“已为你整理”“建议先处理”“去看看”“再添一件商品”等可行动的句式。避免命令式、指责式或夸大承诺的表达。

| 场景 | 推荐表达 | 避免表达 |
| --- | --- | --- |
| 成功 | 已记好这笔账，今天的收入更清楚了。 | 操作成功！ |
| 提醒 | 牛奶库存只剩 3 件，建议及时补货。 | 库存严重告急！！！ |
| 空状态 | 还没有商品，先添加第一件吧。 | 暂无数据。 |
| 新手引导 | 先录入今天的第一笔收入，生意从清楚开始。 | 请按照步骤完成初始化配置。 |
| 风险 | 这笔成本与平时差异较大，建议核对一下。 | 检测到异常数据。 |

### 7.2 品牌常用语

| 用途 | 建议文案 |
| --- | --- |
| 首屏主标语 | 生意算得清，老板更轻松。 |
| 引导副标题 | 收入、成本、库存，一眼看明白。 |
| 数据概览 | 今天的生意，已经为你整理好了。 |
| 库存提醒 | 及时补货，别让好生意断在库存上。 |
| 报表入口 | 看懂趋势，下一步更有把握。 |
| 多门店入口 | 每家店的生意，都能算得清。 |

## 8. 应用商店视觉规范

应用商店宣传图应在前三张内完成核心价值传达：**看清经营、管好库存、掌握利润**。单张截图只突出一个利益点，避免同时堆叠多个模块。推荐使用 9:16 竖版视觉，并保留安全边距，适配常见手机设备展示。

| 图序 | 主标题 | 辅助文案 | 主视觉内容 | 色彩策略 |
| ---: | --- | --- | --- | --- |
| 01 | **生意，一眼算清** | 收入、成本、利润，今天就看明白。 | 手机经营总览 + 大数据卡。 | 蓝色渐变主背景，白色数据卡。 |
| 02 | **库存有提醒，不怕卖断货** | 商品余量实时掌握，补货刚刚好。 | 库存预警卡 + 算小胖提醒状态。 | 浅蓝背景，橙色预警点。 |
| 03 | **趋势看得见，经营更有底** | 看收入、成本和利润的每一步变化。 | 清晰折线图 + 分析摘要。 | 白底 + 蓝绿橙趋势线。 |
| 04 | **多门店，也能一起管清楚** | 一部手机，掌握每家店的生意。 | 多门店切换 + 汇总卡。 | 深蓝横幅 + 浅蓝信息层。 |
| 05 | **及时提醒，少操心一点** | 待办、库存、成本异常，都会告诉你。 | 提醒中心列表 + 算小胖举爪。 | 白底 + 橙色提醒标签。 |

### 8.1 应用商店图像共性规则

每张宣传图顶部应保留品牌图标和“算得清”文字标识，标题控制在两行以内，副标题控制在一行或两行短句以内。设备画面建议占画面高度的 55%–70%，确保缩略图状态下仍能看见关键标题与手机轮廓。首图使用主品牌蓝营造记忆点；后续图使用白色或浅蓝底色降低连续浏览疲劳。

### 8.2 启动页规范

启动页只承载品牌识别与加载感受，不展示复杂业务信息。背景使用 `#087AFF` 至 `#5ACBFA` 的斜向渐变；中心放置白色品牌图标，图标下方使用“算得清”和英文副标“SUAN DE QING”。底部可加入低透明度的算盘珠、等号与微笑曲线辅助纹样，并让“算小胖”在右下角以小比例出现。整页以克制留白为先，避免出现广告语、按钮、通知、数据或冗长说明。

## 9. 线下与传播应用规范

### 9.1 品牌物料

| 物料 | 建议版式 | 关键注意事项 |
| --- | --- | --- |
| 门店招牌 | 深蓝底 + 反白横向组合标志。 | 远距离优先识别图标与中文名，不堆叠功能清单。 |
| 名片 | 白底、左上图标、信息区域采用深灰文字与蓝色分隔线。 | 留白充足，不使用全幅渐变。 |
| 收银台立牌 | 顶部口号，中部二维码，底部算小胖或产品示意。 | 二维码周围留白不少于 4X。 |
| 员工服饰 | 白色或深蓝Polo，胸前小图标，背部横向组合标志。 | 避免在袖口、衣摆重复印满图形。 |
| 包装贴纸 | 使用彩色图标、浅蓝辅助纹样和橙色小点。 | 适合圆形、方形或长条封口贴。 |

### 9.2 社交媒体

社交媒体封面可采用品牌蓝渐变、中央产品界面或算小胖，标题控制在 12 字以内。日常运营图文使用白底卡片与蓝色标题条，橙色仅用于重点数字与行动号召。头像固定使用彩色 App 图标，不使用吉祥物头像替代官方账号标识。

## 10. 交付与维护清单

上线或对外发布前，设计、产品和市场团队应共同完成以下核验。

| 检查项 | 合格标准 |
| --- | --- |
| 标志使用 | 采用批准版本，符合最小尺寸与安全空间规范。 |
| 颜色使用 | 主色、辅助色与语义色使用正确，关键状态未仅依赖颜色。 |
| 文字排版 | 中文可读、数字清晰、标题与正文层级分明。 |
| UI 一致性 | 圆角、边距、按钮、图标和卡片符合本手册规范。 |
| 吉祥物使用 | 形象、饰品、毛色和情绪与场景一致，不干扰严肃流程。 |
| 应用商店素材 | 前三张突出核心价值；标题在缩略图下仍具可识别性。 |
| 启动页 | 仅展示品牌识别与轻量辅助图形，无复杂文案和功能按钮。 |
