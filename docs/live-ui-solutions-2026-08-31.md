## 一、P0 阻断级（3 项）

### P0-1｜洞察页 FAB 遮挡瀑布图底部
**问题：** 洞察页右下角 FAB "+ 记一笔" 遮挡瀑布图下方的毛利/毛利率/费用率指标。

**Skill 依据：**
- `ui-ux-pro-max` 导航一致性规则：FAB 不得遮挡核心内容，内容区需预留安全距离
- `ui-ux-pro-max` 移动端规则：触控热区 ≥44pt，固定元素需避让内容

**解决方案：**
| 方案 | 改法 | 优劣 |
|---|---|---|
| A | 洞察页隐藏 FAB（洞察是数据分析页，记账入口不常用） | 最彻底，但失去快捷记账 |
| B | FAB 上移 64px（从底部导航上方移到瀑布图上方） | 保留 FAB，但位置突兀 |
| C | 瀑布图容器增加 `padding-bottom: 96px`，确保内容不被遮挡 | 最小改动，推荐 |
| D | FAB 滚动时自动隐藏，停止时显示（apple-design 可中断动效） | 体验好，但实现复杂 |

**推荐方案：** C + A 组合——瀑布图增加 `padding-bottom: 96px` 立即修复遮挡；中期洞察页改为隐藏 FAB（分析页不需要记账入口）。
**对应批次：** C9 导航重构

### P0-2｜商品详情标题"商品商品成本详情"重复
**问题：** 商品详情页顶部标题显示"商品商品成本详情"，"商品"二字重复。

2. 检查代码中标题拼接逻辑（ likely `商品 + 商品成本详情` 的 bug），修复为单一 prop
3. 面包屑保留"商品 · 成本核算"，标题与面包屑不重复
4. 全局审计其他页面标题是否有类似拼接 bug

**推荐方案：** 改为"商品成本详情" + 修复代码拼接逻辑 + 全局审计。
**对应批次：** C11 页面专项 P0

### P0-3｜OTP 验证持续失败（注册被阻断）
**问题：** OTP 验证码发送成功，但验证环节持续报"无法完成验证码验证，请重新获取"，新用户无法注册。

**Skill 依据：**
- `ui-ux-pro-max` 表单规则：错误提示应具体可操作，内联显示
- `ui-ux-pro-max` 流程规则：多步表单应保留状态，避免用户重填

**解决方案（后端 + UX 双层）：**

**后端（根因修复）：**
1. 排查 CloudBase OTP 验证接口：challengeId 是否匹配、验证接口是否报错、生产环境 CloudBase 配置是否正确
2. 验证失败时返回具体错误码（验证码错误 / 已过期 / 挑战不存在），而非笼统错误

**UX（体验改进）：**
1. 错误提示具体化：
   - 验证码错误 → "验证码错误，请重新输入"
   - 验证码过期 → "验证码已过期，请重新获取"
   - 验证失败 → "验证失败，请稍后重试"
2. "重新获取验证码"**留在注册页**，不跳回登录页，保留所有表单状态（姓名/店铺/行业/密码/条款）
3. 验证码输入错误 3 次后自动提示重新获取
4. 重新获取倒计时 60s，期间按钮禁用

**推荐方案：** 后端优先排查修复 CloudBase 验证链路；UX 层同步改进错误提示和状态保留。
**对应批次：** 后端-P0 分流

## 二、P1 体验级（5 项）

### P1-4｜我的页退出登录红色
**问题：** 退出登录按钮用红色描边+红色文字+红色箭头，视觉权重过高。

**Skill 依据：**
- `ui-ux-pro-max` 按钮层级规则：主按钮（蓝填充）/ 次按钮（白描边）/ 文字按钮（无背景）/ 危险按钮（红色，仅用于高破坏性操作）
- `ui-ux-pro-max` 破坏性操作规则：红色仅用于不可恢复的高风险操作（删除店铺、清除数据），退出登录可重新登录，不属于高破坏性

**解决方案：**
1. 退出登录改为**中性文字按钮**（深灰文字，无背景无描边），与"编辑"等操作一致
2. 点击后增加确认弹窗："确定退出登录吗？" + 取消/确认按钮
3. 红色仅保留给真正高破坏性操作（如"删除店铺""清除所有数据"）
4. 退出登录位置移到页面最底部，与账户信息视觉分离

**推荐方案：** 中性文字按钮 + 确认弹窗 + 位置下移。
**对应批次：** C12 页面专项 P1

### P1-6｜商品列表缺库存/SKU/最近成交信息
**问题：** 商品卡片仅显示单位成本/售价/单件利润，缺库存数量、SKU 编码、最近成交信息。

**Skill 依据：**
- `ui-ux-pro-max` 信息密度规则：卡片应展示用户决策所需的核心信息
- `ui-ux-pro-max` 数据可视化规则：关键指标用语义色，异常值高亮

**解决方案：**
1. 商品卡片增加第三行信息：`库存 120件 · SKU: ECO-ISC · 最近成交 08-31`
2. 库存低于阈值（如 <10 件）时用**橙色警示色**高亮，库存为 0 时红色
3. 布局调整为三行：
   - 第一行：商品名 + 标签（成本上升/新品）
   - 第二行：单位成本 · 售价 · 单件利润（已有）
   - 第三行：库存 · SKU · 最近成交（新增）
4. 信息过多时默认显示核心 3 项，点击"更多"展开

**推荐方案：** 增加第三行（库存·SKU·最近成交）+ 低库存警示高亮。
**对应批次：** C12 页面专项 P1

### P1-7｜商品详情"更多"按钮权重不匹配
**问题：** 商品详情页"编辑成本""测算定价""更多"三个按钮视觉权重相同，未形成层级。

**Skill 依据：**
- `ui-ux-pro-max` 按钮层级规则：一个页面最多 1 个主按钮，次操作降权，三级操作用文字/图标
- `apple-design` 视觉层级原则：通过颜色/大小/位置建立清晰操作优先级

**解决方案：**
1. **编辑成本**：保持主按钮（蓝色填充，最高权重）
2. **测算定价**：保持次按钮（白色背景+蓝色描边+蓝色文字）
3. **更多**：降为**文字按钮**（无背景无描边，仅蓝色文字 + 图标），或改为图标按钮（"..."图标，点击弹出底部菜单）
4. "更多"菜单内容：复制商品、删除商品、查看历史、导出成本卡
5. 按钮排列：主按钮 + 次按钮在一行，"更多"在次按钮右侧或下方

**推荐方案：** "更多"改为文字按钮，形成主→次→文字三级层级。
**对应批次：** C12 页面专项 P1

### P1-8｜详情页无底部 Tab 导航
**问题：** 订单详情/商品详情页仅有顶部返回按钮，无底部 Tab 导航，用户无法快速切换模块。

**Skill 依据：**
- `ui-ux-pro-max` 导航一致性规则：全站主导航一致，详情页应保留底部 Tab
- `ui-ux-pro-max` 移动端规则：用户期望在任何页面都能快速切换核心模块

**解决方案：**
1. 详情页**保留底部 Tab 导航**（与列表页一致：工作台/订单/商品/洞察/我的）
2. 详情页**隐藏 FAB**（详情页不需要快捷记账，避免遮挡）
3. 顶部保留返回按钮（←），返回上一级列表
4. 滚动时底部导航可自动隐藏（apple-design 可中断动效），停止滚动时显示，增加内容可视区域
5. 从详情页切换到其他 Tab 时，保留详情页返回栈（返回时回到详情页而非列表）

**推荐方案：** 详情页保留底部 Tab + 隐藏 FAB + 顶部返回 + 滚动自动隐藏导航。
**对应批次：** C9 导航重构

## 三、P2 打磨级（7 项）

### P2-9｜工作台经营概览卡底部白色矩形空白
**问题：** 工作台经营概览卡（蓝色大卡）底部有明显白色矩形空白区域，无内容。

**Skill 依据：**
- `ui-ux-pro-max` 空态/加载态规则：空白区域应有明确内容、加载态或空态提示，不得留白
- `ui-ux-pro-max` 组件规则：卡片高度应自适应内容，不预留固定空白

**解决方案：**
1. 检查白色矩形是否为**未加载完成的组件**（如趋势图、指标卡），修复加载逻辑和数据绑定
2. 如果是预留区域，填入有价值的内容：
   - "较昨日"趋势箭头（↑/↓）+ 变化幅度
   - 利润率趋势迷你图（sparkline）
   - 本月累计利润 / 本月目标完成度
3. 如果暂无数据，显示**空态提示**："暂无数据，记一笔后查看经营趋势" + 引导按钮
4. 移除不必要的固定高度，卡片高度自适应内容

**推荐方案：** 优先检查组件加载逻辑（疑似 bug）；修复后填入趋势迷你图或空态提示。
**对应批次：** C11 页面专项 P0

### P2-10｜订单卡片右侧大片空白

- `ui-ux-pro-max` 信息密度规则：充分利用卡片空间，展示核心决策信息

**推荐方案：** 左右分栏 + 金额右对齐 + 状态标签 + 快捷操作。

### P2-11｜"成本上升"徽章警示不足
**问题：** 商品卡片"成本上升"徽章为浅色标签，警示性不足，用户不易察觉。

**Skill 依据：**
- `ui-ux-pro-max` 数据可视化语义化规则：颜色 + 符号 + 文本，不单靠颜色
- `ui-ux-pro-max` 徽章规则：警示类徽章用高对比度背景+白色文字，配方向箭头

**解决方案：**
1. 徽章改为**橙色背景 + 白色文字**（更强警示性），成本下降用绿色背景+白色文字
2. 增加**上升箭头图标**（↑）+ 上升幅度（如"+12%"），形成"↑ 成本上升 +12%"
3. 鼠标悬停/点击显示**详情气泡**："较上期成本上升 12%，主要因原材料木头原料涨价"
4. 徽章位置固定在商品名右侧，与商品名同一行，不占用额外空间
5. 成本上升超过阈值（如 >20%）时升级为红色徽章

**推荐方案：** 橙色背景+白色文字+↑图标+幅度 + 悬停详情 + 超阈值升级红色。
**对应批次：** C12 页面专项 P1

### P2-12｜经营预算无解释
**问题：** 我的页"经营预算 ¥500.00"仅有金额，无说明文字，用户不理解预算用途。

**解决方案：**

   - 当实际成本接近预算时，系统会发出预警

3. 点击进入编辑页时，在表单顶部显示预算用途说明
4. 预算超支时在**工作台显示预警提示**（橙色横幅："本月成本已超预算 15%，请注意控制"）

**推荐方案：** 灰色说明文字 + "i"信息图标 + 超支预警。
**对应批次：** C12 页面专项 P1

### P2-13｜订单详情 SKU 字号偏小
**问题：** 订单详情页 SKU 成交明细字号偏小（约 11-12px），可读性差。

**Skill 依据：**
- `ui-ux-pro-max` 字号体系规则：正文 ≥14px，辅助文字 ≥12px，不得小于 11px
- `ui-ux-pro-max` 财务数字规则：编码类用等宽字体，提升识别性

**解决方案：**
1. SKU 明细字号从当前（约 11-12px）提升到 **13px**（辅助文字规范下限）
2. SKU 编码（如 ECO-ISC）用**等宽字体**（IBM Plex Mono），便于识别和复制
3. 增加**行高**到 1.5-1.6，提升可读性
4. 关键信息（数量 12件、金额 ¥459.96）用**稍大字号（14px）或加粗**
5. SKU 行增加 hover 态（浅灰背景），提示可点击查看详情

**推荐方案：** SKU 字号 13px + 等宽字体 + 行高 1.5 + 关键信息加粗。
**对应批次：** C12 页面专项 P1

### P2-14｜退款与退货回收空卡
**问题：** 订单详情页"退款与退货回收"卡片在无退款时显示空白卡片，无空态提示。

**Skill 依据：**
- `ui-ux-pro-max` 空态设计规则：结果—原因—行动三段式，不得留白
- `ui-ux-pro-max` 信息架构规则：无数据的模块可折叠，减少视觉噪音

**解决方案：**
1. 空态显示**三段式提示**：
   - 结果："暂无退款记录"
   - 原因："该订单未发生退款或退货"
   - 行动："如有退款，记一笔后自动同步到这里"
2. 空态用**浅灰背景 + 图标**（退款图标），不要用空白卡片
3. 无退款时该卡片**默认折叠**（仅显示标题"退款与退货回收 · 暂无"），点击展开
4. 或与"售后经营口径"卡片合并，减少卡片数量
5. 有退款时显示完整明细（退款金额、退款原因、退货回收数量、退款时间）

**推荐方案：** 空态三段式提示 + 浅灰背景 + 无退款时默认折叠。
**对应批次：** C12 页面专项 P1

### P2-15｜商品详情图片上传区图标色浅
**问题：** 商品详情页"添加商品图片"上传区图标为浅蓝色，在浅蓝背景上对比度不足，不易识别。

**Skill 依据：**
- `ui-ux-pro-max` 对比度规则：非文本元素（图标）对比度 ≥3:1
- `ui-ux-pro-max` 图标纪律：图标颜色应与背景形成足够对比，统一尺寸和描边

**解决方案：**
1. 上传区图标颜色**加深**（从浅蓝 #93C5FD 改为中蓝 #3B82F6 或深蓝 #1D4ED8），对比度提升到 ≥3:1
2. 上传区背景改为**更浅的灰色**（#F9FAFB），与蓝色图标形成对比
3. 增加**虚线边框**（1px dashed #D1D5DB），上传区边界更明显
4. 图标尺寸**增大**（从 20px 到 24px），提升可识别性
5. 上传区文字"添加商品图片"字号提升到 14px，辅助文字"JPEG、PNG 或 WebP · 最大 5MB"保持 12px 灰色
6. 有图片时显示图片预览 + 替换/删除按钮，无图片时显示上传引导

**推荐方案：** 图标颜色加深到中蓝 + 虚线边框 + 尺寸 24px + 浅灰背景。
**对应批次：** C12 页面专项 P1

## 四、P3 微调级（2 项）

### P3-16｜行业下拉原生 select 边框略粗
**问题：** 注册页/我的页经营行业下拉用原生 select 样式，边框较粗，与整体设计语言不一致。

**Skill 依据：**
- `ui-ux-pro-max` 组件一致性规则：所有表单组件样式统一（边框、圆角、聚焦态、图标）
- `ui-ux-pro-max` 图标纪律：下拉箭头用统一的 ChevronDown 图标（Lucide）

**解决方案：**
1. 用**自定义下拉组件**替代原生 select，与全局输入框样式统一：
   - 边框 1px（#E5E7EB）
   - 圆角 8px（全局圆角令牌）
   - 聚焦态蓝色边框（#3B82F6）+ 蓝色阴影
   - 高度 44px（触控热区规范）
2. 下拉箭头用统一的 **ChevronDown 图标**（Lucide，20px，灰色）
3. 下拉选项面板样式统一：
   - 白色背景 + 阴影
   - 选项 hover 态浅灰背景
   - 选中态蓝色文字 + 左侧勾选图标
   - 选项高度 44px（触控规范）
4. 禁用态：灰色文字 + 灰色背景 + 不可点击

**推荐方案：** 自定义下拉组件，与全局表单样式统一，纳入 C8 全局组件库。
**对应批次：** C8 全局组件与空态

### P3-17｜洞察瀑布图缺图例
**问题：** 洞察页利润构成瀑布图仅有柱子和数值，无图例说明颜色含义。

**Skill 依据：**
- `ui-ux-pro-max` 数据可视化规则：图表必须有图例，颜色含义明确
- `ui-ux-pro-max` 可访问性规则：不单靠颜色传达信息，配合文字/符号

**解决方案：**
1. 瀑布图**顶部增加图例**（右对齐）：
   - 蓝色方块 = 收入 / 利润（正向）
   - 深色方块 = 成本 / 费用（负向）
2. 图例用**颜色方块（12×12px）+ 文字说明**（12px，辅助色）
3. 鼠标**悬停柱子**时显示 tooltip：
   - 项目名称（如"销售成本"）
   - 金额（¥276.00）
   - 占净营收比例（60%）
   - 与上期对比（↑/↓ + 幅度）
4. 柱子上直接标注金额（已有），配合图例理解颜色含义
5. 正负向柱子用不同颜色：正向蓝色，负向深灰/深蓝，零轴用虚线
6. 瀑布图下方增加结论文字："本月净营收 ¥459.96，扣除成本费用后经营利润 ¥133.96，利润率 29.1%"

**推荐方案：** 顶部图例（颜色方块+文字）+ 悬停 tooltip + 底部结论文字。
**对应批次：** C12 页面专项 P1

## 五、全局改进建议（跨页面）

### 5.1 设计令牌收尾（C1 已建，需补全）

### 5.4 数据可视化语义化（C12）

- 颜色 + 符号 + 文本三重传达（不单靠颜色）

- 异常值语义色高亮（成本上升/库存低/超预算）
