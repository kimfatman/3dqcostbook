# P0 首页经营判断适配：实施与验收记录

## 已实施内容

首页已由单一利润卡升级为由真实账本结果驱动的经营判断簇。`home-decision.ts` 只整理显示优先级：保留 `totals`、`buildBudgetBurn()` 与既有通知派生逻辑作为唯一口径，按预算超支、低利润订单、风险成本卡、预算预测风险、退款提醒的顺序取一项优先行动。主卡现在以“净营收 − 本月成本 ＝ 本期结果”表达计算关系，同时展示三列核算、预算状态和可下钻的风险行动。

Banner 已收束为 96px 的 Navy / Digital Blue 账本产品牌，不再使用光泽球体或抽象科技插画；其职责仍然限定为产品宣传与未来广告。成本趋势补充当前成本数值与账本栅格；消息中心将每条真实提醒改为“影响金额/范围 → 原因 → 业务动作”，并保留虚线、页签与等宽金额。

## 可访问性与回归

新增 `useReducedMotion()` 后，用户在页面打开期间切换系统“减少动态”设置，Banner 与提醒的自动切换会即时停止。轮播点位、暂停、提醒 ticker、风险行动和首页数据行均有不低于 44px 的操作命中面积；风险状态同时提供图标、文字、色彩与下钻，不依赖颜色单独表达。
