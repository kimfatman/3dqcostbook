# 第一批首页经营图表：实施验收

## 已实施图表与真实口径

首页保留“净营收 − 本月成本 ＝ 本期结果”的数字核算卡，不把经营结果图表化。新增的销售动能组件按订单成交自然日聚合近 7 日销售额和订单数：柱形表示成交金额，折线表示成交笔数；退款不会被错误计入销售发生日。SKU 排行以当前期间的订单行和退款为来源，销量榜按净销量（成交数量减退款数量）排序，利润榜按退款与可售回收入库冲减后的真实毛利排序。成本结构环图继续使用同一期间已过账的成本分类金额。

## 页面层级与交互

首页顺序现在是经营结果、销售/商品动能、成本结构、产品宣传。订单数据为空时，销售趋势与两张 SKU 榜不会拆成多个厚重空卡，而是合并为单一“销售与商品动能”账本状态，说明缺失原因并提供“记录第一笔订单”操作。已有数据时，销售趋势下钻订单，商品排行进入对应成本卡，成本结构进入已带分类关键词和月份条件的流水页。

## 视觉与回归

白色图表模块采用蓝色页签、24px 轻网格、虚线分隔和等宽金额列；空状态使用“结果状态 → 缺失原因 → 下一步经营动作”而非占位边框。375px、390px 和 430px 复核均未发现文字裁切、数值遮挡或触控拥挤。类型检查通过；7 个测试文件共 33 项测试通过；生产构建通过。构建仍提示前端主包大于 500 kB，属于既有包体提示，未阻断本轮功能与发布。
