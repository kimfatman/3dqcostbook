# 全站图表视觉升级记录

**目标：** 在不改变业务逻辑、数据结构或指标定义的前提下，将经营图表收敛为移动优先、消费级的数据体验。设计取向为低干扰的金融数字、柔和趋势、语义配色与可触达下钻，而非传统 ERP 或 BI 大屏。

## 图表盘点与数据边界

| 图表 | 页面 | 现有数据来源 | 本轮视觉边界 |
|---|---|---|---|
| 销售动能 | 首页 | 近 7 日订单销售额与订单数 | 平滑订单曲线、销售圆角柱体、当前/极值点强调；不更改订单聚合。 |
| 经营趋势 | 首页 | 近 7 日销售与成本汇总 | 平滑趋势线与渐变面积；不更改收入或成本计算。 |
| SKU 销量/利润榜 | 首页 | 当前期间 SKU 指标 | 统一横向圆角排行条、金融数字与下钻；不更改排序。 |
| 成本结构/预算进度 | 首页与预算 | 已分类成本、预算使用率 | 环心保留核心金额，弱化装饰；不更改分母或预算预测。 |
| 成本堆积、现金流、利润桥、退款帕累托、健康雷达 | 分析页 | 已入账分录、订单、退款与健康评分 | 弱化网格、圆角柱/条、语义色与可点击下钻；不更改筛选和指标。 |
| 定价利润曲线 | 智能定价 | 现有价格区间的贡献采样 | 3px 平滑曲线、面积渐变、当前价强调；不更改试算或采样。 |

## 统一规范（首轮落地）

| 项目 | 规范 |
|---|---|
| 语义配色 | 品牌蓝用于主趋势与当前值；成功绿用于正向流入/高点；风险红用于退款或亏损；预警橙用于低点与预警。 |
| 数字 | 使用既有金融数字字体与等宽数字；核心金额优先于图例与坐标文本。 |
| 曲线 | 3px 圆角平滑线，低对比渐变面积，当前/峰值/低值以小型语义点强调。 |
| 柱、排行和环 | 圆角柱体与进度条，细间距；环形图中心呈现核心金额或完成率。 |
| 网格与标题 | 取消背景网格和虚线，仅保留必要的低对比参考线；标题保持短句，图例压缩为数据提示。 |
| 动效 | 仅对曲线绘制、柱体入场和卡片淡入使用 280–720ms 动效，遵守 `prefers-reduced-motion`。 |
| Tooltip | `ChartTooltip` 同时支持键盘聚焦、鼠标悬停和触碰点击；已接入预期利润曲线、SKU 排行、退款排行与成本环形图。 |
| 深色模式 | 图表令牌同时定义 `.dark` 与系统深色偏好回退的表面、文字、轨道和网格色；“我的 → 个性化”提供用户可操作的图表深色模式切换。 |

## 响应式与可读性复核

在 375px、390px、430px、768px 与 1280px 下复核首页、成本分析与智能定价。首页空数据趋势保持清晰可读；分析页成本结构、结构对照与排行没有引入额外视觉噪声；定价利润曲线在三个手机宽度和两档较宽布局中保留 3px 平滑路径、渐变填充、当前/最高/最低点与紧凑当前值提示。

| 验证面 | 结果 |
|---|---|
| 375px、390px、430px | 关键数值、排行条、图例、当前值提示和底部操作均未裁切；图表标题保持单层短句。 |
| 768px | 首页核心经营结果与提醒使用双列，图表卡不被拉伸成后台式大面板。 |
| 1280px | 宽屏维持移动应用的最大阅读宽度与留白，成本排行的数值列和进度条保持对齐。 |
| 动效与无障碍 | 图表入场、曲线绘制和柱体生长仅在允许动效时执行；展示层数字过渡覆盖定价当前贡献、预算环、销售额/订单数、SKU 排行和成本环心。`AnimatedChartValue` 的 jsdom 回归验证减少动效时立即展示最终值与辅助技术标签；键盘焦点可见，关键 SVG 带有说明文本与点位标题。 |
| 深色模式 | 通过 `.dark` 和 `prefers-color-scheme: dark` 定义图表表面、正文、轨道、网格和语义色。真实 Home DOM 回归已验证用户在“我的 → 个性化”切换后根元素写入/移除 `.dark`；另在 390px 逐页采集首页、成本分析和智能定价实际深色令牌截图，修复数据卡浅底浅字冲突后，核心数字、排行、环形图、趋势和 Tooltip 入口均保持可读。 |

## 最终验证与效果图

`pnpm check`、45 个测试文件共 160 项测试和 `pnpm build` 均通过。新增回归覆盖 ChartTooltip 的键盘焦点与点击切换、用户可操作的运行时深色模式切换，以及数字过渡在减少动效偏好下的即时可访问输出。构建仅保留既有主 JavaScript chunk 大于 500 kB 的提示。

效果图以最终 390px 移动端截图归档：`home-dashboard-chart-upgrade.png`、`cost-analysis-chart-upgrade.png` 和 `pricing-profit-chart-upgrade.png`。它们分别展示首页趋势入口、分析页排行/结构对照，以及定价曲线的当前/高低点和提示入口。组件级标题/装饰、数字反馈、深色模式和多视口验收矩阵见 `docs/chart-visual-validation-2026-08-25.md`。
