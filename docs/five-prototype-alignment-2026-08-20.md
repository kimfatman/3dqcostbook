# 五张 UI 原型严格对齐基准

## 经营页

经营页原型采用“品牌栏 → 月份标题 → 蓝色经营结果主卡 → 成本趋势柱图 → 两条下钻数据行 → 五级底部导航”的固定顺序。主卡为明亮数字蓝，经营结果使用最大字号；柱图是独立白色容器，显示 6 个月成本、数值、月份和当前月的蓝色强调；预算剩余与第一成本均为单行横向数据卡，不与其他列表混排。

## 分析页

分析页原型采用“标题与月份 → 白色利润瀑布卡及本月/上月切换 → 独立收入/成本双柱趋势卡 → Top 5 成本变化排行卡”的三图顺序。瀑布图必须有收入、销售成本、经营费用和经营利润四根竖柱以及连接虚线；趋势图和排行均独立成卡，不插入订单、供应商、隐性成本等其他模块。该页底部导航高亮“分析”。

## 已识别的真实页面差异

当前经营页已具备结果主卡、预算摘要和成本趋势，但成本趋势仍过于紧凑且混入较多快捷入口和成本构成列表；需要收敛至原型的主卡、趋势、两条横向数据行。当前分析页在无收入时正确显示补录入口；当有收入时应严格采用原型的白色瀑布卡和三卡结构，而不是继续堆叠 SKU、供应商、隐性成本等附属模块。

## 预算页

预算页原型采用“标题与月份 → 居中大单环 → 本月预算/剩余可用双指标 → 橙色预测预警条 → 独立月末预测趋势卡 → 月度预算编辑卡”的顺序。单环为页面唯一主图，蓝色代表已用，灰色代表剩余；预测线从今日已用金额向月末延伸，并使用蓝/橙两段和预算虚线。真实页面必须移除原型外的深色页头、说明卡和多余入口。

## 订单页

订单页原型采用“深海军蓝品牌带 → 订单标题、搜索与新增按钮 → 月份筛选 → 全部/低利润/退款三枚筛选 → 无卡片分隔订单行 → 售后处理状态区 → 底部导航”的顺序。每个订单行包含订单号、客户、渠道标签、时间、成交额、贡献利润或橙色预警；无退款时仅显示一条带蓝色对勾的状态条。真实页面需弱化空状态说明，只在没有订单时显示新增引导。

## 商品页

商品页原型采用“品牌栏与新增成本卡 → 商品成本标题与一行说明 → 全部商品/关注/按成本上升栏目 → 搜索 → 大成本卡”的顺序。成本卡必须依次包含商品标识、状态标签、单位成本/售价/单件利润三列、带数值的 6 期单位成本柱图，以及成本构成和智能定价两条下钻。当前真实数据中没有可靠商品照片，因此使用统一的成本卡图标占位，而不伪造商品图片。

## 严格对齐复核结果

已在 390px 视口逐页复核经营、分析、预算、订单和商品。经营页与原型保持蓝色主 KPI、独立趋势卡、预算剩余和第一成本两条数据行；分析页保持三卡结构，并在零收入条件下诚实地退化为补录入口；预算页的旧多段预测线已修复为一条连续蓝橙线与单条预算虚线；订单页与商品页分别对齐其筛选/空状态及成本卡/微趋势构图。类型检查通过，6 个测试文件、24 项测试通过，生产构建通过。
