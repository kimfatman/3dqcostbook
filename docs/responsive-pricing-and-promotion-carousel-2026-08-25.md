# 柔和利润曲线、全终端布局与五页宣传轮播验收记录

**日期：** 2026-08-25  
**范围：** 智能定价利润趋势、首页核心模块的手机/平板/PC 布局，以及产品宣传轮播。

## 实施口径

| 模块 | 已实施内容 | 保留的准确性边界 |
| --- | --- | --- |
| 预期利润趋势 | 在真实采样价格点之间使用 Catmull–Rom 插值生成高密度柔和 SVG 曲线；当前价、保本价、建议价、零贡献线和原始采样标记仍独立显示。 | 曲线只改变连线观感，不改变任一价格点、单件贡献、贡献毛利率或两位小数计算结果。 |
| 手机与平板 | 390px 保持单列数据主线；从 768px 起将首页次级模块收紧为两列，同时保留经营主卡、轮播和快捷入口为满宽。 | 触控控件、金额列和轮播文字安全区仍按移动端最小宽度设计。 |
| PC | 从 1080px 起扩展为约 1080px 的居中经营工作台，内容区收敛至可扫描宽度，避免大屏过度拉伸。 | 不改变底部导航、页面栈或账本数据来源。 |
| 产品宣传 | 轮播由 3 页扩展至 5 页：成本核算、智能定价、经营洞察、订单退款、现金流。每页使用独立的蓝色亚克力视觉资产与左侧文字渐变安全区。 | 宣传图为装饰性背景，功能入口仍由可访问的轮播按钮和文字标签提供。 |
| 全站折线图 | 首页销售动能与经营趋势、智能定价预期利润共用 Catmull–Rom 柔和插值；加入圆角线端、渐变面积、原始采样点和终点高亮。 | 不伪造趋势：原始采样点、滑块价格、贡献金额、保本价和建议价保持原计算结果；定价线在数学上为线性时仍忠实呈现线性斜率。 |
| 无界轮播 | 移除轮播外层卡片边框、圆角和阴影；五页宣传图作为沉浸式全幅内容嵌入首页数据流。 | 保留左侧文字遮罩安全区、五页指示器、键盘可触达按钮与固定页宽轨道。 |
| 悬浮记账 | 首页、订单、商品、分析等一级业务页新增右下角“记一笔”悬浮入口；资料页与所有二级/表单页隐藏，避免重复主操作。 | 入口复用既有 `openNewRecord` 导航语义；固定定位避让底部导航与安全区。 |
