## 自动化覆盖边界

`client/src/lib/template-display.test.ts` 持续对五个行业模板执行映射层回归，断言首页行业标识、底部入口、订单实体/单位、成本卡标题/描述/单位利润/图片管理文案、SKU、资料页图片名称，以及预算/分析的行业分类来源。新增的 `Home.template-display.dom.test.tsx` 则验证该映射确实进入真实 React DOM 和实际导航路径。两者互补：映射层便于定位模板元数据漂移，DOM 层能捕获页面未引用映射、动态 Tab、单位保留、路由栈或条件渲染的断点。

本轮本地质量门禁为 `pnpm check`、43 个测试文件共 146 项测试和 `pnpm build` 均通过。生产构建仍只有既有的主 JavaScript chunk 大于 500 kB 提示，没有新增构建错误。该项改动包含测试运行时和测试代码，不改变账本计算、数据库结构、API 合约或生产页面业务流程。

## 材料输入根因

材料行过去将材料名称拼入 React `key`，每输入一个字符就会改变行身份并重建输入框。现已改用仅存在于草稿层的稳定材料 ID；保存时会剥离该 ID，因此不会改变 BOM 持久化 ID、SKU 成本或历史订单快照。
