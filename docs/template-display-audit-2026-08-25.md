## 自动化覆盖边界

`client/src/lib/template-display.test.ts` 已对五个行业模板执行映射层回归，断言首页行业标识、底部入口、订单实体/单位、成本卡标题/描述/单位利润/图片管理文案、SKU、资料页图片名称，以及预算/分析的行业分类来源。该测试用于防止模板数据或展示映射漂移；它不替代真实页面渲染快照，后者继续保留在待办。

## 材料输入根因

材料行过去将材料名称拼入 React `key`，每输入一个字符就会改变行身份并重建输入框。现已改用仅存在于草稿层的稳定材料 ID；保存时会剥离该 ID，因此不会改变 BOM 持久化 ID、SKU 成本或历史订单快照。
