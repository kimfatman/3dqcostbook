# 算得清｜经营分析模块 PRD 完整需求文档
**版本：** V1.0 ｜ **适用：** 小程序端 ｜ **迭代优先级：** 一期餐饮完整版，二期多行业模板 ｜ **定稿日期：** 2026-08-31

## 一、导航层级定稿（产品结构）

一级菜单：经营分析（首页核心入口卡片）
```
├─ Tab二级菜单 ① 成本分析（管控物料、配方、真实物料消耗、损耗浪费）
└─ Tab二级菜单 ② 利润分析（定价毛利、盈亏保本、客流产能、经营诊断）
```

**模块职责边界（严格区分，避免功能耦合）**
1. **成本分析**：向内算成本，管节流。只核算物料、耗材、原材料的真实投入；输出单品/套餐的标准物料成本，不计算售价、毛利、盈利结果。
2. **利润分析**：向外算盈利，管开源。读取成本分析产出的物料成本，搭配售价、门店固定开支，计算毛利、保本营业额、保本客流，给老板经营决策。

## 二、顶部全局控件（父页面「经营分析」通用）

页面顶部固定栏：
1. 行业模板下拉选择器：餐饮｜烘焙甜品｜美业美容｜汽修保养｜鲜果奶茶｜小型加工厂｜自定义通用版
2. 功能按钮：导出PDF报表｜重置模板

切换模板触发效果：两个Tab页面同步替换业务名词、行业告警阈值、预置示例物料/文案，**底层计算引擎不变**。

## 第一部分 Tab1：成本分析（需求明细）

页面整体布局：4张业务功能卡片（从上到下业务顺序）

### 卡片1｜物料耗材资料库
功能描述：维护所有原材料、配件、耗材基础数据，自动计算加工后净料成本。

| 输入字段 | 说明 |
|---|---|
| 物料名称 | 文本输入 |
| 采购单位 | 斤/公斤/个/包（随行业模板变更） |
| 采购单价 | 采购入库原价 |
| 加工出成率(%) | 清洗、去皮、烘烤损耗比例；例如土豆70%，肉类85% |
| 备注 | 可选填写供应商信息 |

- 自动计算公式：**净料单价 = 采购单价 ÷（出成率 ÷ 100）**
- 操作按钮：新增｜编辑｜删除｜批量导入
- 行业模板文案替换示例：餐饮=食材；美业=美容耗材；汽修=维修配件；加工厂=原材料

### 卡片2｜产品标准BOM成本卡
功能描述：给每一款产品建立配方卡，引用物料库数据，自动汇总一份产品全部物料总成本。

输入字段：
1. 产品名称
2. BOM明细行（可新增多行）：选择物料库物料 → 填写单份用量

- 自动计算：**单品标准物料总成本 = Σ（明细净料单价 × 使用用量）**
- 功能操作：保存配方｜复制配方（快速新建同类产品）｜打印导出PDF成本卡
- 输出结果：只展示物料成本，不填写售价、不计算毛利（毛利交给利润分析模块）

### 卡片3｜套餐物料成本汇总
功能描述：勾选多个已经建好BOM的单品，自动汇总整套套餐的全部物料投入成本。

1. 选择套餐包含的产品列表
2. 填写套餐内每款产品份数

- 自动计算公式：**套餐总物料成本 = Σ（单品标准物料成本 × 套餐份数）**
- 仅输出物料合计成本；套餐售价、套餐毛利不在本页计算

### 卡片4｜库存盘点 & 损耗差异对账（会员付费功能）
功能描述：对比理论用料和实际库存消耗，核算后厨/车间浪费、丢失损耗金额。

1. 录入期初库存、采购入库数量、月末盘点剩余库存
2. 系统自动读取当月销售销量 × BOM配方，算出理论物料消耗
3. 实际消耗 = 期初库存 + 采购入库 − 期末盘点库存
4. 损耗差额成本 =（实际消耗 − 理论消耗）× 物料净料单价

- 输出报表：物料损耗明细、异常损耗告警提示

## 第二部分 Tab2：利润分析（需求明细）

**数据联动规则：** 本模块自动读取【成本分析】保存的单品/套餐物料成本，无需重复录入配方数据。

页面布局：4张业务功能卡片

### 卡片1｜单品 & 套餐毛利核算
输入内容：
1. 选择产品/套餐（自动带出系统保存的标准物料成本）
2. 填写对外销售售价、外卖打包附加成本（可选）

自动计算公式：
- 毛利金额 = 销售售价 − 物料总成本 − 打包耗材成本
- 销售毛利率 = 毛利金额 ÷ 销售售价 × 100%（勇哥餐饮标准口径）

**行业健康红线告警（切换模板自动变更阈值）**：示例：餐饮食材成本率25%‑30%；美业耗材成本8%‑15%；汽修配件35‑45%。高于/低于合理区间文字风险提示。

### 卡片2｜门店固定成本设置
输入字段（月度固定开支）：房租租金｜人员固定底薪｜设备折旧｜平台年费｜其他固定杂费

自动汇总：**月度固定总成本 = 全部固定费用相加**

### 卡片3｜盈亏保本测算报表
前置依赖数据：
1. 产品加权平均毛利率（系统自动读取全部产品数据加权计算）
2. 月度固定总成本（上一卡片录入）

计算公式：
1. 月度保本营业额 = 月度固定总成本 ÷ 综合加权毛利率
2. 每日保本营业额 = 月度保本营业额 ÷ 每月营业天数
3. 各项成本占营收百分比，超标红色告警

输出诊断文案：当前门店成本结构健康 / 人工成本过高 / 房租压力偏大

### 卡片4｜客流 & 产能评估测算
输入字段：
1. 门店客单价
2. 门店产能配置：座位/工位数量、桌均消费人数 / 单工位每日最大承接量
3. 新店评估补充：门口过路人流、进店转化率

自动计算指标：
1. 每日保本订单/保本客流量 = 每日保本营业额 ÷ 客单价
2. 翻台率 / 工位利用率计算
3. 门店单日营收理论天花板（产能上限）
4. 开店风险评估结论：安全盈利区间｜刚好保本｜开店风险较高

## 三、数据表结构设计（后端）

1. `material` 物料主数据表（成本分析基础数据）
2. `bom_product` BOM配方主表（绑定行业模板ID）
3. `bom_item` BOM配方明细行，存储物料+用量
4. `package_group` 套餐组合表，记录套餐包含产品及份数
5. `product_price` 产品售价表（利润分析使用）
6. `business_fixed_cost` 门店月度固定运营成本
7. `capacity_config` 工位、客流产能配置参数
8. `daily_business_log` 每日经营台账（会员复盘）
9. `inventory_check` 库存盘点、损耗对账记录

## 五、业务闭环完整故事线
1. 成本分析维护物料配方 → 算出产品真实物料成本
2. 利润分析填入售价，核算单品毛利
3. 录入房租人工，算出门店保本营业额
4. 测算每天需要多少客流订单才能盈利
5. 月末盘点库存，核对理论用料和实际损耗，完成全链路经营管控
