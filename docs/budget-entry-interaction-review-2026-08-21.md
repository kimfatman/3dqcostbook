# 预算入口与交互优化：实施验收

首页已移除“预算剩余”常驻数据行。首页仍会在预算进入风险或超支状态时，通过经营判断主卡的“优先处理”与顶部经营提醒提供直接下钻；预算健康时，不额外占用首页阅读空间。

预算管理页保留为唯一完整编辑场景，个人中心的“预算设置”和消息中心的预算提醒均进入该页面。编辑卡中已显示当前月度预算、可直接输入的“调整为”金额以及“保存预算并刷新预测”主操作。保存后停留在预算页，预算环、剩余金额、月末预测和风险提示同步重新计算，并通过状态提示反馈完成结果。

在 375px、390px 与 430px 复核：首页的主线已收束为经营结果、产品宣传、成本趋势和第一成本；预算页面的输入与保存不发生裁切、金额列保持右对齐。账本计算、预算预测公式与行业模板未改动。
