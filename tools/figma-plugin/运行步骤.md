# 运行步骤 · 算得清 Design System Builder

> 目标：在 Figma 文件 `kimfatman's team library` 中生成 00–07 八个页面 + SDQ Core 变量集。
> 插件文件：本目录（manifest.json / code.js）。全程约 1 分钟。

## 步骤

### 1. 打开目标文件
浏览器或 Figma 桌面客户端打开 `kimfatman's team library`（之前发给助手的那个文件链接）。

### 2. 打开插件菜单
- **桌面客户端**：左上角 Figma 图标（主菜单）→ Plugins → Development
- **网页版**：左上角 Figma logo（主菜单）→ Plugins → Development
- 必须在**设计文件内**（不是首页仪表盘），否则看不到 Plugins 菜单

### 3. 导入插件
点 **Import plugin from manifest…** → 文件选择器导航到：
`C:\Users\Administrator\Projects\3dqcostbook\tools\figma-plugin\`
选中 **manifest.json** → 打开。（注意选 manifest.json，不是 code.js）

### 4. 运行
导入后插件自动弹窗运行；若未运行：Plugins → Development → **算得清 Design System Builder** 点击运行。等 3–10 秒，右上角出现提示「算得清 Design System 已生成：8 个页面 + SDQ Core 变量集」。

### 5. 确认生成
- 左侧页面面板出现 **00｜封面 & 使用说明 → 07｜Developer Handoff** 八个页面
- 主菜单 → Variables（或 Assets 面板旁）出现 **SDQ Core** 集合：blue/neutral 50–950 全阶 + semantic 五色，light/dark 双模式

### 6. 收尾
- 原有空 Page 1、Page 2：右键 → Delete
- 回复助手「跑完了」，触发 API 复验（页面清单/变量数量/组件数量）

## 故障排查

| 现象 | 处理 |
| --- | --- |
| 菜单里没有 Plugins/Development | 确认已打开设计文件（首页仪表盘无此菜单） |
| 导入报 manifest 解析错误 | 确认选择的是 manifest.json 文件本身 |
| 插件弹红色报错 | 报错文本原样发给助手修复 |
| 想重跑 | 先右键删除已生成的 00–07 页面，否则会生成两套 |
| 文字显示为英文 Inter 字体 | 正常：Figma 插件环境字体演示用 Inter；中文按字体栈回退 |

## 找不到 Development 菜单？三种打开方式

> 前提：必须已打开设计文件（能看到画布与左侧图层面板）。Figma 首页/文件列表里没有插件菜单。

1. **画布右键（推荐）**：在画布空白处点右键 → 插件/Plugins → 开发/Development → 从清单导入插件/Import plugin from manifest…
2. **主菜单**：左上角 Figma 图标/logo → 插件/Plugins → 开发/Development → Import plugin from manifest…（中文界面：「从清单导入插件」）
3. **快速操作**：文件内按 Ctrl+/（Mac Cmd+/）→ 输入 manifest 或 导入 → 回车

若三个入口都不存在（个别账号类型限制）：改走社区插件 html.to.design 路线——助手把 00–07 分册生成为 HTML 后逐个导入，无需 Development 菜单。跟助手说「走社区插件路线」即可。
